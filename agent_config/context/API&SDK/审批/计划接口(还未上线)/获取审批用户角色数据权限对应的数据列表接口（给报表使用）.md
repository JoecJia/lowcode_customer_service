**简要描述：**

- 获取审批权限设置-数据权限里所对应的数据列表接口

**请求URL：**
http://m.oa.chaoxing.com/api/approve/app/forms/data/role/permission/data/search/list

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID    |高级设置页面可以查看  与formAlias参数至少要有一个有值|
|formAlias   |否  |string | 表单接口标识（表单别名）    |高级设置页面可以设置 与formId参数至少要有一个有值 |
|uid   |是  |int | 当前用户uid    |当前用户uid|
|roleId   |否 |int | 角色ID    |默认-1|
|permissionGroupId   |否  |int| 权限组ID|默认为默认权限组，其id为1|
|searchStr     |否  |string | 查询筛选条件,不参与加密|json格式，传入时需做URLEncode编码，注意不要二次编码,[点击查看searchStr结构](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看searchStr结构")|
|cpage |否  |int |页码   | 默认1|
|pageSize |否  |int |一页多少条   | 默认10|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2023031314][fid=97253][formId=182183][permissionGroupId=1][roleId=3][sign=xxx][uid=47101001]";
```
          
（4） MD5加密操作
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
