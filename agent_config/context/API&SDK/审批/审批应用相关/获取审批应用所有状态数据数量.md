**简要描述：**

- 获取审批应用所有状态数据数量

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/end/data/count?fid=&formId=&datetime=&sign=&enc=&approveStatusTypeId=

**请求方式：**
- GET,POST均可

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|fid   |是  |int | 单位ID    |单位fid|
|formId   |是  |int | 审批应用id    |审批应用id|
|approveStatusTypeId   |否  |string | 审批状态类型值    |0,1,2,3 待审批，同意，拒绝，撤销

**返回结果**
（1）成功

* 返回数据格式：
```json
    {
      "data": {
        "waitCount": 1,
        "agreeCount": 1,
        "rejectCount": 1,
        "revokeCount": 1
      },
      "success": true
    }
```
* 返回参数说明：

|参数名字|参数说明|
|---- |----  |
|waitCount|待审批个数|
|agreeCount|同意个数|
|rejectCount|拒绝个数|
|revokeCount|撤销个数|

（2）失败

* 返回数据格式：
```json
   {"msg":"应用ID为空","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|应用ID为空|未传 fid / formId|
|审批不存在|formId 无对应审批|

**接口参数配置**
（1）接口标识
> sign=XXX 由超星办公系统方分配

（2）加密秘钥
> key=XXX 由超星办公系统方分配

（3）加密原文字符串
> source="[approveStatusTypeId=2][datetime=2020092718][fid=1385][formId=10021][sign=]";

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/approve/forms/end/data/count?fid=1385&formId=10021&datetime=&sign=&enc=

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
