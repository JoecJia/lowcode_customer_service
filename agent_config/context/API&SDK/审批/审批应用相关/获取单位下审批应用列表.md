**简要描述：**

- 获取单位下审批应用列表接口

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/app/list

**请求方式：**
- GET,POST均可

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|deptId   |是  |int | 单位ID    |单位ID|
|formIds  |否 |string|审批表单ID  |不传获取该单位下所有审批；传此参数获取对应审批的信息,多个以逗号分隔|
|formAlias  |否 |string|表单别名  |支持传多个表单别名,多个以逗号分隔|
|name  |否 |string|表单名称  |表单名称|
|source  |否 |int|表单的创建来源 |表单的创建来源|
|excludeFields  |否 |string|返回值排除的字段 |approveVerifyConfig，enteringVerifyConfig，submitVerifyConfig，permissionConfig，formConfig，formHighGradeConfig，submitPrompt 中的0个或多个，英文逗号分隔|
|cpage  |否 |int|页码 |默认第1页|
|pageSize  |否 |int|一页多少条 |默认50条，最多限制一次100条|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|aprvTypeId |否  |int |审批类型id |审批类型 id，默认 10000 |
|findEngineCreate |否  |boolean |仅查引擎创建 |是否只查引擎创建的审批，默认 false；仅传了 source 且不为 0 时生效 |

**返回结果**

（1）成功

* 返回数据格式：
```json

        "dataList": [{
            "applyUrl": "http://t.chaoxing.com/front/approve/apps/forms/fore/apply?id=10053&aprvAppId=10053",//审批填写页地址
            "aprvAppId": 10053,//审批应用id
            "deptId": 97253,//单位id
            "id": 10053,//审批应用id
            "inserttime": 1559619449000,//审批创建时间
			"appName":"10053",//表单接口标识
			"columnsNum":1,//多列信息
            "name": "测试指定主管",//审批应用名称
            "source": 0,//审批创建来源，0：微服务
            "uid": 21025345,//审批创建人uid

```
（2）失败

* 返回数据格式：
```
{"msg":"验证失败","success":false}
```

**补充参数取值：**

|参数|说明|
|:---|:---|
|excludeFields=auditConfig|在现有 excludeFields 取值基础上，可额外排除审核配置字段|

**补充返回字段：**

|字段|说明|
|:---|:---|
|data.total|总条数，文档未列|
|data.totalPage|总页数，文档未列|
|dataList[] 配置类字段|`approveVerifyConfig`、`permissionConfig`、`formConfig`、`formHighGradeConfig`、`submitVerifyConfig`、`enteringVerifyConfig`、`auditConfig` 等随实体返回，可用 `excludeFields` 裁剪|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|formIds长度不得超过100|formIds 超过 100 个|
|获取单位下自建审批应用列表异常|服务端处理异常|
|鉴权失败|签名/enc 或单位校验不通过|

**接口参数配置**
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串，具体加密字段以实际传的参数为准，不传就不用
```
> source="[datetime=2019101517][deptId=1385][sign=xxx]";
```

（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
