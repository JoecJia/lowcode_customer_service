**简要描述：**

- 单位下审批应用模板删除接口

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/app/del?deptId=&formAppId=&datetime=&sign=&enc=

**请求方式：**
- GET,POST均可

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|deptId   |是  |int | 单位ID    |单位ID|
|formAppId   |是  |int | 审批应用模板id    |审批应用模板id|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|appName |否  |string |审批别名 |formAppId 未传或小于等于 0 时按别名定位审批 |

**返回结果**
（1）成功

* 返回数据格式：
```json
    {"msg": "删除成功","success": true}
```

（2）失败

* 返回数据格式：
```json
   {"msg":"删除失败","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|单位id不能为空|未传 deptId|
|应用id和应用别名不能同时为空|formAppId<=0 且 appName 为空|
|无权删除|当前用户无该审批的删除权限|
|应用不存在|formAppId / appName 定位不到审批|

**接口参数配置**
（1）接口标识
> sign=xxx 由超星办公系统方分配

（2）加密秘钥
> key=xxx 由超星办公系统方分配

（3）加密原文字符串
```
> source="[datetime=2020092718][deptId=1385][formAppId=10021][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/approve/forms/app/del?datetime=2020092718&deptId=1385&sign=xxx&enc=11167d9f4d858bde607e6136eb3c30dd&formAppId=10021

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
