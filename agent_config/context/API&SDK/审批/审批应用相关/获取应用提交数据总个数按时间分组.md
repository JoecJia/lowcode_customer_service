**简要描述：**

- 获取应用提交数据总个数按时间分组

**请求URL：**

- http://m.oa.chaoxing.com/api/approve/forms/statistics/list/count?fid=&formId=&timeType=&datetime=&sign=&enc=

**请求方式：**

- GET,POST均可

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|fid   |是  |int | 单位ID    |单位fid|
|formId   |是  |int | 审批应用id    |审批应用id|
|timeType   |是  |int | 统计时间类型    |1：年 2：月 3：日|
|start |否  |long |开始时间 |统计开始时间（时间戳），不传无法限定区间（SDK：未单列） |
|end |否  |long |结束时间 |统计结束时间（时间戳），不传无法限定区间（SDK：未单列） |

**返回结果**
（1）成功

* 返回数据格式：

```json
    {
      "data": {
        "statisticsMap": {
          "2023-03-29": "17",
          "2023-03-28": "5"
        }
      },
      "success": true
    }
```

|参数名称|参数类型|参数说明|
|----|----|----|
|statisticsMap|object|key：(按年统计格式为yyyy，按月统计格式为yyyy-MM，按日统计格式为yyyy-MM-dd)，value:个数

（2）失败

* 返回数据格式：

```json
   {"msg":"应用ID为空","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|单位id不能为空|未传 fid|
|应用id不能为空|未传 formId|
|时间类型不能为空|未传 timeType|
|时间类型格式异常|timeType 非法|

**接口参数配置**
（1）接口标识
> sign=XXX 由超星办公系统方分配

（2）加密秘钥
> key=XXX 由超星办公系统方分配

（3）加密原文字符串
> source="[datetime=2020092718][fid=1385][formId=10021][timeType=3][sign=]";

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/approve/forms/statistics/list/count?fid=1385&formId=1385&timeType=3&datetime=&sign=&enc=

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
