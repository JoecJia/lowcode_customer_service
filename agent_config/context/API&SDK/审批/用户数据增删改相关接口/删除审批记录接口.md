**简要描述：**

- 删除审批记录接口

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/user/data/del?fid=&aprvAppId=&formUserId=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
```
POST请求样例:
ContentType:application/x-www-form-urlencoded
Body数据:
fid=97253&aprvAppId=1&formUserId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705
```

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID |
|aprvAppId   |是  |int | 审批应用id  |审批应用id
|formUserId |是 |string|数据行记录id |(多行以"1,2,3"传递)
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|operationRecord |否  |string |操作记录 |操作记录，≤100 字，写入数据操作日志 |
|operatorUid |否  |long |操作人uid |操作人 uid |

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "msg":"删除成功",
    "success": true
}
```

（2）失败

* 返回数据样例:
```
{"msg":"缺少单位Id","success":false}
{"msg":"审批不存在","success":false}
{"msg":"删除失败","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|数据已被删除|formUserId 对应数据不存在|
|您所访问的应用正在升级中|审批升级中|
|operationRecord参数内容限制100字符|operationRecord 超过 100 字符|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[aprvAppId=1][datetime=2021082717][fid=97253][formUserId=1][sign=xxx]";

```
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5） 结果地址
> http://m.oa.chaoxing.com/api/approve/forms/user/data/del?fid=97253&aprvAppId=1&formUserId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
