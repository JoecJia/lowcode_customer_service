**简要描述：**
- 根据单位ID，表单id和数据行ID修改审批数据接口

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/user/data/update

**请求方式：**
- POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json
```java
POST
ContentType:application/x-www-form-urlencoded
Body数据:
fid=&formId=&formUserId=&formData=&datetime=&sign=&enc=
```


**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位id    | 单位id|
|formId   |是  |int | 审批表单id    | 审批表单id|
|operatorUid   |否(不参与加密)  |int | 当前操作用户UID    | 当前操作用户UID|
|formUserId   |是  |string | 用户填写数据行id    | 数据行id|
|formData|是(不参与加密)  |string | 修改的表单数据jsonArray数组    |字段值数组[{字段值1},{字段值2}],需做utf8URL编码|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|currentVersion |否  |Integer |  传1更新为最新版本，不传或者传0还保持原来的逻辑  |
|aprvTypeId |否  |int |审批类型id |审批类型 id，默认 10000 |
|operationRecord |否  |string |操作记录 |操作记录，≤100 字 |
|defaultValueRules |否  |string |默认值规则 |字段默认值规则 |

**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|success| true/false
|msg|修改成功/失败

**返回结果**
（1）成功

* 返回数据格式：
```json
   {
       "msg": "[200]修改成功",
       "success": true
   }
```
（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]修改失败","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少单位Id|未传 fid|
|缺少审批表单Id|未传 formId|
|查无数据|formUserId 无对应数据|
|审批不存在|formId 定位不到审批|
|operationRecord参数内容限制100字符|operationRecord 超过 100 字符|
|您所访问的应用正在升级中|审批升级中|
|更新数据失败|服务端处理异常|

**接口参数配置**(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2020090916][fid=1][formId=12][formUserId=9760][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
