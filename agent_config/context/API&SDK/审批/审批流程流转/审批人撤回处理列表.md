**简要描述：**

- 自建审批审批人撤回权限列表接口说明

**请求URL：**
- https://office.chaoxing.com/api/approve/apps/status/user/revoke/list?formUserId=&fid=&uid=&datetime=&sign=&enc=

**请求方式：**
- GET/POST请求

**参数说明：**

|参数名称     |是否必填|参数类型|参数名称       |参数说明|
|:----       |:----|:----- |:-----        |-----   |
|datetime    |是    |string | 生成加密串时间 | 格式：yyyyMMddHH|
|sign        |是    |string | 接口标识      | 由超星办公系统方提供|
|enc         |是    |string | 接口参数加密串 |采用md5加密方式进行生成|
|fid         |是    |int    | 单位ID       |单位fid|
|uid         |是    |long   | 用户ID       |当前审批处理人passport id|
|formUserId  |是    |int    | 审批数据id    |审批数据主键|
|formId      |否    |int    | 审批应用id    |审批应用ID|
|formAlias   |否    |string | 审批应用别名   |审批应用别名|

**返回参数说明：**

|参数名称        |参数类型 |参数名称         |参数说明|
|:----          |:----- |:-----          |-----   |
|userRevokeList |list   | 审批人可撤回节点列表 | 当前用户可撤回的审批节点列表；无权限时返回空数组|

**userRevokeList参数说明：**

|参数名称      |参数类型 |参数名称|
|:----        |:-----  |:----- |
|nodeUniqueId |long    | 审批节点唯一标识|
|title        |string  | 审批节点名称|

**返回结果**
（1）成功

* 返回数据格式：
```JSON
{
    "data": {
        "userRevokeList": [
            {
                "nodeUniqueId": 123456789,
                "title": "审批人"
            }
        ]
    },
    "success": true
}
```

（2）无撤回权限

* 返回数据格式：
```JSON
{
    "data": {
        "userRevokeList": []
    },
    "success": true
}
```

（3）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_UID|未传 uid|
|MISSING_FORM_USER_ID|未传 formUserId|
|服务层失败|撤回列表查询失败|

**接口参数配置**
（1）接口标识
> sign=aprvStatusHandle_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[datetime=xxx][fid=xxx][formAlias=xxx][formId=xxx][formUserId=xxx][sign=xxx][uid=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]

（3）旧版审批流数据不支持审批人撤回处理，本接口返回空数组。
