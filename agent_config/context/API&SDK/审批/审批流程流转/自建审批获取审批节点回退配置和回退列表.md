**简要描述：**

- 自建审批获取审批节点回退配置和回退列表接口说明

**请求URL：**
- https://office.chaoxing.com/api/approve/apps/status/back/list?formUserId=&fid=&datetime=&sign=&enc=

**请求方式：**
- GET/POST请求

**参数说明：**

|参数名称     |是否必填|参数类型|参数名称       |参数说明|
|:----       |:----|:----- |:-----        |-----   |
|datetime    |是    |string | 生成加密串时间 | 格式：yyyyMMddHH|
|sign        |是    |string | 接口标识      | 由超星办公系统方提供|
|enc         |是    |string | 接口参数加密串 |采用md5加密方式进行生成|
|fid         |是    |int    | 单位ID       |单位fid|
|formId      |否    |int    | 表单ID    |表单ID,与formAlias任传一个|
|formAlias   |否    |string | 表单接口标识    |表单接口标识,与formId任传一个|
|formUserId  |是    |int    | 审批数据id    |审批数据主键|
|nodeUniqueId |否  |string |节点唯一标识 |并行流程可指定当前节点；不传时取当前处理中节点，取不到报“获取当前审批节点失败”，指定节点不在流程中报“节点唯一标识指定节点不存在” |

**返回参数说明：**

|参数名称              |参数类型 |参数名称         |参数说明|
|:----                |:----- |:-----          |-----   |
|approveBackConfig    |int    | 回退节点配置     | 1：审批人自选回退节点 -1：回退上一节点|
|approveStepBackList  |list   | 审批回退节点列表  | 当前节点可进行回退的节点列表|

**approveStepBackList参数说明：**

|参数名称 |参数类型 |参数名称 
|:----  |:-----  |:-----   
|id     |int     | 审批节点id 
|name   |string  | 审批节点名称


**返回结果**
（1）成功

* 返回数据格式：
```JSON
  {
      "data": {
          "approveStepBackList": [
              {
                  "name": "审批人-第一节点",
                  "id": "0"
              },
              {
                  "name": "审批人-不可回退",
                  "id": "1"
              },
              {
                  "name": "审批人-可回退默认",
                  "id": "2"
              }
          ],
          "approveBackConfig": -1
      },
      "success": true
  }
```

（2）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_FORM_USER_ID|未传 formUserId|
|APPROVE_NOT_EXIST|审批不存在|
|数据所在单位与用户填写单位不一致，请确认数据所在单位!|fid 与数据单位不一致|
|您所访问的应用正在升级中|审批升级中|
|获取审批流程配置失败|流程配置读取失败|
|审批流程数据不存在|流程数据缺失|
|获取当前审批节点失败|并行流程未传 nodeUniqueId|
|节点唯一标识指定节点不存在|nodeUniqueId 非法|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[datetime=xxx][fid=xxx][formId=xxx][formUserId=xxx][sign=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
