
**简要描述：**

- 自建审批加签转交接口说明

**请求URL：**
- https://office.chaoxing.com/api/approve/apps/status/turn/other

**请求方式：**
- POST请求

**参数说明：**

|参数名称              |是否必填|参数类型|参数名称               |参数说明|
|:----               |:----  |:----- |:-----               |-----   |
|datetime            |是      |string |生成加密串时间         | 格式：yyyyMMddHH|
|sign                |是      |string | 接口标识             | 由超星办公系统方提供|
|enc                 |是      |string | 接口参数加密串        |采用md5加密方式进行生成|
|fid                 |是      |int    | 单位ID              |单位fid|
|formId              |否      |int    | 表单ID    |表单ID,与formAlias任传一个|
|formAlias           |否      |string | 表单接口标识    |表单接口标识,与formId任传一个|
|uid                 |是      |int    | 用户ID              |用户passport id |
|countersignType     |否      |int    | 加签方式             |单人节点加签时需要传参  0：后加签 1：前加签 默认为0|
|approveWay          |否      |int    | 多人审批方式          |单人节点加签且添加多人时需要传参  1：或签 2：会签 3：依次审批 默认为2-会签 |
|operateType         |否      |int    | 审批操作类型          |0：加签 1：转交 默认值为0-加签 |
|approveUserList     |是      |string | 加签/转交用户         |格式：[{"t":5,"uid":232993016,"uname":"梁田田"},{"t":5,"uid":234113304,"uname":"梁亦涵"}] |
|approveVerify       |否      |boolean| 是否进行审批校验       |默认值为true(参与审批校验) |
|formUserId          |是      |int    | 审批数据id            |审批数据主键|
|signature           |否      |string | 手写签名图片地址       | |
|electronicSignature |否      |string | 电子签章图片地址       | |
|file                |否      |string | 审批意见文件          | 同附件字段value结构|
|picture             |否      |string | 审批意见图片          | 同图片字段value结构|
|opinion             |否      |string | 审批意见             | |
|formData            |否      |string | 修改的表单数据jsonArray数组    | 字段值数组[{字段值1},{字段值2}],需做utf8URL编码(不参与enc加密)|
|noticeUrl |否  |string |结果通知地址 |处理结果通知地址 |
|formAuthority |否  |string |表单权限配置 |字段权限配置 JSON，默认空 |
|nodeUniqueId |否  |string |节点唯一标识 |并行流程节点唯一标识 |
|autoHandle |否  |int |自动处理标记 |自动处理标记，不传按 0 处理 |
|autoTrigger |否  |int |触发触发器 |是否触发触发器，默认 1（1 触发 / 0 不触发） |

目前已支持基础字段,子表单,图片和文件上传等字段类型,定位、直播、计算公式、选择数据、说明文字、自动编号、关联审批、审批套件等暂不支持
图片/文件上传首先要将图片或文件通过云盘接口上传到云盘，上传后获取到图片信息比如objectId,name,size等。再调用本接口传入values数组即可
compt详细的取值请查阅 https://document.chaoxing.com/web/#/page/372


**返回结果**
（1）成功

* 返回数据格式：{"success":true}

（2）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_UID|未传 uid|
|MISSING_FORM_USER_ID|未传 formUserId|
|autoTrigger参数不合法|autoTrigger 不是 0/1|
|当前审批处理不存在|对应审批处理记录不存在|
|您所访问的应用正在升级中|审批升级中|
|参数错误|参数校验失败|
|[300]服务异常|服务层返回失败|
|APPROVE_NOT_EXIST|审批不存在|
|[500]|服务端异常|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[approveUserList=xxx][approveWay=xxx][countersignType=xxx][datetime=xxx][fid=xxx][formId=xxx][formUserId=xxx][operateType=xxx][opinion=xxx][sign=xxx][uid=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
