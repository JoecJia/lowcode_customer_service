
**简要描述：**

- 撤销审批记录接口

**请求URL：**
- http://office.chaoxing.com/api/approve/apps/status/revoke?fid=&uid=&formUserId=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
```
POST请求样例:
ContentType:application/x-www-form-urlencoded
Body数据:
fid=97253&uid=1&formUserId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705
```

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID |
|formId      |否    |int    | 表单ID    |表单ID,与formAlias任传一个|
|formAlias   |否    |string | 表单接口标识    |表单接口标识,与formId任传一个|
|uid   |是  |int | 用户uid  |用户uid
|formUserId |是 |int|数据行记录id |数据行记录id
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|aprvTypeId |否  |int |审批类型id |审批类型 id，默认 10000 |
|autoHandle |否  |int |自动处理标记 |自动处理标记，默认 0 |
|version |否  |string |版本号 |≥1.17.1 时强制 formId/formAlias 至少一个 |

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "success": true
}
```

（2）失败

* 返回数据样例:
```
{"msg":"缺少单位Id","success":false}
{"msg":"审批不存在","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_UID|未传 uid|
|MISSING_FORM_USER_ID|未传 formUserId|
|[3000]审批id和审批别名不能同时为空|formId 与 formAlias 均未传|
|[300]服务异常|服务层返回失败|
|当前审批处理不存在|对应审批处理记录不存在|
|您所访问的应用正在升级中|审批升级中|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021082717][fid=97253][formId=xxx][formUserId=1][sign=xxx][uid=1]";

```
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5） 结果地址
> http://office.chaoxing.com/api/approve/apps/status/revoke?fid=97253&uid=1&formUserId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
