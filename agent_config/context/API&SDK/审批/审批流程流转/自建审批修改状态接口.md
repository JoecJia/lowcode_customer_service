
**请求URL：**
- https://office.chaoxing.com/api/approve/apps/status/handle?approveStatusTypeId=&approveStatusType=&approveHandleType=&aprvId=&deptId=&datetime=&electronicSignature=&file=&opinion=&picture=&roleName=&sign=&signature=&uid=&enc=

- POST请求

**返回结果**
（1）成功

* 返回数据格式：{"success":true, "data":{"noticeIdList":[11,22,33]}}

（2）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少单位id信息|未传 deptId|
|缺少用户id信息|未传 uid|
|缺少审批状态信息|未传审批状态参数|
|autoSendData参数不合法|autoSendData 不是 0/1|
|autoTrigger参数不合法|autoTrigger 不是 0/1|
|无权限修改！|当前用户无该审批处理权限|
|当前审批处理不存在|aprvId 无对应待处理记录|
|您所访问的应用正在升级中|审批升级中|
|传递参数有误|参数校验失败|
|审批处理接口失败|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[approveStatusTypeId=xxx][approveStatusType=xxx][approveHandleType=xxx][aprvId=xxx][datetime=xxx][deptId=xxx][electronicSignature=xxx]
> [file=xxx][formId=xxx][opinion=xxx][picture=xxx][roleName=xxx][sign=xxx][signature=xxx][uid=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
