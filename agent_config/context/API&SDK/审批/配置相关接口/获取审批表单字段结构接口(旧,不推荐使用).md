###接口地址
* http://m.oa.chaoxing.com/api/approve/forms/app/config/values?deptId=&formId=&appName=&datetime=&sign=&enc=

**参数：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|deptId   |是  |int | 单位ID    |单位fid|
|formId   |否  |int | 表单ID    | 表单Id|
|appName   |否  |String | 表单接口标识    | 表单接口标识|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回参数说明：**

|参数名称|参数说明|
|:----  |:----
|compt   |字段类型名称 如"editinput"
|id   |字段id
|alias|字段别名
|label|字段标题名
|visible|字段是否可见
|editable|字段是否可编辑
|uploadConfig|图片，视频，附件字段的上传方式
|columnsNum参数说明|当表单设计-样式-字段布局，开启多列后，会返回columnsNum此参数，2表示开启了2列.开启多列后，配合layoutRatio(字段布局行占比参数)参数使用
|layoutRatio|当表单填写页开启多列后，返回字段的布局行占比参数。例如:columnsNum为2列,layoutRatio为1，代表此字段宽度为二分之一
|values|字段的值数据名称 例如:```"values":["val"]```
|field|字段信息 ```{"fieldType":{"type":"string"},"label":"姓名","values":[{"val":""}],"verify":{"format":{"type":""}}}```
|optionBindInfo|下拉类型组件的选项如果关联了表单信息,则返回此结构.```{"bindFieldId":1,"bindFieldIdx":0,"bindFormId":51034,"bindFormIdEnc":"3ed58ce9eed7b8f29de3c4fd07d63a8c","bindFormType":"customForm","isBinded":true,"originalOptions":[{"checked":false,"idArr":[],"score":0,"title":"选项1"},{"checked":false,"idArr":[],"score":0,"title":"选项2"},{"checked":false,"idArr":[],"score":0,"title":"选项3"}]}```
|linkInfo|如果字段有数据联动,则返回此结构. ```{"condFields":[{"currFormCondFieldId":6,"linkFormCondFieldCompt":"dateinput","linkFormCondFieldId":5}],"linkFormId":51000,"linkFormIdEnc":"f6ecbe36c25ca4ba87aa09cffd0464fb","linkFormType":"customForm","linkFormValueFieldCompt":"editinput","linkFormValueFieldId":1,"linked":true}```
|optionsLoadFromUrl|如果选项使用了"第三方获取",则返回此结构.```{"isLoadFromUrl":true,"response":[{"jpath":"123123213"}],"url":[{"ftype":"txt","label":"单行输入","type":"field","cid":"1"}],"urlHeaders":[{"name":"name","value":"111"}]}```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|单位id不能为空|未传 deptId|
|审批表单id和表单别名不能同时为空|formId 与 appName 均未传|
|审批表单不存在|formId / appName 定位不到审批|
|获取审批表单Values结构接口异常|服务端处理异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[appName=info][datetime=2020090916][deptId=1385][formId=1][sign=xxx]";
```
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5） 结果地址
> http://m.oa.chaoxing.com/api/approve/forms/app/config/values?appName=info&formId=1&datetime=2020090916&deptId=1385&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
