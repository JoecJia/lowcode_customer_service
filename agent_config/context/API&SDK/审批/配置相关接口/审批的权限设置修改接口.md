**简要描述：**

- 审批后台权限设置-角色数据权限/字段权限/功能权限的修改接口
其中此接口中支持的功能有：
	1. 数据权限：仅支持修改按筛选条件过滤的数据权限，不支持修改创建时设置为按角色管理范围显示的数据权限，不支持在筛选条件和角色管理范围两种类型之间切换修改，数据权限走覆盖修改逻辑，将旧配置整体替换为新传入的条件
	2. 字段权限：可以对字段的不可编辑，或者不可见做修改，仅修改传入的字段/按钮/功能，未传的保持原配置不变
	3. 功能权限：支持顶部按钮（包括导入、导出、分组 的二级按钮）、筛选字段、右侧按钮、其他按钮的开启或关闭进行修改
	4. 其它权限：支持查看数据日志（及子设置项）、查看数据详情的开启或关闭


**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/permission/config/edit

**请求方式：**
- GET

**返回结果**
（1）成功 

* 返回数据格式：
```json
  {
      "msg": "[200]请求成功",
      "success": true
  }
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]请求失败错误信息","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_UID|未传 uid|
|PARAMS_INVALID|参数校验失败|
|FIELD_ID_ALIAS_PERMISSIONS_NOT_EMPTY|字段权限参数为空|
|dataPermission不能为空|未传 dataPermissions|
|dataPermission结构不合法|dataPermissions 结构错误|
|APPROVE_NOT_EXIST|审批不存在|
|匹配失败，角色IDx不存在|roleIds 含不存在的角色|
|权限组id'x'在审批id'y'中不存在，添加失败|permissionGroupId 非法|
|OPERATION_FAILED|服务层操作失败|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
``` json
"[datetime=2020090916][fid=1385][fieldPermissions="字段配置"][formId=1][permissionType=0][roleIds=1,3][sign=xxx]";
```
          
（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
