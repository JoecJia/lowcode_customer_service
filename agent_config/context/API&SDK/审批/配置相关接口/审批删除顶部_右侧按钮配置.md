##### 简要描述

- 删除数据管理页顶部按钮
- 删除数据管理页右侧按钮
- 备注：
	- 系统按钮不允许删除
	- [系统按钮id字典](https://cxapi.chaoxing.com/web/#/p/cd5e9ed25b2b97c6ffe98c124ebb53c2)

##### 请求URL
- ` http://m.oa.chaoxing.com/api/approve/forms/operate/config/delete `
  
##### 请求方式
- POST 

##### 参数

| 参数名称     | 是否必填 | 参数类型   | 参数名称    | 参数说明               |
|:---------|:-----|:-------|:--------|---------------------|
| formId   | 是    | int    | 应用ID    | formId和formAlias同时为空 |
| formAlias| 是    | string | 应用别名  | formId和formAlias同时为空 |
| fid      | 是    | int    | 单位fid   ||
| uid      | 是    | int    | 操作人UID ||
| delTopOperateIds | 否    | string | 删除顶部按钮的id列表  | 多个id使用英文逗号分隔，例：1,2,3 |
| delRightOperateIds| 否   | string | 删除右侧按钮的id列表  | 多个id使用英文逗号分隔，例：1,2,3 |
| isReturnOperates  | 否    | boolean   | 成功是否返回按钮配置列表    | 默认false，为true返回的结果同：[查询接口返回值](https://cxapi.chaoxing.com/web/#/p/432d279c53e26862e330568779ba7f8f) |
| sign     | 是    | string | 接口标识    | 由超星办公系统方提供     |
| datetime | 是    | string | 生成加密串时间 | 格式：yyyyMMddHH       |
| enc      | 是    | string | 接口参数加密串 | 采用md5加密方式进行生成       |

### 请求结果
（1）接口调用成功

 **返回示例**
```
{
  "success": true,
  "msg": "[200]请求成功"
}
```
  
（2）接口调用失败

 **返回示例**
```
{
  "success":false,
  "msg":"错误信息"
}
```

**P1 · 加密参与参数：**

|项|说明|
|:---|:---|
|实际参与 enc 的参数|`uid`、`delTopOperateIds`、`delRightOperateIds`、`isReturnOperates` 全部参与；文档加密示例用“……”省略，照抄会导致 enc 不匹配（SDK 内部自动生成）|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|[3000]删除按钮id列表不能为空|delTopOperateIds 与 delRightOperateIds 均为空|
|delTopOperateIds存在错误按钮id|含不存在/不可删除的顶部按钮 id|
|不允许删除系统按钮:x|包含系统按钮 id|
|delRightOperateIds存在错误按钮id|含不存在/不可删除的右侧按钮 id|
|[500]|服务端异常|

###参数校验配置
（1）接口标识类型
> sign=appsFormsData__*

（2）加密秘钥
> key=xxx

（3）加密方式字符串
> source="[datetime=2019040818][fid=xxx][formAlias=xxx][formId=xxx][sign=xxx]……";

（4） MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
