**简要描述：**

- 审批后台权限设置-角色数据权限/字段权限的添加、删除接口

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/permission/config/save

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |是  |int | 表单ID  | 表单ID|
|uid   |是  |int | 操作人uid    |操作人uid|
|roleIds   |是  |string | 角色ID    |多个值，以英文状态下逗号隔开,例`"1,2,3"`|
|type |是  |int |操作类型   | 1:添加操作 2:删除操作|
|permissionType |否  |int |权限类型   | 默认0:数据权限 1:字段权限|
|fieldPermissions|否|string|字段权限json串 |当permissionType=1时必传(其中，若字段不传，则默认该字段是可编辑可见的；示例如下:```{"1":2,"2":2,"3":2,"10",1,"11",1}```，其中key为字段id;value中的1表示可见不可编辑，2:不可见不可编辑)，和fieldAliasPermissions参数互斥，只要填一个就行
|fieldAliasPermissions|否|string|字段权限json串 |当permissionType=1时必传(其中，若字段不传，则默认该字段是可编辑可见的；示例如下:```{"1":2,"2":2,"3":2,"10",1,"11",1}```，其中key为字段别名;value中的1表示可见不可编辑，2:不可见不可编辑)和fieldPermissions参数互斥，只要填一个就行
|topOperates |否  |string |功能权限里的顶部按钮   | permissionType为2时，可以对顶部按钮进行显示或者隐藏|```[{"operate":"add","status":false},{"operate":"import","status":false},{"operate":"2","status":false}]```实例的中含义为将 按钮add,import和自定义按钮id为2的按钮隐藏掉。operate参数可以为系统字段的名称比如add,或者自定义字段的id,如2
|rightOperates |否  |string |功能权限里的右侧按钮   | permissionType为2时，可以对右侧按钮进行显示或者隐藏|```[{"operate":"scan","status":false},{"operate":"2","status":false}]```实例的中含义为将 按钮scan和自定义按钮id为2的按钮隐藏掉。operate参数可以为系统字段的名称比如add,或者自定义字段的id,如2
|permissionGroupId |否  |int |权限组id   |传入此值后,roleIds角色的数据权限将放入此权限组下|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc |是  |string |加密串 |接口参数加密串，参与验签，必须传入 |
|formAlias |否  |string |审批别名 |可用审批别名替代 formId 定位 |


**返回结果**
（1）成功 

* 返回数据格式：
```json
  {
      "msg": "[200]请求成功",
      "success": true
  }
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]请求失败错误信息","success":false}
```

**补充参数取值：**

|参数|说明|
|:---|:---|
|permissionType|0 数据权限 / 1 字段权限 / 2 操作权限；其他值报 PARAMS_INVALID|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_ROLE_ID|未传 roleIds|
|MISSING_UID|未传 uid|
|PARAMS_INVALID|参数校验失败|
|FIELD_ID_ALIAS_PERMISSIONS_NOT_EMPTY|字段权限参数为空|
|APPROVE_NOT_EXIST|审批不存在|
|OPERATION_FAILED|服务层操作失败|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2020090916][fid=1385][formId=1][permissionType=0][roleIds=1,3][sign=xxx][type=1]";
```
          
（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
