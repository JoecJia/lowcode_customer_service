**简要描述：**

- 自建审批校验保存接口说明

**请求URL：**

- https://m.oa.chaoxing.com/api/approve/forms/approve/verify/config/save?fid=97253&formId=23491&datetime=2025122218&id=1&sign=approveData_test&enc=3d0cdfb5a482214f32d428768a467948&version=1766398619289

**请求方式：**

- POST请求

**参数说明：**

| 参数名称     | 是否必填 | 参数类型   | 参数名称     | 参数说明               |
|:---------|:-----|:-------|:---------|--------------------|
| fid      | 是    | int    | 单位ID     | 单位fid              |
| formId   | 是    | int    | 应用ID     | 应用ID               |
| id       | 否    | int    | 审批校验配置id | 不传该参数时，表示新增，否则表示修改 |
| uid      | 是    | long   | 用户uid    | 用户uid              |
| datetime | 是    | string | 生成加密串时间  | 格式：yyyyMMddHH      |
| sign     | 是    | string | 接口标识     | 由超星办公系统方提供         |
| enc      | 是    | string | 接口参数加密串  | 采用md5加密方式进行生成      |
|verifyConfigType |否  |int |校验配置类型 |审批校验配置类型，默认 2（第三方校验），传其他值报“审批校验配置类型错误” |

以下数据为审批校验信息，格式为json，需要放到requestBody中，具体结构如下：

```json
{
  "promptText": "测试第三方校验",
  "on": true,
  "choseBehaviourIdArr": [
    5,
    14
  ],
  "url": "http://www.xxx.com"
}
```

**审批校验信息参数说明：**

| 参数名称                | 是否必填 | 参数类型    | 参数名称 | 参数说明                                                                                                                 |
|:--------------------|:-----|:--------|:-----|----------------------------------------------------------------------------------------------------------------------|
| promptText          | 是    | string  | 校验名称 | 校验名称                                                                                                                 |
| on                  | 是    | boolean | 是否开启 | true-开启；false-关闭                                                                                                     |
| choseBehaviourIdArr | 是    | int[]   | 校验事件 | 1-开始处理；2-处理完成；3-同意；4-拒绝；5-加签；6-回退；7-打回修改；8-撤回流程总的审批；9-撤回已通过的审批；10-转交；11-保存；12-审批人打回修改后提交；13-发起人打回修改后提交；14-发起人退回修改后提交 |
| url                 | 是    | string  | 校验地址 | 第三方校验地址                                                                                                              |                                                                                                   |

**返回结果**
（1）成功

* 返回数据格式：

```json
{
  "msg": "保存审批校验配置成功",
  "success": true
}
```

（2）失败

* 返回数据格式：

```json
{
  "msg": "保存审批校验配置失败",
  "success": false
}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_FORM_ID|未传 formId|
|审批校验配置类型错误|verifyConfigType 不是 2|
|MISSING_UID|未传 uid|
|服务层失败|校验配置保存失败|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[datetime=xxx][fid=xxx][formId=xxx][id=xxx][sign=xxx][uid=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
