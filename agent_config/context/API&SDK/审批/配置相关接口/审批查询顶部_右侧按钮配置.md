##### 简要描述

- 查询数据管理页顶部按钮配置列表
- 查询数据管理页右侧按钮配置列表
- 备注：
	- [系统按钮id字典](https://cxapi.chaoxing.com/web/#/p/cd5e9ed25b2b97c6ffe98c124ebb53c2)

##### 请求URL
- ` http://m.oa.chaoxing.com/api/approve/forms/operate/config/get `
  
##### 请求方式
- POST 

##### 参数

| 参数名称     | 是否必填 | 参数类型   | 参数名称    | 参数说明               |
|:---------|:-----|:-------|:--------|---------------------|
| formId   | 是    | int    | 应用ID    | formId和formAlias同时为空 |
| formAlias| 是    | string | 应用别名  | formId和formAlias同时为空 |
| fid      | 是    | int    | 单位fid   ||
| uid      | 是    | int    | 操作人UID ||
| hasTopOperate | 否    | boolean | 是否返回顶部按钮列表  | 默认 false 不返回 |
| hasRightOperate| 否   | boolean | 是否返回右侧按钮列表  | 默认 false 不返回 |
| sign     | 是    | string | 接口标识    | 由超星办公系统方提供     |
| datetime | 是    | string | 生成加密串时间 | 格式：yyyyMMddHH       |
| enc      | 是    | string | 接口参数加密串 | 采用md5加密方式进行生成       |

**P1 · 返回键名修正：**

|实际返回|说明|
|:---|:---|
|data.rightOperates|右侧按钮配置；文档写单数 `rightOperate`，按文档取不到|
|data.topOperates|顶部按钮配置；`isReturnOperates=true` 时返回|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_FORM_ID|未传 formId|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|[300]服务异常|服务层返回失败|
|[500]|服务端异常|

###参数校验配置
（1）接口标识类型
> sign=appsFormsData__*

（2）加密秘钥
> key=xxx

（3）加密方式字符串
> source="[datetime=2019040818][fid=xxx][formAlias=xxx][formId=xxx][sign=xxx]……";

（4） MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
