**简要描述：**

- 审批数据权限接口：根据审批的数据权限配置，返回最终带有筛选值的筛选条件

**请求URL：**
- https://m.oa.chaoxing.com/api/approve/app/forms/data/permission/config/filter?fid=&formId=&formAlias=&uid=&state=&roleId=&permissionGroupId=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看，默认-1|
|formId   |否  |int | 审批ID    |审批id，与formAlias二选一|
|formAlias   |否  |string | 审批别名    |审批别名，与formId二选一|
|uid   |否  |long | 当前用户ID    |当前用户id，条件含"当前用户/当前用户部门"时必填|
|state   |否  |int | 当前审批使用单位    |单位字段筛选项使用|
|roleId   |是  |int | 角色ID    |角色id，不传则读取"其他"角色权限|
|permissionGroupId   |是  |int | 权限组ID    |权限组id，不传则读取默认权限组(id=1)|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc |是  |string |加密串 |接口参数加密串；参数表原缺此行，按表对接会因缺少 enc 失败（SDK 内部自动生成） |

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "msg": "[200]操作成功",
    "data": {
        "permissionFilter": "[{\"id\":1,\"compt\":\"editinput\",\"express\":\"===\",\"val\":\"test\"}]"
    },
    "success": true
}
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[3000]请求参数不合法","success":false}
```

**补充参数说明：**

|参数|说明|
|:---|:---|
|roleId / permissionGroupId|文档标“必填=是”，说明又写“不传读其他/默认”；实现默认 -1 可执行（SDK：未单列）|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|APPROVE_NOT_EXIST|审批不存在|
|[300]操作失败|服务层返回失败|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)**
（1）接口标识
> sign=XXX

（2）加密秘钥
> key=由超星办公系统方分配

（3）加密原文字符串
```
> source="[datetime={yyyyMMddHH}][fid={fid值}][sign=XXX]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） 结果地址
> https://m.oa.chaoxing.com/api/approve/app/forms/data/permission/config/filter?fid={fid值}&formId={formId值}&datetime={yyyyMMddHH}&sign=approveData&enc={enc值}


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]

（3）formId 与 formAlias 二选一，必须传其中一个

（4）当权限条件中包含"当前用户"或"当前用户部门"时，必须传入 uid 参数

（5）roleId 和 permissionGroupId 默认值为 -1，表示读取全部/其他角色权限或默认权限组
