## 接口地址
* http://m.oa.chaoxing.com/api/approve/forms/foreground/app/config/submit/limit/edit

## 接口标识类型
> sign=approveData_*

## 请求参数

| 参数名称 | 是否必填 | 参数类型 | 默认值 | 参数说明 |
|:---|:---|:---|:---|:---|
| fid | 是 | int | - | 单位fid |
| formId | 否 | int | - | 审批ID，与formAlias任传一个 |
| formAlias | 否 | string | - | 审批别名，与formId任传一个 |
| uid | 是 | long | - | 操作人UID |
| submitNum | 否 | int | - | 上限次数（兼作开关）：大于0为开启提交限制且该值即上限次数（后台"N次"输入框）；不传或小于等于0为关闭；开启时必传大于0 |
| submitOptionValue | 条件必填 | int | - | 计数周期类型 1/2/3/4/5/6 只能/每天/每周/每月/每年/自定义，开启时必传 |
| submitLimitType | 条件必填 | int | - | 限制类型 1/2 提交/被通过，开启时必传 |
| limitStartDate | 否 | string | - | 自定义周期开始日期，格式yyyy-MM-dd，仅submitOptionValue=6时生效；不传保留原配置；原配置也无日期时周期降级为"只能" |
| limitEndDate | 否 | string | - | 自定义周期结束日期，格式yyyy-MM-dd，仅submitOptionValue=6时生效；不传保留原配置 |
| sign | 是 | string | - | 接口标识，由超星办公系统方提供 |
| datetime | 是 | string | - | 生成加密串时间，格式：yyyyMMddHH |
| enc | 是 | string | - | 接口参数加密串，采用md5加密方式进行生成 |

## 后台管理页控件对应
审批高级设置中"用户提交限制"各控件与本接口参数的对应关系：

| 后台控件 | 对应参数 |
|:---|:---|
| "用户提交限制"开关 | 无独立参数：开启=submitNum大于0，关闭=submitNum不传或小于等于0 |
| 计数周期下拉（只能/每天/每周/每月/每年/自定义） | submitOptionValue（1-6） |
| 限制类型下拉（提交/被通过） | submitLimitType（1/2） |
| 上限次数输入框（N次） | submitNum（值即次数） |

## 参数规则
（1）提交限制开关由submitNum隐式表达：submitNum大于0为开启，不传或小于等于0为关闭，与后台管理页保存口径一致。
（2）关闭时仅上限次数置0，submitOptionValue、submitLimitType保留原值不变更；原配置已为关闭态（上限次数为0或为空）时，接口幂等返回配置未变更，不写库、不记录操作日志。
（3）submitOptionValue=6（自定义）且开始、结束日期都传时，开始时间必须早于结束时间，否则返回参数错误；日期落库时归一化为当天00:00:00与23:59:59；日期不传时保留原配置，仅当原配置也无日期（合并后双空）时周期降级为"只能"。
（4）审批提交限制按提交记录实时计数，配置修改后无需清除计数。

## 处理结果

### 成功
配置有变更、修改成功：
```json
{
  "success": true,
  "msg": "[200]修改成功"
}
```
配置未变更（各字段与原配置一致）时幂等返回成功，不写库、不记录操作日志：
```json
{
  "success": true,
  "msg": "[200]配置未变更,无需修改"
}
```

### 失败
参数校验不通过（示例：自定义周期开始时间不早于结束时间）：
```json
{"msg":"[3000]提交限制开始时间需小于提交限制结束时间","success":false}
```
落库未命中时：
```json
{"msg":"[300]修改失败","success":false}
```

### 返回码说明
| 返回码 | 含义 |
|:---|:---|
| [200] | 成功（含"修改成功"与"配置未变更,无需修改"两种文案） |
| [300] | 操作失败（落库未命中） |
| [3000] | 请求参数不合法（如周期类型越界、限制类型非1/2、上限次数非法、开始时间不早于结束时间、日期格式非yyyy-MM-dd等） |

## 测试关注点建议

1. **开关语义**：由 submitNum 隐式表达——大于0 开启，不传或小于等于0 关闭（无独立开关字段）。
2. **条件必填校验**：开启（submitNum>0）时 submitOptionValue + submitLimitType 必传；缺失或越界应返回 [3000]。submitLimitType 仅支持 1（提交）/ 2（被通过）。
3. **自定义周期（submitOptionValue=6）**：
   - 开始、结束都传 → 开始必须早于结束，否则 [3000]；落库归一化为 00:00:00 / 23:59:59。
   - 只传一侧 → 另一侧保留原配置。
   - 都不传 → 保留原配置；若原配置也无日期 → 周期降级为"只能"。
4. **关闭（submitNum 不传或≤0）**：仅上限次数置0，submitOptionValue、submitLimitType 保留原值；原配置已是关闭态（次数为0或空）时幂等返回"配置未变更"。
5. **幂等性**：重复提交相同配置 → 返回"配置未变更,无需修改"，不写库、不落操作日志。
6. **计数方式**：审批按提交记录实时计数，改配置后不清计数（与表单不同）。
7. **formId / formAlias**：二者任传一个定位审批。
8. **操作日志**：变更成功后应生成管理员操作日志（单条概要）。

## 加密说明

（1）加密秘钥
> key=xxx（由超星办公系统方提供）

（2）加密方式字符串
> source="[datetime=2019040818][fid=xxx][formId=xxx][sign=xxx]……";

（3）MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_UID|未传 uid|
|APPROVE_NOT_EXIST|审批不存在|
|审批配置不存在|审批配置缺失|
|[3000]submitNum仅支持整数|submitNum 非整数|
|[3000]submitOptionValue仅支持1-6|submitOptionValue 越界|
|[3000]submitLimitType仅支持1或2|submitLimitType 非法|
|[500]|服务端异常|

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合
* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合
* 例如：[a=1,2,3,4,5,6]
