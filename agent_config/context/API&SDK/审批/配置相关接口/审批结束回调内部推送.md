
**简要描述：**

- 可以对单位下审批应用增加第三方回调接口，当这些应用下的审批状态变为完成状态时，会对相应的回调地址进行调用

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/callback/add?fid=&datetime=&sign=&callback=&formIds=&enc=

**请求方式：**
- GET,POST
```
POST请求样例:
ContentType:application/x-www-form-urlencoded
Body数据:
fid=97253&datetime=2023101014&sign=XXX&callback=www.baidu.com&formIds=16130&enc=2fd943b60d218ad0b92c822ce2005c3e
```

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID |
|formIds   |是  |string | 表单ID     |格式：表单id字符串，多个之间以 , 拼接 |
|callback  |是  |string | 回调地址    |审批完成时调用的地址 |
|datetime |是  |string |生成加密串时间 | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识     | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回结果**
（1）成功

* 返回数据格式：
```json
{
  "msg": "[200]请求成功",
  "success": true
}
```

（2）失败

* 返回数据样例:
```
{
    "msg": "[100000]缺少单位id",
    "success": false
}
{
    "msg": "[100002]缺少表单id",
    "success": false
}
{
    "msg": "[300]enc参数验证失败",
    "success": false
}
```

**回调地址传递参数**
```
fid: 单位ID
formId: 审批应用ID
aprvId: 审批数据ID
aprvStatusTypeId: 审批状态ID
aprvStatusType: 审批状态
```

**补充行为说明：**

|项|说明|
|:---|:---|
|callback 重复配置|同一 `formId` 已有回调配置时直接返回成功（幂等），不报错（SDK：未单列）|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|[100000]|参数缺失/非法（服务层）|
|[100002]|配置写入失败（服务层）|
|[300]|服务层返回失败|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[callback=www.baidu.com][datetime=2023101014][fid=97253][formIds=16130][sign=XXX]";

```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） 结果地址
> http://m.oa.chaoxing.com/api/approve/forms/callback/add?fid=97253&datetime=2023101014&sign=XXX&callback=www.baidu.com&formIds=16130&enc=2fd943b60d218ad0b92c822ce2005c3e

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
