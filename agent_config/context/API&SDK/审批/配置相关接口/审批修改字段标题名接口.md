**简要描述：**

- 支持给审批字段修改标题名，如下图所示，可以修改'单行输入'字段的标题名
![](http://cxapi.chaoxing.com/server/index.php?s=/api/attachment/visitFile&sign=9d6ab811b5cf11a0562ded90251bc96a)
**注意：审批补卡套件，请假套件，外出套件，加班套件，说明文字字段，不支持修改字段标题名**

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/edit/field/label

**请求方式：**
- POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID    |高级设置页面可以查看  与formAlias参数至少要有一个有值|
|formAlias   |否  |string | 表单接口标识（表单别名）    |高级设置页面可以设置 与formId参数至少要有一个有值 |
|operatorUid   |是  |long | 操作人uid  | 注意：传此参数请求成功后，审批应用创建人会更换为operatorUid|
|fieldId   |否  |int | 字段id | 要删除的字段id,与字段别名任传一个即可|
|fieldAlias|否  |string | 字段别名 | 要删除的字段别名,与字段id任传一个即可|
|label |是 |string    |字段标题名|字段标题名|
|autoSendData|否 |int    |默认为1|1:可触发数据推送，0:不触发数据推送|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc |是  |string |加密串 |接口参数加密串；参数表原缺此行，按表对接会因缺少 enc 失败（SDK 内部自动生成） |

**返回结果**
（1）成功 

* 返回数据格式：
```json
  {
      "msg": "[200]请求成功",
      "success": true
  }
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]请求失败错误信息","success":false}
```

**补充加密说明：**

|项|说明|
|:---|:---|
|加密示例参数名|示例沿用 add/field 的 `fieldListStr`；本接口实际参与加密的是 `fieldId`/`fieldAlias`/`label`/`autoSendData`（SDK 内部自动生成 enc）|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_OPERATE_UID|未传 operatorUid|
|COMPT_ID_ALIAS_NOT_EMPTY|fieldId 与 fieldAlias 均未传|
|label不能为空|未传 label|
|APPROVE_NOT_EXIST|审批不存在|
|修改失败,字段不存在|fieldId / fieldAlias 无对应字段|
|修改失败,该字段不支持修改标题|字段类型不允许改标题|
|OPERATION_FAILED|服务层操作失败|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[autoSendData=][datetime=][fid=][fieldListStr=][formAlias=][formId=][operatorUid=][sign=]";
```

（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
