**简要描述：**

- 根据单位id,(表单id或表单别名)获取审批字段结构配置接口

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/struct/config

**请求方式：**
- GET

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID    |高级设置页面可以查看  与formAlias参数至少要有一个有值|
|formAlias   |否  |string | 表单接口标识（表单别名）    |高级设置页面可以设置 与formId参数至少要有一个有值 |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|msg|返回的提示信息|
|success|请求成功/失败|
|data|```{"columnsNum":2,"filedTab":[],"filedConfig":[],"bindOrganizationID":-1}```|
|data.fieldConfig |字段配置列表；文档表格原写 `filedConfig`，按原名取不到 |
|data.fieldTab |字段分组/页签配置；文档表格原写 `filedTab`，按原名取不到 |
|data.layoutInfo |布局信息，示例有、参数表未列 |
|data.conditionFilters |字段条件筛选配置 |
|data.bindRegionInfo |绑定的区域架构 |
|data.fieldVisibleConfig |字段可见配置，仅 `columnsNum > 1` 时返回 |
|data.fieldEditConfig |字段可编辑配置，仅 `columnsNum > 1` 时返回 |
|data.fieldRequiredConfig |字段必填配置，仅 `columnsNum > 1` 时返回 |
|data.fieldUniqueConfig |字段唯一配置，仅 `columnsNum > 1` 时返回 |

**columnsNum参数说明：**
当表单设计-样式-字段布局，开启多列后，会返回columnsNum此参数，2表示开启了2列.开启多列后，filedConfig字段配置参数会返回layoutRatio字段布局行占比参数.

**bindOrganizationID参数说明：**
返回当前表单绑定的组织架构id(-1:通讯录,0:默认架构; id大于0的为自建组织架构)

**filedTab参数说明：**

开启多标签显示后，会返回此参数。

|参数名称|参数说明|
|:----|:---- |
|fieldIds|多标签内的组件数据id集合 ``` "fieldIds": [3,4] ```
|title|多标签的标题名称

**filedConfig参数说明：**

|参数名称|参数说明|
|:----  |:----
|compt   |字段类型名称 如```"editinput"``` compt详细的取值请查阅 [表单字段类型字典数据](https://cxapi.chaoxing.com/web/#/653656579/207985741 "123213")
|id   |字段id 
|alias|字段别名
|label|子表单、矩阵字段标题名
|layoutRatio|当表单填写页开启多列后，返回字段的布局行占比参数。例如:columnsNum为2列,layoutRatio为1，代表此字段宽度为二分之一.
|fields|字段信息 ```{"fieldType":{"type":"string"},"label":"姓名","values":[{"val":""}],"verify":{"format":{"type":""}}}```
|optionBindInfo|下拉类型组件的选项如果关联了表单信息,则返回此结构.```{"bindFieldId":1,"bindFieldIdx":0,"bindFormId":51034,"bindFormIdEnc":"3ed58ce9eed7b8f29de3c4fd07d63a8c","bindFormType":"customForm","isBinded":true,"originalOptions":[{"checked":false,"idArr":[],"score":0,"title":"选项1"},{"checked":false,"idArr":[],"score":0,"title":"选项2"},{"checked":false,"idArr":[],"score":0,"title":"选项3"}]}```
|linkInfo|如果字段有数据联动,则返回此结构. ```{"condFields":[{"currFormCondFieldId":6,"linkFormCondFieldCompt":"dateinput","linkFormCondFieldId":5}],"linkFormId":51000,"linkFormIdEnc":"f6ecbe36c25ca4ba87aa09cffd0464fb","linkFormType":"customForm","linkFormValueFieldCompt":"editinput","linkFormValueFieldId":1,"linked":true}```
|optionsLoadFromUrl|如果选项使用了"第三方获取",则返回此结构.```{"isLoadFromUrl":true,"response":[{"jpath":"123123213"}],"url":[{"ftype":"txt","label":"单行输入","type":"field","cid":"1"}],"urlHeaders":[{"name":"name","value":"111"}]}```
|relationValueConfig|联系人/所属人组件使用 默认值从表单内字段关联获取.```{"condFieldId": 0, //关联的字段id "type": 0, //关联类型 0/1 学号/手机号 "open": false //是否开启默认值从表单内字段关联获取},```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|APPROVE_NOT_EXIST|formId / formAlias 定位不到审批|
|[500]|服务端异常|
|鉴权失败|签名/enc 或单位校验不通过|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2020090916][fid=1385][formAlias=info][formId=1][sign=xxx]";
```
          
（4） MD5加密操作
> enc=md5(source+[key]);
enc的获取:可使用此链接进行md5加密测试，取其32位小写https://md5jiami.bmcx.com/
          
（5） 结果地址
> http://m.oa.chaoxing.com/api/approve/forms/struct/config?formAlias=info&formId=1&datetime=2020090916&fid=1385&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
