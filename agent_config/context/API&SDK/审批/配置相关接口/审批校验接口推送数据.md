
传递的参数: 

(系统字段) 审批应用id、单位fid、发起人uid、操作时间、审批人uid、审批节点名称（包括级别）、操作名称（操作按钮名字）、

(表单字段)  所有字段的值都推送给第三方




填写一个校验url ，   参数以post方式传递

返回值要求： 必须要有2个参数   result(校验结果): YES\NO    message(校验结果描述，一般result为NO时，审批需要把message的内容弹出来， 如果message为空，审批弹出默认提示“第三方校验失败”)

{
    "result":"YES",
    "message":""
}





{
    "result":"NO",
    "message":"提交数量达到上限了"
}
