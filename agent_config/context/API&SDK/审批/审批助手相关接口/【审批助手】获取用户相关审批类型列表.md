
**请求URL：**
- ` http://m.oa.chaoxing.com/api/approve/forms/user/approve/type/list?fid=&formIds=&queryType=&uid=&datetime=&sign=&enc=`

**请求方式：**
- GET/POST

**参数：**

|参数名     |必选 |类型|说明|
|:----     |:---|:----- |-----   |
|uid       |是  |string | 用户ID   |
|fid       |否  |string | 单位id，多个以英文逗号分隔   |
|formIds   |否  |string | 应用formId，多个以英文逗号分隔   |
|queryType |否  |string | 查询列表类型（1:待审批列表，2:我已处理列表，3:抄送我的列表）默认查询待审批列表   |
|datetime  |是  |string | 生成加密串时间， 格式：yyyyMMddHH  |
|sign      |是  |string | 接口标识 ， 由超星办公系统方提供    |
|enc       |是  |string | 接口参数加密串，采用md5加密方式进行生成    |

**结果参数说明：**

|参数名     |类型|说明|
|:----     |:----- |-----   |
|formId    |int    | 审批应用id|
|aprvType  |string | 审批应用标题|

 **返回示例**
- 成功
返回数据格式
```
 {
     "data": {
         "approveTypeList": [
             {
                 "aprvType": "请假套件测试",
                 "formId": 15192
             },
             {
                 "aprvType": "发起人权限测试",
                 "formId": 15608
             }
         ]
     },
     "success": true
 }
```
- 失败
返回数据格式：{"msg": "[100001]缺少用户id","success": false}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|[100001]缺少用户id|未传 uid|
|获取用户所有审批类型接口异常|服务端处理异常|

###接口参数配置
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串(未传参的参数不参与加密)
> source="[datetime=xxx][fid=xxx][formIds=xxx][queryType=xxx][uid=xxx][sign=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

（5） 结果地址
> http://m.oa.chaoxing.com/api/approve/forms/user/approve/type/list?fid=&formIds=&queryType=&uid=&datetime=&sign=&enc=


### 注意事项
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
