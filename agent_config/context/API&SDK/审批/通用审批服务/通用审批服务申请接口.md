
**简要描述：**

- 学习通智能审批通用审批服务申请接口说明

**请求URL：**
- https://office.chaoxing.com/api/approve/apps/sustain/apply?deptId=&uid=&forms=&aprvUserJson=&ccUserJson=&identity=&datetime=&sign=&enc=

**请求方式：**
- POST请求

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|deptId   |是  |int | 单位ID    |单位fid|
|uid   |是  |int | 用户ID    |用户passport id |
|aprvUserJson   |是  |string | 审批人员列表json数据 |默认值为[]|
|turnToOthers   |否  |int | 转他人审批    |默认值为0（0不显示，1显示） |
|aprvTitle   |否  |string | 自定义审批标题 |用于在通知标题和审批详情页中显示，不传则显示“审批”|
|ccUserJson   |否  |string | 抄送人员列表json数据 |没有抄送人则空|
|identity   |是  |string | 第三方记录的唯一标识    |即审批后要更改记录的id |
|forms   |是  |string | 提交表单列表json数据 |默认值为[]|
|nonCancelable   |否  |int | 是否不可撤销    |0可撤销 1不可撤销 |
|aprvSummary   |否  |string | 自定义审批摘要，不传则按表单字段默认生成    |结构：[{"key":"字段名","value":"字段值"}] |
|hideIcon |否  |boolean |是否隐藏图标 |是否显示默认头像：true 显示默认头像，false（默认）显示真实头像 |

**aprvUserJson （审批人员）参数提交数据结构：**
```

[
    {
        "t":1,
        "way": 1,
        "users":[
            {"uid":21482682,"uname":"xxx"},{"uid":21482682,"uname":"xxx"}
        ]
    }, 
    {
        "t":1,
        "way": 1,
        "users":[
            {"uid":21482682,"uname":"xxx"},{"uid":21482682,"uname":"xxx"}
        ]
    }, 
    {
        "t":3,
        "way": 1,
        "roleList":[{"id":3481,"roleName":"999"},{"id":13,"roleName":"66"}]
    }
]

```
 //t值为1是指定人员，uid为用户passportId；t值为3时是指定角色，传roleList即可，id是角色ID，roleName是角色名称。way为审批类型,1:或签,2:会签 多人节点必传

**ccUserJson （抄送人员）参数提交数据结构：**
[{"t":1,"users":[{"uid":21482682,"uname":"xxx"}]}] //t值固定为1，uid为用户passportId

**返回结果**
（1）成功

* 返回数据格式：{"success":true, "data":{"aprvId":23,"aprvStatusTypeId":1,"detailLink":"https://office.chaoxing.com//front/approve/apps/sustain/detail/approve?id=23"}}

（2）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少单位id信息|未传 deptId|
|缺少用户id信息|未传 uid|
|缺少提交参数|必填参数缺失或参数结构不完整|
|审批人数据格式有误|aprvUserJson 非法 JSON / 结构错误|
|抄送人数据格式有误|ccUserJson 非法 JSON / 结构错误|
|提交表单信息有误|forms 非法 JSON / 结构错误|
|forms参数结构错误|forms 字段结构不合法|
|无法获取用户信息|uid 对应用户不存在|
|审批申请异常|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=sustainApply_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[aprvUserJson=xxx][ccUserJson=xxx][datetime=2018082819][deptId=1385][forms=xxx][identity=xxx][sign=officeApp][turnToOthers=0][uid=21482682]";

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> https://office.chaoxing.com/api/approve/apps/sustain/apply?deptId=1385&uid=21482682&forms=xxx&aprvUserJson=xxx&ccUserJson=xxx&identity=xxx&datetime=2018082819&sign=officeApp&enc=c6e7a12fc14784df87e71e3701c0f37c

**注意事项**
（1）目前可支持的数据类型包括：长整型（long）、double类型、字符串类型（string）、上传图片（img）、上传附件（file）

（2）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（3）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]


**第三方回调接口参数说明**
deptid 当前审批单位ID
uid 当前审批发起人uid
datetime 当前时间,格式为yyyyMMddHH
aprvUid 审批人uid
approveStatusTypeId 审批状态值 已删除:-3,已撤销:-2,已拒绝:-1,待处理:1,已通过:2
approveStatusType 审批状态名称
identity 业务ID(第三方传递的主键)
sign 配置的sign(无需关注)
enc 加密串(无需关注)
