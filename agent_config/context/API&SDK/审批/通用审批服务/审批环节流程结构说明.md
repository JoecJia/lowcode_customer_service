
-  结构实例  （数组顺序代表着审批流顺序）
```json
"aprvUsers":[
	{
		"way":1,
		"users":[{"uid":112321,"uname":"张三"}]
	},
	{
		"way":1,
		"users":[{"uid":112321,"uname":"张三"},{"uid":112341,"uname":"李四"}]
		}
	},
	{
		"way":2,
		"users":[{"uid":112321,"uname":"张三"},{"uid":112341,"uname":"李四"}]
	}
]
```

    
-  审批环节流程结构说明

|字段|类型|注释|
|:----    |:-------   |------      |
| way     |int    |多人审批时，审批方式。 1-或签  2-会签 |
| users   |array    |当前审批环节的审批人列表 |

- 备注：无
