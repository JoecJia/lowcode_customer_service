
**简要描述：**

- 学习通智能审批通用审批服务获取审批状态接口说明

**请求URL：**
* https://office.chaoxing.com/api/approve/apps/sustain/status?aprvId=&datetime=&sign=&enc=

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|aprvId   |是  |int | 审批id    |申请接口返回的审批服务id |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回结果**
（1）成功

* 返回数据格式：
```
        {
             "data": {
                 "sustainAprv": {
                     "aprvStatusType": "已拒绝",
                     "aprvStatusTypeId": -1,
                     "aprvTitle": "XXX",
                     "deptId": 1385,
                     "forms": "[{\"data\":{\"type\":\"string\",\"values\":[{\"val\":\"XXX\"}]},\"label\":\"审批详情\"}]",
                     "id": 606,
                     "identity": "1",
                     "inserttime": 1567067164000,
                     "signKey": "officeApp",
                     "turnToOthers": 0,
                     "uid": 93544868,
                     "uname": "超星办公",
                     "updatetime": 1567067309000
                 }
             },
             "success": true
         }
```

（2）失败

* 返回数据格式：
```
{"success":false, "msg":"xxx"}
```

**补充返回字段：**

|字段|说明|
|:---|:---|
|data.aprvOpinions|审批意见列表，与 `sustainAprv` 同时返回|
|data.sustainAprv.signKey|内部签名标识，属敏感字段，建议脱敏后再对外输出|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少审批id信息|未传 aprvId|
|审批不存在|aprvId 无对应审批|
|审批sign不匹配|请求 sign 与审批 signKey 不一致|
|获取审批状态异常|服务端处理异常|

> `sign` 会与 `sustainAprv.signKey` 比对，换 sign 查询会返回 `审批sign不匹配`。

**接口参数配置**
（1）接口标识
> sign=sustainApply_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[aprvId=1][datetime=2018082819][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> https://office.chaoxing.com/api/approve/apps/sustain/status?aprvId=1&datetime=2018082819&sign=xxx&enc=e92c0243f8b0bf3aa9d7a7b590c8427d

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
