

**请求URL：**
- https://office.chaoxing.com/api/approve/apps/sustain/approve

**请求方式：**
- POST请求

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|aprvTypeId   |是  |int | 审批类型ID    |传11即可 |
|aprvUserUid   |是  |int | 审批人UID    |用户passport id |
|aprvId   |是  |int | 审批数据id |审批数据主键|
|aprvStatusTypeId   |是  |int | 审批状态码 |同意：2，拒绝：-1|
|file   |否  |string | 审批意见文件    | |
|picture   |否  |string | 审批意见图片    | |
|opinion   |否  |string | 审批意见    | |
|formId |否  |long |表单id |拖拽表单审批对应的表单 id，`>=10001` 生效 |
|aprvAppId |否  |long |审批应用id |审批应用 id，默认 0 |
|userNames |否  |string |转他人姓名 |仅 aprvStatusTypeId 为转他人时生效，用于生成“转他人”状态文案，默认空 |


**返回结果**
（1）成功

* 返回数据格式：{"success":true, "data":{"noticeIdList":[11,22,33]}}

（2）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**补充参数取值：**

|参数|说明|
|:---|:---|
|aprvStatusTypeId=转他人|文档只写“同意 2 / 拒绝 -1”，实现还支持“转他人”状态|

**补充返回字段：**

|字段|说明|
|:---|:---|
|data.noticeIdAndUuidList|通知 id 与 uuid 列表，文档未列|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少审批id信息|未传 aprvId|
|审批不存在|aprvId 无对应审批|
|审批sign不匹配|请求 sign 与审批 signKey 不一致|
|formId参数有误|formId 非法|
|通用修改审批状态API接口异常|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=sustainApply_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[aprvStatusTypeId=xxx][aprvUserUid=xxx][aprvTypeId=xxx][aprvId=xxx][datetime=xxx]
> [file=xxx][opinion=xxx][picture=xxx][sign=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
