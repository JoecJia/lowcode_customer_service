
**请求URL：**
* https://office.chaoxing.com/api/approve/apps/sustain/detail/url?datetime=&sign=&aprvId=&enc=

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|aprvId   |是  |int | 审批id    |申请接口返回的审批服务id |

**返回结果**
（1）成功

* 返回数据格式：
```
        {
            "data": {
                "detailUrl": "http://office.chaoxing.com/front/approve/apps/sustain/detail/approve?id=8958&pageEnc=d36fd6737ed30ab1709e6d71d5e41c53"
            },
            "success": true
        }
```

（2）失败

* 返回数据格式：{"success":false, "msg":"xxx"}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少审批id信息|未传 aprvId|
|审批不存在|aprvId 无对应审批|
|获取审批详情页地址接口异常|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=sustainApply_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[aprvId=1][datetime=2018082819][sign=xxx]";

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> https://office.chaoxing.com/api/approve/apps/sustain/detail/url?datetime=2022071819&sign=xxx&aprvId=8958&enc=97c79925176c111bc551099b6403756c

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
