
**简要描述：**

- 学习通智能审批通用审批服务撤销接口说明

**请求URL：**
- https://office.chaoxing.com/api/approve/apps/sustain/cancel?deptId=&uid=&aprvId=&datetime=&sign=&enc=

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|deptId   |是  |int | 单位ID    |单位fid|
|uid   |是  |int | 用户ID    |用户passport id |
|aprvId   |是  |int | 审批id    |申请接口返回的审批服务id |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|


**返回结果**
（1）成功

* 返回数据格式：
```
{"success":true}
```

（2）失败

* 返回数据格式：
```
{"success":false, "msg":"xxx"}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少单位id信息|未传 deptId|
|缺少用户id信息|未传 uid|
|缺少审批id信息|未传 aprvId|
|该审批禁止撤销|审批 nonCancelable=1|
|审批撤销异常|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=sustainApply_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[aprvId=1][datetime=2018082819][deptId=1385][sign=officeApp][uid=21482682]";
```
（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
 https://office.chaoxing.com/api/approve/apps/sustain/cancel?deptId=1385&uid=21482682&aprvId=1&datetime=2018082819&sign=officeApp&enc=e92c0243f8b0bf3aa9d7a7b590c8427d

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
