**简要描述：**

- 审批的分组汇总统计接口（支持对审批数据按字段进行分组聚合统计）

**请求URL：**

- http://m.oa.chaoxing.com/api/approve/forms/group/summary/statistics?fid=&formId=&statsFieldId=&statsType=&groupFieldId=&datetime=&sign=&enc=

**请求方式：**

- GET,POST均可

**参数说明：**

|参数名称| 是否必填 | 参数类型   | 参数名称     | 参数说明                                                        |
|:----    |:-----|:-------|:---------|-------------------------------------------------------------|
|datetime | 是    | string | 生成加密串时间  | 格式：yyyyMMddHH                                               |
|sign     | 是    | string | 接口标识     | 由超星办公系统方提供                                                  |
|enc      | 是    | string | 接口参数加密串  | 采用md5加密方式进行生成                                               |
|fid      | 是    | int    | 单位ID     | 单位fid                                                       |
|formId   | 否    | int    | 表单ID     | 与formAlias任传一个                                              |
|formAlias| 否    | string | 表单别名     | 与formId任传一个                                                 |
|statsFieldId | 是 | int   | 统计字段ID   | 需要进行统计的表单字段ID                                               |
|statsType| 否    | string | 统计类型     | count(计次)、sum(求和)、avg(平均值)、max(最大值)、min(最小值)，默认count       |
|groupFieldId | 否 | int   | 分组字段ID   | >0为表单字段ID；<0为系统字段ID（见下方说明）；不传则不分组，返回整体统计结果                  |
|subIndex | 否    | int    | 日期区间子索引  | 日期区间字段使用，值可以为0(开始时间)、1(结束时间)、2(时长)，默认0                      |
|searchStr| 否    | string | 字段查询条件   | JSON格式的数据过滤条件，不参与加密                                         |

searchStr不参与加密

**groupFieldId系统字段说明（groupFieldId < 0）：**

|groupFieldId| 系统字段名称   | 说明           |
|:-----------|:---------|--------------|
|-1          | 提交人      | 按提交人uid分组    |
|-6          | 审批状态     | 按审批状态分组      |
|-8          | 当前审批人    | 按当前审批人uid分组  |
|-9          | 审批人列表    | 按审批人uid分组    |
|-10         | 抄送人列表    | 按抄送人uid分组    |
|-17         | 实际审批人    | 按实际审批人uid分组  |
|-22         | 当前审批节点   | 按当前审批节点名称分组  |
|-28         | 当前审批节点状态 | 按当前审批节点状态分组  |

**statsType说明：**

- 数字类型字段（numberinput、computeinput、slider、rate）支持 count、sum、avg、max、min
- 非数字类型字段仅支持 count（即使传入其他类型也会自动降级为count）

**searchStr格式说明：**

```json
{
  "model": 0,
  "filters": [
    {
      "id": 1,
      "compt": "editinput",
      "type": "eq",
      "value": "条件值"
    }
  ]
}
```

**返回结果**
（1）成功（有分组字段）

* 返回数据格式：

```json
{
  "msg": "[200]操作成功",
  "data": {
    "resultMap": {
      "分组值1": {"value": 100.0},
      "分组值2": {"value": 200.0}
    }
  },
  "success": true
}
```

resultMap中key为分组字段的值，value中的value为统计结果数值

（2）成功（无分组字段）

* 返回数据格式：

```json
{
  "msg": "[200]操作成功",
  "data": {
    "resultMap": {
      "totalStcs1": {"value": 300.0}
    }
  },
  "success": true
}
```

resultMap中key格式为 totalStcs{statsFieldId}，日期区间/套件类字段为 totalStcs{statsFieldId}_{subIndex}

（3）失败

* 返回数据格式：

```json
{"msg": "[300]缺少fid参数", "success": false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_STATS_FIELD_ID|未传 statsFieldId|
|PARAMS_INVALID|statsType / subIndex / groupFieldId / searchStr 非法|
|APPROVE_NOT_EXIST|审批不存在|
|[300]服务异常|服务层返回失败|
|[500]|服务端异常|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx 由超星办公系统方分配

（2）加密秘钥
> key=xxx 由超星办公系统方分配

（3）加密原文字符串
> source="[datetime=2020092718][fid=1385][formId=10021][groupFieldId=-1][sign=approveData_xxx][statsFieldId=5][statsType=sum][subIndex=0]";

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/approve/forms/group/summary/statistics?fid=1385&formId=10021&statsFieldId=5&statsType=sum&groupFieldId=-1&subIndex=0&datetime=2020092718&sign=approveData_xxx&enc=xxx

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]

（3）searchStr参数不参与enc加密计算

（4）formId和formAlias任传一个即可定位审批应用，若两个都传则以formId为准

（5）groupFieldId不传或传0时不进行分组，返回整体统计结果；传负数时使用系统字段分组；传正数时使用表单自定义字段分组
