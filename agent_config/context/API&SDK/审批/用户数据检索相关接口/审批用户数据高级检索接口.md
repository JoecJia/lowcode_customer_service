

**简要描述：**

- 支持多字段设置查询条件，组合查询表单数据。并且支持多条件之间是或还是且的关系进行查询。
  支持多种逻辑关系，比如数字支持等于、不等于、大于、小于等关系，详情参见下面的说明。

**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/advanced/search/list?formId=&aprvStatus=&orderType=&datetime=&uids=&cpage=&deptId=&sign=&pageSize=&fromInsertTime=&toInsertTime=&fromFinishTime=&toFinishTime=&enc=&searchStr=

**请求方式：**
- POST

**参数说明：**

|参数名|必选|类型|详细说明|
|:----    |:---|:----- |-------   |
|deptId     |是  |int | 单位ID    |
|formId     |否  |int | 表单ID,与formAlias任传一个   |
|formAlias  |否  |int | 表单接口标识,与formId任传一个    |
|aprvStatus  |否  |int |审批状态 0-待审批，1-已同意，2-已拒绝，3-已撤销| 
|searchStr     |否  |string | 查询筛选条件,不参与加密,json格式，格式参加下文   |
|returnFields |否  |string | 指定需要返回的表单字段 比如需要返回组件别名为name的字段和子表单下组件别名为name1的字段格式为:```[{"alias":"name"},{"alias":"detailbox","subFields":[{"alias":"name1"}]}]```|
|uids     |否  |string | 要参与检索的用户uid串，格式：uid1,uid2,uid3 。加密时不用urlcode（utf-8）编码, 访问时进行一次urlcode（utf-8）编码    |
|approveUsers |否  |string | 要参与检索的审批人uid串，格式：uid1,uid2,uid3 。加密时不用urlcode（utf-8）编码, 访问时进行一次urlcode（utf-8）编码|
|ccUsers |否  |string | 要参与检索的抄送人uid串，格式：uid1,uid2,uid3 。加密时不用urlcode（utf-8）编码, 访问时进行一次urlcode（utf-8）编码|
|cpage     |否  |int | 当前页码  ，从1开始。（默认1）|
|pageSize     |否  |int | 分页大小   （默认10）最大值：100  |
|orderType     |否  |string | 排序类型， 按照表单用户填写时间排序（desc降序，asc升序，默认desc）  |
|fromInsertTime     |否  |string | 审批发起开始时间 参数格式 yyyy-MM-dd |
|toInsertTime     |否  |string | 审批发起结束时间 参数格式 yyyy-MM-dd  |
|fromFinishTime     |否  |string | 审批完成开始时间 参数格式 yyyy-MM-dd |
|toFinishTime     |否  |string | 审批完成结束时间 参数格式 yyyy-MM-dd  |
|flowDetailShow     |否  |int | 传1时展示流程详情数据，不传或者传其他值不返回流程详情|
|datetime |是  |string |生成加密串时间，格式：yyyyMMddHH  |
|sign |是  |string | 接口标识 ，由超星办公系统方提供   |
|enc     |是  |string | 接口参数加密串  ，具体加密方式参见文章最下面的ecn加密说明  |
|onlyReturnCount |否 |int |传 1 时只返回总数 data.totalRow，不返回列表 |
|orderBy |否 |string |排序字段，默认 inserttime；仅支持数字/日期字段，多个以逗号分隔，配合 orderType 使用 |


**searchStr参数格式：**

|参数名|类型|说明|
|:----    |:---|-----   |
|model |数字  |或且标记， 0-且， 1-或   |
|filters  |数组  |数组里的每一项都是一个字段的查询条件，具体格式如下 |

**filters参数格式：**

|  参数名 | 类型   | 说明  |
| ------------ | ------------ | ------------ |
| id  | 数字  | 字段id， id可通过”获取表单结构“接口的返回值拿到 ；针对系统字段， 提交人： id固定为-1；提交时间: id固定为-3; 更新时间: id固定为-4 |
| alias|字符串| 字段别名|
| compt  | 字符串  | 字段类型标识， 标识可通过”获取表单结构“接口的返回值拿到。 针对系统字段，提交人固定为contact； 提交时间和更新时间固定为dateinput   |
| express  | 字符串  | 查询条件的关系标识， 不同类型的字段支持不同的查询关系。取值说明如下  |
| val  | 字符串  | 查询关键词 |
| range | 数组  | 当express等于><时使用该参数，针对数字字段和日期字段，可以使用该参数设置查询的范围。  |

**express取值说明：**

|  关系标识 |  说明  | 可以使用的字段类型 |
| -------- | ------------ |------------ |
| === | 等于 |所有字段|
| !== | 不等于 |所有字段|
| null  | 为空(改字段没有值) |所有字段|
| notNull  | 不等于 |所有字段|
| like  | 包含 |除数字类型字段和日期类型字段外的所有字段|
| notLike  | 不包含 |除数字类型字段和日期类型字段外的所有字段|
| > | 大于 |数字类型字段和日期类型字段|
| >= | 大于等于 |数字类型字段和日期类型字段|
|< | 小于 |数字类型字段和日期类型字段|
| <= | 小于等于 |数字类型字段和日期类型字段|
| >< | 选择范围 |数字类型字段和日期类型字段，如果express设置了><, 那么range不能为空。|
| match  | 等于任意一个 |单选，多选，联系人，部门字段|
|notMatch  | 不等于任意一个 |单选，多选，联系人，部门字段|
| allMatch  | 同时包含 |单选，多选，联系人，部门字段|

**其它说明**

> express = '><' 时  range:


 ```
[{
		"express": ">=",
		"val": "1"
	},
	{
		"express": "<=",
		"val": "10"
	}
]

```

>另外 昨日、今日、本周、本月、本年这样的日期范围也用range形式表达

**返回结果**
（1）成功

* 返回数据格式：
```
{"totalRow": "总条数","totalPage": "总页数","dataList": "数据结果集","success": true}
```

（2）失败

* 返回数据格式：{"msg":"失败信息","success":false}

**P1 · 返回键名修正（onlyReturnCount=1）：**

|实际返回|说明|
|:---|:---|
|MySQL/PostgreSQL 分支 `data.totalRow`|只返回总数|
|ES 分支 `data.total`|只返回总数|
|文档旧写的 `data.totalCount`|实际不存在，按旧文档取不到总数|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|请求参数不合法|分页参数（cpage/pageSize）非法|
|审批不存在|formId / formAlias 定位不到审批|
|searchStr格式错误|searchStr 非合法 JSON 或字段不存在|
|查询超出范围|检索范围超出限制|
|获取审批用户记录异常|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxxxxxxx

（3）加密原文字符串
```
> source="[cpage=1][datetime=2020080808][deptId=73566][formId=8][orderType=desc][pageSize=8][uids=1,2,3][sign=xxx]"
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） 结果地址
> http://m.oa.chaoxing.com/api/approve/forms/advanced/search/list?formId=8&aprvStatus=&orderType=desc&datetime=2020080808&uids=1%2C2%2C3&cpage=1&deptId=73566&sign=xxx&pageSize=8&fromInsertTime=&toInsertTime=&fromFinishTime=&toFinishTime=&enc=5c3dc065952cf1856f91064ec9a6cf0c

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
