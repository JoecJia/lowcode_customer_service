**请求URL：**

*   `http://office.chaoxing.com/api/approve/apps/forms/data/expose/find/user/electronic/signature?uid=&fid=&name=&explain=&cpage=&pageSize=datetime=&sign=&enc=`

**请求方式：**

*   GET/POST

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| uid | 是 | long | 用户ID |
| fid | 是 | int | 单位id |
| formId | 否 | int | 审批表单id 根据该审批绑定的组织架构查询签章 |
| name | 否 | string | 印章名称关键字 |
| explain | 否 | string | 印章说明关键字 |
| cpage | 否 | int | 当前页码 ，从1开始。（默认1） |
| pageSize | 否 | int | 分页大小 （默认10）最大值：100 |
| datetime | 是 | string | 生成加密串时间， 格式：yyyyMMddHH |
| sign | 是 | string | 接口标识 ， 由超星办公系统方提供 |
| enc | 是 | string | 接口参数加密串，采用md5加密方式进行生成 |

**响应结果参数说明：**

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| sealName | string | 印章名称 |
| formUserId | long | 数据id |
| sealDescription | string | 印章说明 |
| sealImage | string | 印章图片信息 |

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|单位id不能为空|未传 fid|
|用户id不能为空|未传 uid|
|参数校验失败|分页或表单参数不合法|
|服务层失败|电子印章查询失败|

### 接口参数配置

（1）接口标识

> sign=xxx

（2）加密秘钥

> key=xxx

（3）加密原文字符串(未传参的参数不参与加密) 字典顺序

> source=[cpage=xxx][datetime=xxx][explain=xxx][fid=xxx][formId=xxx][name=xxx][pageSize=xxx][sign=xxx][uid=xxx];

（4） MD5加密操作

> enc=md5(source+\[key\]);

### 注意事项

（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

*   例如：\[a=1\]\[b=2\]\[c=3\]\[ei=4\]\[ej=5\]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

*   例如：\[a=1,2,3,4,5,6\]
