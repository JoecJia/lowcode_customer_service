**简要描述：**
 顶部按钮是一个批量操作功能，顶部按钮点击后，系统会自动调用按钮配置好的url，同时会在url后面追加queryId参数， 拿到queryId的值，就可以调用本接口获取在点按钮的时候用户都勾选了哪些数据。 
**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/user/data/top/search/list

**请求方式：**
- GET,POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID|
|uid      |是  |int | 用户ID    |点击顶部按钮时的用户uid|
|queryId  |是  |String | 查询条件Id |根据按钮url后面自动追加的参数值|
|sortValues |否  |string | 查询游标 |第一次查询默认传空,反之则传入上一次查询返回数据sortValues,进行下一页查询,注意，sortValues不参与加密|
|limit    |否  |int | 每页大小 |默认10条,最多1次限制100条|
|returnFields |否  |string | 指定需要返回的表单字段 |比如需要返回组件别名为name的字段和子表单下组件别名为name1的字段格式为:[{"alias":"name"},{"alias":"detailbox","subFields":[{"alias":"name1"}]}]|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**P1 · 返回键名修正：**

|实际返回|说明|
|:---|:---|
|data.dataList|数据结果集；文档示例写 `data`，按文档取不到记录|
|data.total|总条数，与 `dataList` 同级|
|data.sortValues|服务端加密游标，与 `dataList` 同级，下一页需原样回传|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|queryId参数异常|queryId 非法|
|queryId参数不存在|queryId 无对应按钮配置|
|无效的查询参数|查询参数不合法|
|PARAMS_INVALID|参数校验失败|
|非法的参数|参数格式错误|
|审批不存在|formId 定位不到审批|
|未找到选择的审批人信息|审批人配置缺失|
|参数错误！！|参数校验失败|
|[500]|服务端异常|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021012816][fid=75035][limit=100][orderType=desc][queryId=][returnFields=][sign=xxx][uid=21662618]";
```

（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
