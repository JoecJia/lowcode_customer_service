
**请求URL：**
- http://m.oa.chaoxing.com/api/approve/forms/searchafter/list?fid=&uid=&startTime=&endTime=&limit=&orderType=&formId=&formAlias=&formUserId
=&returnFields=&datetime=&sign=&enc=&sortValues=&approveStatus=

**请求方式：**
- GET,POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID|
|formId   |否  |int | 审批ID    |formId 与formAlias参数至少要有一个有值|
|formAlias   |否  |String | 审批接口标识（别名)    |formAlias 与formId参数至少要有一个有值|
|uid      |否  |int | 用户ID    |发起人人UID|
|approveStatus     |否  |int | 审批状态 | 0-待审批，1-已同意，2-被拒绝，3-已撤销。如果不传该参数获取的就是所有审批状态的发起记录。    |
|searchStr     |否  |string | 查询筛选条件 |查询筛选条件,不参与加密,json格式，传入时需做URLEncode编码，注意不要二次编码 |
|sortValues    |否  |string | 查询游标 |第一次查询默认传空,反之则传入上一次查询返回数据sortValues,进行下一页查询|
|limit    |否  |int | 每页大小 |默认30条,最多1次限制100条|
|orderType |否  |string | 排序类型    | 按照表单用户审批时间排序（desc降序，asc升序，默认desc）|
|startTime   |否  |string | 起始时间|查询某时间范围内数据-起始时间(yyyy-MM-dd)|按审批申请发起时间
|endTime     |否  |string | 结束时间|查询某时间范围内数据-结束时间(yyyy-MM-dd)  |按审批申请发起时间
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

|inserttime |timestamp   |审批发起时间， 时间戳格式 |

|formData | array   |该条审批的表单填写数据|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|[3000]审批id和审批别名不能同时为空|formId 与 formAlias 均未传|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|游标解析失败|sortValues 非法或已失效|
|searchStr格式错误|searchStr 非合法 JSON 或字段不存在|
|获取用户发起的审批记录接口异常|服务端处理异常|

**接口参数配置**
（1）接口标识
> sign=approveData_xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021012816][fid=75035][formAlias=info][formId=2713][formUserId=9642][limit=100][orderType=desc][returnFields=][sign=xxx][uid=21662618][sortValues=]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/approve/forms/searchafter/list?formAlias=info&formId=2713&formUserId=9642&orderType=desc&datetime=2021012015&fid=73566&uid=21662618&sign=xxx&limit=1&enc=af46e7058ef5c4184ad41f2476b8c7d0&returnFields=&sortValues=

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
