## 表单引擎 webAPI（60 篇）

- **表单应用相关接口**（9 篇）：获取单位下表单应用列表、表单应用批量复制、第三方创建应用删除/修改、数据空间占用统计等。
- **表单配置相关接口**（20 篇）：表单字段结构、权限配置/设置、前台应用配置、组织架构设置、打印模板、提交校验、按钮配置、数据权限、提交限制等。
- **表单数据接口(增删改查)**（16 篇）：单条/批量新增、更新、删除，高级检索、按行 id 取数、深度分页同步、分组汇总、操作日志恢复、数据日志与导出记录等。
- **数据推送相关接口**（5 篇）：推送配置增删改、失败数据列表、表单下推送列表。
- **获取页面地址相关**（6 篇）：编辑页/详情页面地址、数据管理页、创建页跳转、precast 字段赋值、令牌获取。
- **推送提醒相关接口**（1 篇）：表单/审批推送提醒日志。
- **计划上线**（2 篇）：报表用角色数据权限列表、批量获取详情页面地址。
- **未分类**（1 篇）：`办公业务码code说明.md`。

## 审批引擎 webAPI（61 篇）

- **通用审批服务**（6 篇）：审批申请、撤销、状态查询、详情页地址、修改状态、环节流程结构说明。
- **用户数据检索相关接口**（7 篇）：高级检索、按审批行 id 取数、深度分页、顶部按钮取数、角色数据权限、详情地址、电子印章。
- **用户数据增删改相关接口**（2 篇）：删除审批记录、审批修改数据。
- **审批流程流转**（7 篇）：修改状态、回退、回退配置列表、撤销、加签转交、审批人撤回处理及列表。
- **审批应用相关**（7 篇）：应用模板删除、节点数据、应用列表、处理时间/状态/提交量统计、导出记录。
- **配置相关接口**（21 篇）：字段结构、权限配置与设置、字段标题修改、组织架构、结束回调、校验推送、打印模板、按钮配置、数据权限、提交限制等。
- **审批流程查询**（3 篇）：自建审批流程信息（含老版）、节点配置。
- **用户数据统计**（2 篇）：字段汇总滤重、分组汇总统计。
- **审批助手相关接口**（4 篇）：收到的/发起的审批记录、发起记录详情、相关审批类型列表。
- **计划接口(还未上线)**（2 篇）：报表用角色数据权限列表、审批删除字段接口。
