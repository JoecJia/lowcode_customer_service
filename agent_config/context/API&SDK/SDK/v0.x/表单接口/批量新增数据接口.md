##### 简要描述

- 批量新增数据接口

##### 方法调用
- ` OfficeApiInvokeService.batchSaveCustomFormsDataByFormId `

- ` OfficeApiInvokeService.batchSaveCustomFormsDataByAlias `

##### 返回值类型
- [ApiResponse](https://cxapi.chaoxing.com/web/#/653656294/207981362 "ApiResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uid |是  |Integer | 【提交人uid】    |
|autoSendData |否  |Integer | 【数据推送】默认为1可触发数据推送，0:不触发数据推送    |
|formsDataList |是  |List<[FormsData](http://cxapi.chaoxing.com/web/#/653656294/207981360 "FormsData")> | 【表单数据】新增的表单数据，sdk构造出来的formData对象集合    |
