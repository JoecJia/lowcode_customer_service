##### 简要描述

- 顶部按钮获取数据接口（根据queryId获取数据）

##### 方法调用
- ` OfficeApiInvokeService.formUserTopSearchListByQueryId `

##### 返回值类型
- [ApiResponse](https://cxapi.chaoxing.com/web/#/653656294/207981362 "ApiResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|uid |是  |Integer | 【uid】点击顶部按钮时的用户uid    |
|queryId |是  |String | 【查询条件Id】根据按钮url后面自动追加的参数值   |
|returnFields |否  |Integer | 【指定需要返回的表单字段】 比如需要返回组件别名为name的字段和子表单下组件别名为name1的字段格式为:[{“alias”:”name”},{“alias”:”detailbox”,”subFields”:[{“alias”:”name1”}]}]    |
|limit |否  |String | 【每页条数】默认30条，最多1次限制100条    |
|sortValues |否  |Boolean | 【游标】上一次请求数据返回游标，用于下一次请求    |
