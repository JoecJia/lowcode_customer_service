##### 简要描述

- 单条新增数据接口

##### 方法调用
- ` OfficeApiInvokeService.saveCustomFormsDataByFormId `

- ` OfficeApiInvokeService.saveCustomFormsDataByAlias `

##### 返回值类型
- [ApiResponse](https://cxapi.chaoxing.com/web/#/653656294/207981362 "ApiResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uid |是  |Integer | 【提交人uid】    |
|uuid |否  |String | 【uuid】调用方业务唯一id，可以防止数据重复提交    |
|checkRequired |否  |Boolean | 【必填校验】控制数据的必填校验是否开启，默认为开启true    |
|autoSendData |否  |Integer | 【数据推送】默认为1可触发数据推送，0:不触发数据推送    |
|formsData |是  |[FormsData](http://cxapi.chaoxing.com/web/#/653656294/207981360 "FormsData") | 【表单数据】新增的表单数据，sdk构造出来的formData对象    |

##### 返回示例 

```
{
  "code": "200",
  "success": true,
  "msg": "保存成功",
  "data": {
    "formUserId": 100
  }
}
```
