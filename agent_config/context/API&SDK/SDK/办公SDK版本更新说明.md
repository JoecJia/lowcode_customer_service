# V1.0
1. **新增审批接口**（8个）：单条修改、根据审批行id获取数据、高级检索、顶部按钮queryId获取数据、获取用户发起过的审批记录、删除审批记录、获取角色数据权限对应的数据列表、分组汇总统计接
2. **新增表单接口**（2个）：获取角色数据权限对应的数据列表、分组汇总统计接口
3. **新增评分字段**（RateField、RateSearchFilter）
4. 由于引入审批接口后接口数量较多或不易区分，调用入口service由OfficeApiInvokeService改为
**OfficeFormsApiInvokeService（表单）**
**OfficeApproveApiInvokeService（审批）**
5. sdk-v0.2返回值对象只有一个ApiResponse，对于检索接口、或是增删改接口都会出现一些无关的NULL属性；考虑到使用者调用的便利性，但又不想让返回值对象过多，考虑将返回值分开为两类（检索类、修改类），即**ApiSearchResponse** 和 **ApiModifyResponse**
6. 新增java源文件jar包，引入后可查看代码中方法参数说明、类属性说明等注释信息，可自行选择是否引入
7. 修复检索接口返回值中**按钮、定位**字段值为null的问题
8. 统一表单“单条新增”接口和“批量新增”接口中formUserId属性获取方式，尽量做到每类接口返回值属性大致统一
```json
// v0.2单条新增
{
  "code": "200",
  "success": true,
  "msg": "保存成功",
  "data": {
    "formUserId": 100
  }
}
// v1.0 单条新增
{
  "code": "200",
  "success": true,
  "msg": "保存成功",
  "data": {
    "succeedList": [
      {
        "formUserId": 754060
      }
    ]
  }
}
```
