##### 简要描述

- 获取角色数据权限对应的数据列表接口

##### 方法调用
- ` OfficeFormsApiInvokeService.formUserPermissionDataAndSearchList `

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 版本要求
v1.14.1 及以上

##### 版本变动
- v1.22.1: 增加参数returnFields

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uid |是  |Long | 【uid】 用户uid    |
|roleId |否  |Integer | 【角色id】 默认-1    |
|permissionGroupId |否  |Integer | 【权限组id】默认为默认权限组，其id为1    |
|logicSearchFilter |否  |[LogicSearchFilter](https://cxapi.chaoxing.com/web/#/653656294/207980777 "LogicSearchFilter") | 【检索条件】sdk中构造的检索条件对象    |
|cpage |否  |Integer | 【页码】默认1    |
|pageSize |否  |Integer | 【每页条数】默认10条    |
|returnFields |否  |String | 【指定需要返回的表单字段】 比如需要返回组件别名为name的字段和子表单下组件别名为name1的字段格式为:[{“alias”:”name”},{“alias”:”detailbox”,”subFields”:[{“alias”:”name1”}]}]    |

##### 调用示例（仅供参考）

```java
	LogicSearchFilter logicSearchFilter = new LogicSearchFilter(SearchModelTypeEnum.OR);
	// 单行输入（等于）
	logicSearchFilter.addFilter(new EditinputSearchFilter("uname", SearchExpressTypeEnum.EQUALS, "张三"));
	// 多行输入（不等于）
	logicSearchFilter.addFilter(new EdittextareaSearchFilter(2, SearchExpressTypeEnum.NOT_EQUALS, "李四"));

	ApiSearchResponse apiResponse = OfficeFormsApiInvokeService.formUserPermissionDataAndSearchList(fid,
																								   181911,
																								   null,
																								   111111,
																								   217,
																								   1,
																								   logicSearchFilter，
																								   1,
																								   10);
```
