##### 简要描述

- 批量编辑数据接口

##### 方法调用
- ` OfficeFormsApiInvokeService.batchUpdateCustomFormsData `

- ` OfficeFormsApiInvokeService.batchUpdateCustomFormsDataByFormId `

- ` OfficeFormsApiInvokeService.batchUpdateCustomFormsDataByAlias `

##### 版本变动
- v1.6：增加参数operatorUid，v1.6及以上必填，老版本正常使用
- v1.11.1：增加参数autoTrigger、dataLogTitle
- v1.16.1: 增加参数extraParam
- v1.21.1: 增加参数autoFilterErrorFields

##### 返回值类型
- [ApiModifyResponse](https://cxapi.chaoxing.com/web/#/653656294/207980778 "ApiModifyResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uids |否  |String | 【检索条件】 可更新该参数指定uid提交的数据。 多值格式”uid1,uid2”,以逗号分隔    |
|formUserIds |否  |String | 【检索条件】 需要更新的数据行id数组,传递此参数后,cPage和pageSize参数失效 。多值格式”1,2,3,4”,以逗号分隔    |
|logicSearchFilter |否  |[LogicSearchFilter](https://cxapi.chaoxing.com/web/#/653656294/207980777 "LogicSearchFilter") | 【检索条件】sdk中构造的检索条件对象    |
|startTime |否  |String | 【检索条件】数据插入时间--开始时间，参数格式 yyyy-MM-dd HH:mm:ss    |
|endTime |否  |String | 【检索条件】数据插入时间--结束时间，参数格式 yyyy-MM-dd HH:mm:ss    |
|startUpdateTime |否  |String | 【检索条件】数据更新时间--开始时间，参数格式 yyyy-MM-dd HH:mm:ss    |
|endUpdateTime |否  |String | 【检索条件】数据更新时间--结束时间，参数格式 yyyy-MM-dd HH:mm:ss   |
|cpage |否  |Integer | 【页码】默认1    |
|pageSize |否  |Integer | 【每页条数】默认10条，最大100条    |
|orderType |否  |String | 【排序类型】默认”desc”    |
|autoSendData |否  |Integer | 【数据推送】默认为1可触发数据推送，0:不触发数据推送    |
|operatorUid |是  |Long | 【操作人uid】用于记录此次修改的操作人    |
|formsData |是  |[FormsData](https://cxapi.chaoxing.com/web/#/653656294/207980776 "FormsData") | 【表单数据】修改的表单数据，sdk构造出来的formData对象    |
|autoTrigger |否  |Integer | 【触发器】默认为1可执行触发器，0:不执行触发器    |
|dataLogTitle |否  |String | 【自定义数据日志title】    |
|checkRequired |否  |Boolean | 【必填校验】控制数据的必填校验是否开启，默认为开启true    |
|extraParam |否  |String | 调用方可以传递额外参数，在接口响应success时会原样返回    |
|autoFilterErrorFields |否  |Boolean | 【过滤错误字段】默认为false,开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；    |

private FormsData getOneFormsData() {
    FormsData formsData = new FormsData();
	// 单行输入
	formsData.addField(new EditinputField("uname", "张三"));
	// 数字输入
	formsData.addField(new NumberinputField(3, 888d));
	// 滑动条
	formsData.addField(new SliderField(4, 88));
	// 单选
	formsData.addField(new RadiobuttonField(5, "选项1"));
	// 多选
	formsData.addField(new ChecklistField(6, "选项1", "选项3"));
	
	return formsData;
}

private LogicSearchFilter getLogicSearchFilter() {
	LogicSearchFilter logicSearchFilter = new LogicSearchFilter(SearchModelTypeEnum.OR);
	// 单行输入（等于）
	logicSearchFilter.addFilter(new EditinputSearchFilter("uname", SearchExpressTypeEnum.EQUALS, "张三"));
	// 多行输入（不等于）
	logicSearchFilter.addFilter(new EdittextareaSearchFilter(2, SearchExpressTypeEnum.NOT_EQUALS, "李四"));
	
	return logicSearchFilter;
}
