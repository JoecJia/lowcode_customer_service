##### 简要描述

- 单条新增数据接口

##### 方法调用
- ` OfficeFormsApiInvokeService.saveCustomFormsData `

- ` OfficeFormsApiInvokeService.saveCustomFormsDataByFormId `

- ` OfficeFormsApiInvokeService.saveCustomFormsDataByAlias `

##### 返回值类型
- [ApiModifyResponse](https://cxapi.chaoxing.com/web/#/653656294/207980778 "ApiModifyResponse")（详情请点击跳转）

##### 返回值补充（SDK 版本支持）

|返回字段|说明|SDK 支持版本|
|:----    |:----   |:----   |
|data.succeedList[].detailUrl | 新增数据的详情页链接 | **v1.23.3 起**（返回对象字段自 v1.23.3 提供；服务端 2026-10-21 起填充该值） |
|data.repeatFormUserId | 唯一值校验重复时返回，值为与当前数据冲突的数据行 id（此时 success=false） | **v1.13.3 起** |

##### 版本变动
- v1.11.1：增加参数autoTrigger、dataLogTitle
- v1.15.2：uid由Integer改为Long类型
- v1.16.1: 增加参数extraParam
- v1.21.1: 增加参数autoFilterErrorFields
- v1.23.1: 增加参数defaultValueConfig

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uid |是  |Long | 【提交人uid】    |
|uuid |否  |String | 【uuid】调用方业务唯一id，可以防止数据重复提交    |
|checkRequired |否  |Boolean | 【必填校验】控制数据的必填校验是否开启，默认为开启true    |
|autoSendData |否  |Integer | 【数据推送】默认为1可触发数据推送，0:不触发数据推送    |
|formsData |是  |[FormsData](https://cxapi.chaoxing.com/web/#/653656294/207980776 "FormsData") | 【表单数据】新增的表单数据，sdk构造出来的formData对象    |
|autoTrigger |否  |Integer | 【触发器】默认为1可执行触发器，0:不执行触发器    |
|dataLogTitle |否  |String | 【自定义数据日志title】    |
|extraParam |否  |String | 调用方可以传递额外参数，在接口响应success时会原样返回    |
|autoFilterErrorFields |否  |Boolean | 【过滤错误字段】默认为false,开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；    |
|defaultValueConfig |否  |Object | 默认值设置项    |

##### 调用示例（仅供参考）

```java
FormsData formsData = new FormsData();
// 单行输入
formsData.addField(new EditinputField("uname", "张三"));
// 数字输入
formsData.addField(new NumberinputField(3, 888d));
// 滑动条
formsData.addField(new SliderField(4, 88));
// 单选
formsData.addField(new RadiobuttonField(5, "选项1"));
// 多选
formsData.addField(new ChecklistField(6, "选项1", "选项3"));
// 单行输入--自动计算默认值（常用公式、数据联动、公式编辑等）
formsData.addField(new EditinputField(2, true));

//调sdk接口
ApiModifyResponse saveByFormId = OfficeFormsApiInvokeService.saveCustomFormsData(fid,
																				 181635,
																				 "181635",
																				 111111,
																				 null,
																				 false,
																				 PushDataEnum.TRUE.type,
																				 formsData,
																				 TriggerEnum.TRUE.type,
																				 null,
																				 null);
```
