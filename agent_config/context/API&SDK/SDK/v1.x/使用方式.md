# 引入jar包
### 1. 下载地址
下载地址（最新的几个版本）：https://noteyd.chaoxing.com/pc/c402c236-a124-4d60-ab5c-342f575c4596

### 2. 有maven私服的放到maven私服中
`mvn install:install-file -DgroupId=com.chaoxing.office.app -DartifactId=office-api-sdk -Dversion=版本号 -Dpackaging=jar -Dfile=本地目录\office-api-sdk-版本号.jar
`

### 3. 仓库找到pom文件加入如下依赖
```xml
<properties>
    <commons-codec.version>1.11</commons-codec.version><!-- v1.22.1 及以上不需要引入 -->
    <okhttp.version>3.12.0</okhttp.version>
	<!--高版本jdk（如jdk17）若报错 java.lang.reflect.UndeclaredThrowableException，请把retrofit版本更换为2.8.0-->
    <retrofit.version>2.8.0</retrofit.version>
    <jackson-core.version>2.12.3</jackson-core.version>
</properties>
<dependencies>
    <dependency>
        <groupId>commons-codec</groupId>
        <artifactId>commons-codec</artifactId>
        <version>${commons-codec.version}</version>
    </dependency>
    <dependency>
        <groupId>com.squareup.okhttp3</groupId>
        <artifactId>okhttp</artifactId>
        <version>${okhttp.version}</version>
    </dependency>
    <dependency>
        <groupId>com.squareup.retrofit2</groupId>
        <artifactId>retrofit</artifactId>
        <version>${retrofit.version}</version>
    </dependency>
    <dependency>
        <groupId>com.squareup.retrofit2</groupId>
        <artifactId>converter-jackson</artifactId>
        <version>${retrofit.version}</version>
    </dependency>
    <dependency>
        <groupId>com.fasterxml.jackson.core</groupId>
        <artifactId>jackson-core</artifactId>
        <version>${jackson-core.version}</version>
    </dependency>
</dependencies>
```

### 4. 项目中引入
```xml
<dependency>
    <groupId>com.chaoxing.office.app</groupId>
    <artifactId>office-api-sdk</artifactId>
    <version>1.0</version>
</dependency>
```

# 配置方式（两种）

- 添加配置文件 **office-api-sdk.properties**，将基础信息配置到文件中,然后调用一次**OfficeAppApiConfigTool.initApiServerConfig()**;

```yaml
#office-api-server-domain不配置默认为https://m.oa.chaoxing.com
office-api-server-domain=https://m.oa.chaoxing.com
office-api-forms-sign=xxx
office-api-forms-key=xxx
office-api-approve-sign=xxx
office-api-approve-key=xxx
office-api-approve-status-handle-sign=xxx
office-api-approve-status-handle-key=xxx
#sdk版本v1.8及以上支持设置okhttp超时时间（单位：秒），不设置则为okhttp默认值10s
#office-api-read-timeout=20
#office-api-connect-timeout=20

#sdk版本v1.20.1新增：okhttp接口调用日志开关（开启时会打印内部调用接口的地址、参数、返回值）
#okhttp.log.enable=true
```

- 或直接对属性赋值

```java
// 表单
#officeApiServerDomain不配置默认为https://m.oa.chaoxing.com
OfficeAppApiConfigTool.officeApiServerDomain = "https://m.oa.chaoxing.com";
OfficeAppApiConfigTool.officeApiFormSign = "appsFormsData_*";
OfficeAppApiConfigTool.officeApiFormKey = "key";
// 审批
OfficeAppApiConfigTool.officeApiApproveSign = "approveData_*";
OfficeAppApiConfigTool.officeApiApproveKey = "key";
OfficeAppApiConfigTool.officeApiApproveStatusHandleSign = "aprvStatusHandle_*";
OfficeAppApiConfigTool.officeApiApproveStatusHandleKey = "key";
// sdk版本v1.8及以上支持设置okhttp超时时间（单位：秒），不设置则为okhttp默认值10s
OfficeAppApiConfigTool.officeApiConnectTimeout = "20";
OfficeAppApiConfigTool.officeApiReadTimeout = "20";
```
