# 默认值使用说明

默认值用于在新增表单或审批数据时，由服务端按表单字段配置自动计算字段值，例如常用公式、公式编辑、数据联动等场景。

SDK 中默认值有两种使用方式，按本次调用诉求二选一使用：

- 接口级默认值配置：通过 `DefaultValueConfig` 参数统一控制本次接口调用是否触发默认值、是否对子表单整体触发默认值、是否只触发本次 `formData` 中传入的字段。
- 字段级默认值：在 `FormsData` 中对指定字段设置 `defaultValue=true`，只触发该字段的默认值。

说明：同一次接口调用建议只选择其中一种方式。只需要指定少量字段时使用字段级默认值；需要整条数据或子表单整体按默认值规则计算时使用 `DefaultValueConfig`。

# 适用接口

当前 `DefaultValueConfig` 参数适用于以下方法：

| 方法 | 说明 |
|:----|:----|
| `saveCustomFormsData` | 表单单条新增数据 |
| `batchSaveCustomFormsData` | 表单批量新增数据 |
| `batchSaveApproveData` | 审批批量新增数据 |

旧版快捷方法如 `saveCustomFormsDataByFormId`、`saveCustomFormsDataByAlias`、`batchSaveCustomFormsDataByFormId`、`batchSaveCustomFormsDataByAlias` 未暴露 `DefaultValueConfig` 参数。如需使用接口级默认值配置，请使用上表中的新方法。

# DefaultValueConfig 参数说明

包路径：

```java
import com.chaoxing.office.app.entity.forms.dto.data.DefaultValueConfig;
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----|:----|
| `enable` | `Boolean` | 否 | 是否触发默认值。默认为false。传 `true` 时开启本次接口调用的默认值计算。 |
| `enableDetailOverall` | `Boolean` | 否 | 是否对子表单启用整体默认值。默认为false。传 `true` 时，子表单按整体维度触发默认值。 |
| `onlyFormData` | `Boolean` | 否 | 是否只触发本次 `formData` 中传入的字段。默认为false。传 `true` 时，只对已传入字段做默认值计算；传 `false` 时，可按服务端规则扩展触发未传入但配置了默认值的字段。 |

构造方式：

```java
DefaultValueConfig defaultValueConfig = new DefaultValueConfig(true, true, false);
```

也可以使用 Lombok Builder：

```java
DefaultValueConfig defaultValueConfig = DefaultValueConfig.builder()
														  .enable(true)
														  .enableDetailOverall(true)
														  .onlyFormData(false)
														  .build();
```

# 常用配置

| 场景 | 推荐配置 | 说明 |
|:----|:----|:----|
| 使用字段级默认值 | `defaultValueConfig` 传 `null` | 在 `FormsData` 中对指定字段设置 `defaultValue=true`，只触发指定字段。 |
| 触发传入字段的默认值 | `new DefaultValueConfig(true, false, true)` | 只处理本次 `formData` 中明确传入的字段，影响范围较小。 |
| 触发整条数据的默认值 | `new DefaultValueConfig(true, false, false)` | 允许服务端按字段配置补充计算未传入字段的默认值。 |
| 子表单整体触发默认值 | `new DefaultValueConfig(true, true, false)` | 适合子表单字段需要计算整体默认值的场景。 |

# 方式一：接口级默认值配置

接口级默认值配置适合希望本次新增数据统一执行默认值规则的场景。使用该方式时，字段对象按正常数据字段构造，默认值触发范围由 `DefaultValueConfig` 控制。

**表单单条新增示例**

```java
public void testSaveCustomFormsData() {
    FormsData formsData = new FormsData();
    formsData.addField(new EditinputField("name", "张三"));

    DefaultValueConfig defaultValueConfig = DefaultValueConfig.builder()
															  .enable(true)
															  .enableDetailOverall(false)
															  .onlyFormData(true)
															  .build();

    ApiModifyResponse response = OfficeFormsApiInvokeService.saveCustomFormsData(170507,
																				 14881,
																				 "14881",
																				 58178393L,
																				 null,
																				 true,
																				 1,
																				 formsData,
																				 1,
																				 "自定义数据日志标题",
																				 null,
																				 false,
																				 defaultValueConfig);
}
```

# 方式二：字段级默认值

字段级默认值适合只希望某几个字段自动计算的场景。字段对象支持 `new XxxField(id, true)` 或 `new XxxField(alias, true)` 构造方式。

```java
public void testFieldDefaultValue() {
    FormsData formsData = new FormsData();
    formsData.addField(new EditinputField(1, "测试"));
    formsData.addField(new EditinputField(2, true));      // 单行输入自动计算默认值
    formsData.addField(new EdittextareaField(3, true));   // 多行输入自动计算默认值
    formsData.addField(new NumberinputField(4, true));    // 数字输入自动计算默认值
}
```

# 使用建议

- 同一次接口调用中，字段级默认值和 `DefaultValueConfig` 二选一。
- `onlyFormData=true` 更适合严格控制触发范围的场景；`onlyFormData=false` 更适合希望服务端补全未传入默认值字段的场景。
- 默认值计算依赖表单字段配置，字段未配置默认值、公式或联动规则时，传入默认值配置也不会产生额外结果。
- 批量新增时，`DefaultValueConfig` 对本次请求中的所有数据生效；如不同数据需要不同触发策略，建议拆分为多次请求。
