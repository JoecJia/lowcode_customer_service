##### 简要描述

- 用户数据高级检索接口

##### 方法调用
- ` OfficeApproveApiInvokeService.approveUserAdvanceSearchListByFormId `

- ` OfficeApproveApiInvokeService.approveUserAdvanceSearchListByAlias `

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 版本变动
- v1.12.3: aprvStatus由int改为string类型，支持传多个
- v1.14.3：增加参数formUserIds

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uids |否  |String | 【检索条件】 可更新该参数指定uid提交的数据。 多值格式”uid1,uid2”,以逗号分隔    |
|aprvUsers |否  |String | 【检索条件】要参与检索的审批人uid串，格式：uid1,uid2,uid3   |
|ccUsers |否  |String | 【检索条件】要参与检索的抄送人uid串，格式：uid1,uid2,uid3   |
|onlyReturnCount |否  |Integer | 【是否只返回总数】传此参数且为1时,则只返回totalCount查询总数量   |
|returnFields |否  |String | 【指定需要返回的表单字段】 比如需要返回组件别名为name的字段和子表单下组件别名为name1的字段格式为:[{“alias”:”name”},{“alias”:”detailbox”,”subFields”:[{“alias”:”name1”}]}]    |
|logicSearchFilter |否  |[LogicSearchFilter](https://cxapi.chaoxing.com/web/#/653656294/207980777 "LogicSearchFilter") | 【检索条件】sdk中构造的检索条件对象    |
|orderBy |否  |String | 【排序字段】orderBy参数为字段别名.目前支持数字字段和日期字段,需结合orderType使用,默认为”inserttime”,两个排序字段为”inserttime,updatetime”中间以逗号分隔    |
|orderType |否  |String | 【排序类型】按照表单用户填写时间排序（desc降序，asc升序，默认desc).当orderBy为2个排序字段时,orderType也支持传递多个,例如”desc,asc”以逗号分隔.如果orderType没传,则两个字段的排序类型均默认为”desc,desc”    |
|aprvStatus |否  |String | 【检索条件】审批状态 0-待审批，1-已同意，2-已拒绝，3-已撤销  （支持传多个，以逗号分隔）  |
|fromInsertTime |否  |String | 【检索条件】审批发起时间--开始时间，参数格式 yyyy-MM-dd HH:mm:ss    |
|toInsertTime |否  |String | 【检索条件】审批发起时间--结束时间，参数格式 yyyy-MM-dd HH:mm:ss    |
|fromFinishTime |否  |String | 【检索条件】审批更新时间--开始时间，参数格式 yyyy-MM-dd HH:mm:ss    |
|toFinishTime |否  |String | 【检索条件】审批更新时间--结束时间，参数格式 yyyy-MM-dd HH:mm:ss   |
|formUserIds |否  |String | 【检索条件】审批数据id列表，逗号隔开，例："123456,232323"，最多100个   |
|cpage |否  |Integer | 【页码】默认1    |
|pageSize |否  |Integer | 【每页条数】默认10条，最多100条    |

private LogicSearchFilter getLogicSearchFilter() {
	LogicSearchFilter logicSearchFilter = new LogicSearchFilter(SearchModelTypeEnum.OR);
	// 单行输入（等于）
	logicSearchFilter.addFilter(new EditinputSearchFilter("uname", SearchExpressTypeEnum.EQUALS, "张三"));
	// 多行输入（不等于）
	logicSearchFilter.addFilter(new EdittextareaSearchFilter(2, SearchExpressTypeEnum.NOT_EQUALS, "李四"));
	
	return logicSearchFilter;
}
