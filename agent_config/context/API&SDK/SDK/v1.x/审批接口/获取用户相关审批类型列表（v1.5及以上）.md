##### 简要描述

- 获取用户相关审批类型列表（v1.5及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.searchApproveType `

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|uid |是  |Long |【用户uid】   |
|fid |否  |String | 【单位ID】支持传递多个，英文逗号隔开，"170507,123456"    |
|formIds |否  |String | 【审批formId】应用formId，多个以英文逗号分隔   |
|aprvType |否  |Integer | 【审批类型标识】 1-待审批； 2-已审批； 3-抄送我 （默认值1）    |

##### AprvTypeEnum类型说明

|枚举值   |含义   |
| ------------ | ------------ |
|DAI_SHEN_PI(1)   |待审批   |
|YI_SHEN_PI(2)   |已审批   |
|CHAO_SONG_WO(3)   |抄送我   |

##### 调用示例（仅供参考）

```java
ApiSearchResponse apiResponse = OfficeApproveApiInvokeService.searchApproveType(111111L,
                                                                                "xxx",
                                                                                null,
                                                                                AprvTypeEnum.CHAO_SONG_WO.type);
```
