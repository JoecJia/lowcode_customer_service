##### 方法调用
- ` OfficeApproveApiInvokeService.updateApproveData `

- ` OfficeApproveApiInvokeService.updateApproveDataByFormId `

##### 版本变动
- v1.6：增加参数operatorUid，v1.6及以上必填，老版本正常使用
- v1.11.1：增加参数autoSendData、autoTrigger、dataLogTitle
- v1.14.2：增加参数checkRequired
- v1.16.1: 增加参数extraParam
- v1.16.2: 增加参数aprvTypeId

##### 返回值类型
- [ApiModifyResponse](https://cxapi.chaoxing.com/web/#/653656294/207980778 "ApiModifyResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|formUserId |是  |Long | 【审批记录ID】审批用户填写记录id    |
|operatorUid |是  |Long | 【操作人uid】用于记录此次删除记录的操作人    |
|formsData |是  |[FormsData](https://cxapi.chaoxing.com/web/#/653656294/207980776 "FormsData") | 【审批数据】修改的审批数据，sdk构造出来的formData对象    |
|autoSendData |否  |boolean | 【数据推送】true可触发数据推送，false不触发数据推送    |
|autoTrigger |否  |boolean | 【触发器】true可执行触发器，false不执行触发器    |
|dataLogTitle |否  |String | 【自定义数据日志title】    |
|checkRequired |否  |Boolean | 【必填校验】控制数据的必填校验是否开启，默认为开启true    |
|extraParam |否  |String | 调用方可以传递额外参数，在接口响应success时会原样返回    |
|currentVersion |否  |Integer |  传1更新为最新版本，不传或者传0还保持原来的逻辑  |
|aprvTypeId |否  |Integer | 【审批类型id】默认 10000，自建审批传 10000（SDK v1.16.2 起支持）  |

private FormsData getOneFormsData() {

	return formsData;
}
