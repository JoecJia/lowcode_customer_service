##### 简要描述

- 分组汇总统计接口

##### 方法调用
- ` OfficeApproveApiInvokeService.groupSummaryStatistics `

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 版本变动
- v1.22.1: 增加参数groupFieldAlias、statsFieldAlias

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|subIndex |否  |Integer | 【日期区间下标】日期区间字段在统计时进行了拆分，故值可以为0,1,2    |
|logicSearchFilter |否  |[LogicSearchFilter](https://cxapi.chaoxing.com/web/#/653656294/207980777 "LogicSearchFilter") | 【检索条件】sdk中构造的检索条件对象    |
|groupFieldId |否  |Integer | 【分组字段ID】    |
|groupFieldAlias |否  |String | 【分组字段ID】    |
|statsType |否  |StatsTypeEnum | 【统计类型】StatsTypeEnum枚举    |
|statsFieldId |是  |Integer | 【统计字段ID】    |
|statsFieldAlias |是  |String | 【统计字段Alias】ID和Alias二选一    |

##### StatsTypeEnum类型说明

|枚举值   |含义   |
| ------------ | ------------ |
|COUNT   |计数（非数字类型只能为COUNT）   |
|SUM   |求和   |
|MIN   |最小值   |
|MAX   |最大值   |
|AVG   |平均值   |

##### 调用示例（仅供参考）
- [LogicSearchFilter](https://cxapi.chaoxing.com/web/#/653656294/207980777 "LogicSearchFilter")（各字段举例及说明请点击跳转）

```java
private LogicSearchFilter getLogicSearchFilter() {
	LogicSearchFilter logicSearchFilter = new LogicSearchFilter(SearchModelTypeEnum.OR);
	// 单行输入（等于）
	logicSearchFilter.addFilter(new EditinputSearchFilter("uname", SearchExpressTypeEnum.EQUALS, "张三"));
	// 多行输入（不等于）
	logicSearchFilter.addFilter(new EdittextareaSearchFilter(2, SearchExpressTypeEnum.NOT_EQUALS, "李四"));
	
	return logicSearchFilter;
}

public void testStatistics() {
	//调sdk接口
	ApiSearchResponse apiResponse = OfficeApproveApiInvokeService.groupSummaryStatistics(fid,
																						 180619,
																						 null,
																						 DateTimeRangeSubIndexEnum.START_TIME.index,
																						 getLogicSearchFilter(),
																						 2,
																						 StatsTypeEnum.MAX,
																						 5);
}
```
