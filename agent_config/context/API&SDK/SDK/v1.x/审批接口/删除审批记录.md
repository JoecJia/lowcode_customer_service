##### 简要描述

- 删除审批记录接口

##### 方法调用
- ` OfficeApproveApiInvokeService.approveUserDataDelete `

- ` OfficeApproveApiInvokeService.approveUserDataDeleteByFormId `

- ` OfficeApproveApiInvokeService.approveUserDataDeleteByAlias `

##### 版本变动
- v1.6：增加参数operatorUid，v1.6及以上必填，老版本正常使用
- v1.11.1：增加参数autoSendData、dataLogTitle
- v1.16.1: 增加参数extraParam
- v1.19.1: 增加参数autoTrigger

##### 返回值类型
- [ApiModifyResponse](https://cxapi.chaoxing.com/web/#/653656294/207980778 "ApiModifyResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|formUserIds |是  |String | 【审批记录ID】审批用户填写记录id，多个行id以逗号分隔 "1,2,3,4"    |
|operatorUid |是  |Long | 【操作人uid】用于记录此次删除记录的操作人    |
|autoSendData |否  |boolean | 【数据推送】true可触发数据推送，false不触发数据推送    |
|dataLogTitle |否  |String | 【自定义数据日志title】    |
|extraParam |否  |String | 调用方可以传递额外参数，在接口响应success时会原样返回    |
|autoTrigger |否  |Integer | 【触发器】默认为1可执行触发器，0:不执行触发器（SDK v1.19.1 起支持）  |

##### 调用示例（仅供参考）

```java
ApiModifyResponse response = OfficeApproveApiInvokeService.approveUserDataDelete(fid,
																				 15496,
																				 "15496",
																				 "4964904",
																				 111111L,
																				 true,
																				 null,
																				 null);
```

{
  "code": "200",

  "msg": "删除成功"
