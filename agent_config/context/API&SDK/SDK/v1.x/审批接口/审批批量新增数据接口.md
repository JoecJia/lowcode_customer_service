##### 简要描述

- 审批批量新增数据接口

##### 方法调用
- ` OfficeApproveApiInvokeService.batchSaveApproveData `

##### 返回值类型
- [ApiModifyResponse](https://cxapi.chaoxing.com/web/#/653656294/207980778 "ApiModifyResponse")（详情请点击跳转）

##### 版本变动
- v1.16.1新增此接口
- v1.23.1: 增加参数 checkRequired、autoFilterErrorFields、defaultValueConfig

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uid |是  |Long | 【提交人uid】    |
|formsDataList |是  |List<[FormsData](https://cxapi.chaoxing.com/web/#/653656294/207980776 "FormsData")> | 【表单数据】新增的表单数据，sdk构造出来的formData对象集合（一次最多50条）    |
|approveStatusTypeId |否  |Integer | 【审批状态id】1:同意，2:拒绝 默认为1   |
|autoSendData |否  |Boolean | 【数据推送】默认为true:可触发数据推送，false:不触发数据推送    |
|autoTrigger |否  |Boolean | 【触发器】默认值为true:可执行触发器，false:不执行触发器    |
|dataLogTitle |否  |String | 【自定义数据日志title】    |
|extraParam |否  |String | 调用方可以传递额外参数，在接口响应success时会原样返回    |
|checkRequired |否  |Boolean | 【必填校验】控制数据的必填校验是否开启，默认为开启true    |
|autoFilterErrorFields |否  |Boolean | 【过滤错误字段】默认为false,开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；    |
|defaultValueConfig |否  |Object | 默认值设置项    |

```java
private FormsData getOneFormUserDataTest() {
    FormsData formsData = new FormsData();
	// 单行输入
	formsData.addField(new EditinputField("uname", "张三"));
	// 数字输入
	formsData.addField(new NumberinputField(3, 888d));
	// 滑动条
	formsData.addField(new SliderField(4, 88));
	// 单选
	formsData.addField(new RadiobuttonField(5, "选项1"));
	// 多选
	formsData.addField(new ChecklistField(6, "选项1", "选项3"));
	
	return formsData;
}

public void testBatchAdd() {
	List<FormsData> formsDataList = new ArrayList<>();
	for (int j = 0; j < 3; j++) {
		formsDataList.add(getOneFormUserDataTest());
	}
	//调sdk接口
	ApiModifyResponse apiResponse = OfficeApproveApiInvokeService.batchSaveApproveData(170507,
	                                                                                   17328,
	                                                                                   "17328",
	                                                                                   58178393L,
	                                                                                   formsDataList,
	                                                                                   1,
	                                                                                   true,
	                                                                                   true,
	                                                                                   "自定义数据日志标题",
	                                                                                   null);
}
```
