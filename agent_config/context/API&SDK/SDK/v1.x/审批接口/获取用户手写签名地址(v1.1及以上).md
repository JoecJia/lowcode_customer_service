##### 简要描述

- 获取用户手写签名地址接口

##### 方法调用
- ` OfficeApproveApiInvokeService.searchSignatureByUid `

##### 版本要求
- sdk-v1.1及以上

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|uid |是  |Long |【用户uid】   |

##### 调用示例（仅供参考）

```java
ApiSearchResponse apiResponse = OfficeApproveApiInvokeService.searchSignatureByUid(111111L);
```
