##### 简要描述

- 获取用户收到的审批记录接口（v1.2及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.searchUserApprovalList `

##### 版本要求
- sdk-v1.2及以上

##### 版本变动
- v1.4：增加检索参数searchWord、uids、formIds、startTime、endTime、aprvStatusType
- v1.21.1：增加检索参数ccRead

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fids |否  |String |【单位ID】支持传递多个，英文逗号隔开，"170507,123456"，最多20个   |
|uid |是  |Long | 【用户uid】    |
|aprvType |是  |Integer | 【审批类型标识】 1-待审批； 2-已审批； 3-抄送我 （默认值1）   |
|searchWord  |否  |string | 检索关键字，发起人姓名｜应用名，支持模糊   |
|uids  |否  |string |发起人uid，多个以英文逗号分隔   |
|formIds  |否  |string |应用formId，多个以英文逗号分隔   |
|startTime  |否  |string | 审批发起时间的开始日期  ，格式：yyyy-MM-dd HH:mm。可以检索到输入时间之后的数据  |
|endTime  |否  |string | 审批发起时间的结束日期  ，格式：yyyy-MM-dd HH:mm。可以检索到输入时间之前的数据   |
|aprvStatusType  |否  |string | 审批状态（0待审批，1已通过，2已拒绝，3已撤销）   |
|cpage |否  |Integer | 【页码】从1开始，默认值1    |
|pageSize |否  |Integer |【每页数据条数】，默认值10    |
|ccRead |否  |Integer |【按人员查询已读/未读的审批数量】0未读/1已读    |

##### AprvTypeEnum类型说明

|枚举值   |含义   |
| ------------ | ------------ |
|DAI_SHEN_PI(1)   |待审批   |
|YI_SHEN_PI(2)   |已审批   |
|CHAO_SONG_WO(3)   |抄送我   |

																					 null,

                                                                                     1,
