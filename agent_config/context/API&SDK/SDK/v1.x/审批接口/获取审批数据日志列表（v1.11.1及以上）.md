##### 简要描述

- 获取审批数据日志列表（v1.11.1及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.getApproveDataTraceList `

##### 返回值类型
- ApiDataLogResponse

##### 版本变动
- v1.11.1：接口上线即支持参数uid、desensitization（desensitization=true 时必须同时传 uid）
- v1.17.1: 增加参数formId、formAlias

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|formUserId |是  |Long | 【审批记录ID】审批用户填写记录id    |
|uid |否  |Long | 【用户uid】当前查看审批数据的用户uid,数据日志需要支持脱敏时需要此参数    |
|desensitization |否  |Boolean | 【数据日志是否支持脱敏】只有配置了脱敏并满足脱敏条件，此处传true才会返回脱敏后的值   |

##### 调用示例（仅供参考）

```java
ApiDataLogResponse result = OfficeApproveApiInvokeService.getApproveDataTraceList(170507,
                                                                                  25554916L,
                                                                                  58178393L,
                                                                                  false);
```

##### 返回值结构说明
- ApiModifyResponse

|属性   |类型   |备注   |
| ------------ | ------------ | ------------ |
|code   |String   |状态码（详情请见[状态码说明](https://cxapi.chaoxing.com/web/#/653656294/207980774 "状态码说明")）   |
|success   |Boolean   |成功标识   |
|msg   |String   |接口返回的信息   |
|data   |List<ApiDataLogVo>   |接口返回的数据   |

- ApiDataLogVo

|属性|类型|备注|
|:-----           |:-----     |-----   |
|title            |String    |数据日志标题名称|
|kind             |String    |数据日志类型， user：用户 trigger：触发器 api：接口|
|operate          |String     |数据日志操作类型， insert：创建 delete：删除 recover：恢复 process：处理 frontupdate(update):修改|
|operateName      |String     |数据日志操作类型名称|
|operateUid       |Long          |操作人uid|
|operateUname     |String    |操作人名称|
|diffData         |List<ApiDataLogInfoVo>          |修改内容数组，详情参考下面说明|
|operateTime      |Date  |操作时间， 时间戳格式|

- ApiDataLogInfoVo

|属性|类型|备注|
|:-----           |:-----    |-----   |
|id               |Integer   |组件id|
|alias            |String    |组件别名|
|compt            |String    |组件类型 |
|fieldName        |String    |组件名称 |
|processName      |String    |审批处理类型名称|
|processContext   |String    |审批处理备注|
|oldValue         |String    |组件修改前的值|
|newValue         |String    |组件修改后的值|
|type             |String   |子表单数据操作类型 add：新增 update:修改 delete：删除 unchanged:无变化|
|hasRowComparison |Boolean   |子表单是否有明细对比(23年之前的数据日志没有明细对比) |
|headerLine       |List<String>     |子表单修改明细标题行, 当compt为"detailcombox"并且hasRowComparison为true时才有值, 和subDiffData下每行数据中组件下标一一对应|
|subDiffData      |List<ApiDataLogSubInfoVo>      |子表单修改明细详情，当compt为"detailcombox"并且hasRowComparison为true时才有值，详情参考下面说明 |
|subOldValue      |List<List<ApiDataLogInfoVo>>      |子表单修改前列表，当compt为"detailcombox"并且hasRowComparison为false时才有值，数组里对象结构和diffData数组对象结构一样 |
|subNewValue      |List<List<ApiDataLogInfoVo>>      |子表单修改后列表，当compt为"detailcombox"并且hasRowComparison为false时才有值，数组里对象结构和diffData数组对象结构一样 |

- ApiDataLogSubInfoVo

|参数名|类型|说明|
|:-----           |:-----     |-----   |
|rowModifyType   |String    |子表单行数据操作类型 add：新增 update:修改 delete：删除|
|diffData        |List<ApiDataLogInfoVo>      |子表单每行数据修改详情，结构同上|
