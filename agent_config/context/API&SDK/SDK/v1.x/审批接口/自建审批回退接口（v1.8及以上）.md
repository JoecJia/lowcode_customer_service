##### 简要描述

- 自建审批回退接口（v1.8及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.approveBackHandle `

##### 返回值类型
- [ApiModifyResponse](https://cxapi.chaoxing.com/web/#/653656294/207980778 "ApiModifyResponse")（详情请点击跳转）

##### 版本变动
- v1.10.1：增加参数noticeUrl
- v1.15.1：增加参数nodeUniqueId
- v1.17.1: 增加参数formId、formAlias

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|uid |是  |Long |【用户uid】   |
|formUserId |是  |Long | 【审批数据id】    |
|backIndex |否  |Integer | 【回退节点id】<br>节点ID从回退列表接口获取<br>默认值为-1（回退到上一环节）   |
|backName |否  |String | 【回退节点名称】 默认值为“上一环节”    |
|signature |否  |String | 【手写签名图片地址】   |
|electronicSignature |否  |String | 【电子签章图片地址】   |
|file |否  |String | 【审批意见文件】    |
|picture |否  |String | 【审批意见图片】   |
|opinion |否  |String | 【审批意见】    |
|formsData |否  |[FormsData](https://cxapi.chaoxing.com/web/#/653656294/207980776 "FormsData") | 【审批数据】修改的审批数据，sdk构造出来的formData对象    |
|approveVerify |否  |Boolean | 【是否进行审批校验】默认值为true    |
|noticeUrl |否  |String | 【自定义通知链接】    |
|nodeUniqueId |否  |Long | 【待审批节点唯一标识】并行分支有多个待处理节点时处理对应节点；不传则默认处理该用户最先流转到的待审批节点   |

##### 调用示例（仅供参考）

```java
public void approveStatusHandle() {
	// 审批意见图片、审批意见文件
	//（1）可以通过自己的方法构造好字符串传参，结构示例：[{"name":"图片.jpg","fileUrl":"http://pan-yz.chaoxing.com/thumbnail/origin/8496cf4c214ea5d7e6ddbf0030bcc6e1","objectId":"8496cf4c214ea5d7e6ddbf0030bcc6e1","size":"2.94KB","byteSize":"3015","suffix":"jpg","modifyDate":1670238673305,"resid":"806602715512950800"}]
	//（2）也可以通过sdk内部的FileFieldValue构造，示例如下
	List<FileFieldValue> fileList = new ArrayList<>();
	fileList.add(new FileFieldValue("图片.jpg",
									"http://pan-yz.chaoxing.com/thumbnail/origin/8496cf4c214ea5d7e6ddbf0030bcc6e1",
									"8496cf4c214ea5d7e6ddbf0030bcc6e1",
									"3015",
									"jpg",
									1670238673305L,
									"806602715512950800"));
	// 构造formsData
	FormsData formsData = new FormsData();
	formsData.addField(new EditinputField("uname", "张三")); // 单行输入
	formsData.addField(new NumberinputField(3, 888d)); // 数字输入
	formsData.addField(new SliderField(4, 88)); // 滑动条
	formsData.addField(new RadiobuttonField(5, "选项1")); // 单选
	formsData.addField(new ChecklistField(6, "选项1", "选项3")); // 多选
	
	// 1、调用回退列表接口
	ApiSearchResponse apiSearchResponse = OfficeApproveApiInvokeService.getApproveStepBackList(170507, 4991383L);
	// 2、获取回退列表
	List<ApproveNodeInfo> approveStepBackList = apiSearchResponse.getData().getApproveStepBackList();
	// 3、获取回退节点
	ApproveNodeInfo approveNodeInfo = approveStepBackList.get(0);
	// 4、调用回退接口进行回退操作
	ApiModifyResponse apiModifyResponse = OfficeApproveApiInvokeService.approveBackHandle(fid,
																						  111111L,
																						  4991383L,
																						  approveNodeInfo.getId(),
																						  approveNodeInfo.getName(),
																						  "https://pan-yz.chaoxing.com/thumbnail/origin/3bfed76d4a74a919482b30d42aad6d5c",
																						  "https://pan-yz.chaoxing.com/thumbnail/origin/3bfed76d4a74a919482b30d42aad6d5c",
																						  JsonMapper.toJsonString(fileList),
																						  JsonMapper.toJsonString(fileList),
																						  "我的审批处理意见666",
																						  formsData);
}
```
