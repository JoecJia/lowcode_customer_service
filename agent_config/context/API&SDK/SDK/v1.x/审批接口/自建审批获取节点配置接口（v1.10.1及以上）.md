##### 简要描述

- 自建审批获取节点配置接口（v1.10.1及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.getApproveNodeConfig `

##### 返回值类型
- [ApiSearchResponse](https://cxapi.chaoxing.com/web/#/653656294/207980779 "ApiSearchResponse")（详情请点击跳转）

##### 版本变动
- v1.15.1：增加参数nodeUniqueId
- v1.17.1: 增加参数fid、formId、formAlias

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|formUserId |是  |Long | 【审批数据id】    |
|uid |否  |Long |【用户uid】不传则返回当前节点配置(审批完成后返回空数据)，传了则返回该用户在流程中的权限(当前审批人返回当前审批节点配置，非当前审批人返回最后一次审批过的节点配置, 未流转过的节点审批或不在审批流程中的返回空)   |
|nodeUniqueId |否  |Long | 【待审批节点唯一标识】并行分支有多个待处理节点时处理对应节点；不传则默认处理该用户最先流转到的待审批节点   |

##### 调用示例（仅供参考）

```java
public void getApproveStepBackList() {
	ApiNodeConfigResponse apiSearchResponse = OfficeApproveApiInvokeService.getApproveNodeConfig(536278L, 58178393L);
}
```
