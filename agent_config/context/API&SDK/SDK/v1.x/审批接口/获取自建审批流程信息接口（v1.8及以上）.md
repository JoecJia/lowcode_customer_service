##### 简要描述

- 获取自建审批流程信息接口（v1.8及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.getApproveFlowDetail `

##### 返回值类型
- [ApiApproveFlowResponse](https://cxapi.chaoxing.com/web/#/653656294/207981570 "ApiApproveFlowResponse")（详情请点击跳转）

##### 版本变动
- v1.17.1: 增加参数fid、formId、formAlias

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |-----   |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |
|formUserId |是  |Long | 【审批数据id】    |

##### 调用示例（仅供参考）

```java
public void approveStatusHandle() {
	ApiApproveFlowResponse apiResponse = OfficeApproveApiInvokeService.getApproveFlowDetail(xxx);
}
```
