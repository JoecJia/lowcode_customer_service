##### 简要描述

- 获取审批表单字段结构列表接口（v1.12.1及以上）

##### 方法调用
- ` OfficeApproveApiInvokeService.getFormStructConfig `

##### 返回值类型
- ApiFormConfigResponse

##### 参数

|参数名|必填|类型|说明|
|:----    |:---|:----- |----- |
|fid |是  |Integer |【单位ID】   |
|formId |是  |Integer | 【表单ID】（formId和formAlias任选一个）    |
|formAlias |是  |String | 【表单别名】表单接口标识（formId和formAlias任选一个）   |

##### 调用示例（仅供参考）

```java
ApiFormConfigResponse apiResponse = OfficeApproveApiInvokeService.getFormStructConfig(170507, 139707, null);
```

##### 返回值结构说明
- ApiFormConfigResponse

|属性   |类型   |备注   |
| ------------ | ------------ | ------------ |
|code   |String   |状态码（详情请见[状态码说明](https://cxapi.chaoxing.com/web/#/653656294/207980774 "状态码说明")）   |
|success   |Boolean   |成功标识   |
|msg   |String   |接口返回的信息   |
|data   |ApiFormConfigResponseData   |接口返回的数据   |

- ApiFormConfigResponseData

|属性|类型|备注|
|:-----           |:-----     |-----   |
|bindOrganizationID  |Integer               |绑定的组织架构id|
|columnsNum          |Integer               |说明填写页开启了多列|
|fieldTab            |List<ApiFieldTabInfo> |表单多标签信息|
|fieldConfig         |String                |表单字段结构|
|fieldVisibleConfig  |String                |返回显隐规则的配置|
|fieldEditConfig  |String                |字段编辑规则的配置|
|fieldRequiredConfig  |String                |必填规则的配置|
|fieldUniqueConfig  |String                |字段唯一规则的配置|

- ApiFieldTabInfo

|属性|类型|备注|
|:-----           |:-----     |-----   |
|title      |String               |多标签名称|
|fieldIds   |List<Integer>        |多标签内的组件id集合|
