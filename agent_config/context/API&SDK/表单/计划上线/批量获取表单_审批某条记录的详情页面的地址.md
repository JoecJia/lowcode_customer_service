**简要描述：**

- 批量获取表单/审批某条记录的详情页面的地址
- 单次最多支持100个formUserIds（按传入个数计）
- 不存在或已删除的数据行不生成链接, 统一通过missingFormUserIds返回告知调用方

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/detail/urls

**请求方式：**
- GET,POST
```
POST请求样例:
ContentType:application/x-www-form-urlencoded
Body数据:
fid=97253&formId=1&formUserIds=92409,92410&formType=0&roleId=1&isShowBtn=false&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705
```

**参数说明：**

|参数名称|是否必填|参数类型|参数说明|
|:----    |:----|:-----|-----   |
|fid   |是  |int | 单位ID |
|formId   |二选一  |int | 表单Id/审批应用Id, 与formAlias二选一 |
|formAlias   |二选一  |string | 表单别名, 与formId二选一 |
|formUserIds |是 |string| 表单/审批的数据行记录id列表, 英文逗号分隔; 按传入个数最多100个, 重复id自动去重并保持传入顺序 |
|formType   |否 |int | 表单类型(0:表单 1:审批 2:公文流转), 默认为0 |
|roleId |否 |int | 表单详情页角色Id, 若传此参数则生成的链接中带有roleId |
|isShowBtn |否 |string | 是否显示编辑等按钮(true/false), 默认为true, 仅formType=0生效 |
|permissionGroupId |否 |int | 权限组Id, 若传此参数则校验表单存在此权限组, 且生成的链接中带有permissionGroupId |
|datetime |是  |string | 生成加密串时间, 格式：yyyyMMddHH |
|sign     |是  |string | 接口标识, 由超星办公系统方提供 |
|enc      |是  |string | 接口参数加密串, 采用md5加密方式进行生成 |

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "msg": "[200]请求成功",
    "data": {
        "details": [
            {
                "formUserId": 92409,
                "detailUrl": "http://t.chaoxing.com/front/apps/forms/fore/stcs/preview?formId=51126&formUserId=92409&isShowBtn=false&applyEnc=xxx&enc=xxx&fidEnc=xxx&roleId=1"
            },
            {
                "formUserId": 92410,
                "detailUrl": "http://t.chaoxing.com/front/apps/forms/fore/stcs/preview?formId=51126&formUserId=92410&isShowBtn=false&applyEnc=xxx&enc=xxx&fidEnc=xxx&roleId=1"
            }
        ],
        "missingFormUserIds": [92411]
    },
    "success": true
}
```

* 返回字段说明：

|字段|类型|说明|
|:----|:-----|-----|
|data.details |array| 成功生成详情页地址的列表, 顺序与传入formUserIds(去重后)一致 |
|data.details[].formUserId |long| 数据行记录id |
|data.details[].detailUrl |string| 详情页地址(带加密参数) |
|data.missingFormUserIds |array| 不存在或已删除、未生成链接的数据行id; 全部存在时为空数组 |

（2）失败

* 错误码说明：

|错误码|说明|触发条件|
|:----|:-----|:-----|
|100000|缺少单位id|fid未传或小于等于0|
|3003|字段id或别名alias不能同时为空|formId与formAlias均未传|
|100005|缺少用户填写id|formUserIds未传或为空|
|3000|请求参数不合法|formType不在{0,1,2}; 或formUserIds含非数字/小于等于0的id|
|100007|数据量超过最大限制,请分批执行此操作|formUserIds按传入个数超过100个|
|100003|表单不存在|formType=0时表单在该单位不存在或别名解析不到|
|100006|审批不存在|formType=1/2时审批应用在该单位不存在|
|-|当前表单无此权限组|传了permissionGroupId但表单权限配置中不包含|
|4000|查无数据|传入的数据行全部不存在或已删除|
|500|接口异常,请联系开发人员|服务端异常|

* 返回数据样例:
```
{
    "msg": "[100007]数据量超过最大限制,请分批执行此操作",
    "success": false
}
```

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021082717][fid=97253][formId=1][formType=0][formUserIds=1,2][roleId=][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） 结果地址
> http://m.oa.chaoxing.com/api/apps/forms/detail/urls?fid=97253&formId=1&formUserIds=1,2&formType=0&roleId=&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]

（3）formUserIds为英文逗号分隔的字符串参数, 整体作为一个参数值参与enc加密

* 例如：[formUserIds=1,2,3]

（4）isShowBtn、permissionGroupId等可选参数若传值, 同样按上述规则参与enc加密

（5）formUserIds中不存在或已删除的数据行不会出现在details中, 统一放在missingFormUserIds中返回; 若传入的数据行全部不存在, 返回错误码4000

（6）formUserIds按逗号分隔逐项严格解析, 存在空项(如尾逗号"1,2,")、非数字或小于等于0的id时返回错误码3000
