##第三方免登录跳转表单数据管理页面接口说明

###接口地址
* http://m.oa.chaoxing.com/api/manager/third/user/login/apps/manager?formId=&formType=&fid=&uid=&errorUrl=&sign=&enc=&roleid=&permissionGroupId=

|参数名称|是否必填| 参数类型   |参数名称| 参数说明                      |
|:----    |:----|:-------|:-----   |---------------------------|
|fid      |是  | int    | 当前单位ID    | 单位fid                     |
|uid      |是  | int    | 当前单位管理员ID    | 用户uid                     |
|datetime |是  | string |生成加密串时间   | 格式：yyyyMMddHH             |
|sign     |是  | string | 接口标识    | 由超星办公系统方提供                |
|enc      |是  | string | 接口参数加密串    | 采用md5加密方式进行生成             |
|formId   |是  | int    | 应用ID    | 应用ID（与接口标识选其一即可）          |
|formAlias   |是  | string | 应用接口标识    | 应用接口标识（与应用ID选其一即可）        |
|formType |是  | int    | 应用类型标识    | 0. 自建审批(默认值) 2. 自定义表单     |
|roleid   |否  | int    | 角色ID   | 角色ID                      |
|thirdUuid   |否  | string    | 透传参数  | 表单/审批数据管理页顶部打开URL功能，如果父页面传了透传参数，则点击按钮时需要自动追加这个参数。如果没传，则不追加。明文透传，参数可能被篡改，请使用uuid或加密参数，最大长度限制64位，请调用方自行负责参数安全                     |
|permissionGroupId| 否 | int | 权限组ID  | 权限组ID|
|searchStr| 否 | string | 过滤条件   | 数据管理页过滤条件（数据结构和高级检索接口searchStr一致[点击查看searchStr结构](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看searchStr结构")）|
|errorUrl |否  | string | 验证失败后跳转地址    | 在请求接口时需要进行一次encode-utf8编码 |
|token    |是  | string   | 令牌 | 身份校验 由https://cxapi.chaoxing.com/web/#/653656295/207987355 获取token |
|precast |否  |string |【precast】 |给表单字段预置值（同项目另有专项说明页） |
|state |否  |string |【state】 |跳转状态透传参数 |

 
### 处理结果
（1）接口调用成功，并发布完应用
  
（2）接口调用失败

* 跳转到errorUrl配置的页面，如果没有指定此参数则默认跳转到办公通后台登录页面

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少用户uid信息!|未传 uid|
|缺少formId或formAlias信息。|formId 与 formAlias 同时为空|
|缺少参数信息!|必要参数缺失|
|thirdUuid参数长度不能超过64位!|thirdUuid 超长|
|thirdUuid参数含有非法字符!|thirdUuid 含非法字符|
|token校验失败|token 无效或过期|
|请检查接口标识是否正确!|sign 不匹配|
|无此应用!|定位不到应用|
|无此应用数据!|定位不到数据|
|用户登录接口异常!|服务端异常|

> 失败时统一跳转到 `errorUrl` 指定页面；未指定则跳转办公通后台登录页，错误文案由调用方从跳转参数中读取。

###接口参数配置
（1）接口标识类型
> sign=deptManager_*

（2）加密秘钥
> key=xxx

（3）加密方式字符串
> source="[datetime=xxx][formId=xxx][sign=xxx][uid=xxx]……";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
