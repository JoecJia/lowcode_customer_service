**简要描述：**

- 获取表单/审批某条记录的详情页面的地址

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/detail/url?fid=&formId=&formUserId=&formType=&roleId=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
```
POST请求样例:
ContentType:application/x-www-form-urlencoded
Body数据:
fid=97253&formId=1&formUserId=1&formType=0&roleId=&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705
```

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID |
|formId   |是  |int |表单Id/审批应用Id|表单Id/审批应用Id |
|formUserId |是 |long|表单/审批的数据行记录id |表单/审批的数据行记录id|
|formType   |否 |int | 表单类型(0:表单 1:审批) |默认为0 |
|roleId |否 |int |表单详情页角色Id |若传此参数,则生成的链接中带有roleId |
|permissionGroupId |否 |int |权限组Id，不需要或没有权限组不要传 |若传此参数,则生成的链接中带有permissionGroupId |
|isShowBtn |否 |string |是否显示操作按钮 |默认为true, true-显示按钮（打印，编辑，删除）,false-不显示按钮|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|formAlias |否  |string |【formAlias】 |表单/审批别名，formId 为空时用它定位 |

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "msg": "[200]请求成功",
    "data": {
        "detailUrl"://pc端/第三方/移动端地址 "http://office.chaoxing.com/front/apps/forms/fore/stcs/preview?formId=51126&formUserId=92409&enc=1ca79c393193e5f3cbad50612793adef"
    },
    "success": true
}
```
（2）失败

* 返回数据样例:
```
{
    "msg": "[100002]缺少表单id",
    "success": false
}
{
    "msg": "[100000]缺少单位id",
    "success": false
}
{
    "msg": "[100005]缺少用户填写id",
    "success": false
}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|COMPT_ID_ALIAS_NOT_EMPTY|formId 与 formAlias 同时为空|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|APPROVE_NOT_EXIST|formType=1 时审批应用不存在|
|当前用户无此权限！|无数据权限|
|NO_DATA|数据行不存在|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021082717][fid=97253][formId=1][formType=0][formUserId=1][isShowBtn=true][roleId=][sign=xxx]";

```
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5） 结果地址
> http://m.oa.chaoxing.com/api/apps/forms/detail/url?fid=97253&formId=1&formUserId=1&formType=0&roleId=&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
