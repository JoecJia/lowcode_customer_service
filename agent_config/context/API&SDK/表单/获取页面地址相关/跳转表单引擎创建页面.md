##第三方免登录跳转创建表单页面接口说明

###接口地址
* http://m.oa.chaoxing.com/api/manager/third/user/login/apps/create?aprvAppId=&formId=&formType=&fid=&toUrl=&uid=&errorUrl=&sign=&enc=

| 参数名称             |是否必填| 参数类型   | 参数名称                     |参数说明|
|:-----------------|:----|:-------|:-------------------------|-----   |
| fid              |是  | int    | 当前单位ID                   |单位fid|
| uid              |是  | int    | 当前单位管理员ID                |用户uid|
| datetime         |是  | string | 生成加密串时间                  | 格式：yyyyMMddHH|
| sign             |是  | string | 接口标识                     | 由超星办公系统方提供|
| enc              |是  | string | 接口参数加密串                  |采用md5加密方式进行生成|
| formId           |否  | int    | 表单ID                     | 表单ID(不为空即为编辑)|
| formType         |是  | int    | 应用类型标识                   | 0.自建审批；（默认值） 2. 自定义表单|
| aprvAppId        |否  | int    | 应用唯一标识                   | 应用唯一标识|
| topBarControlJson|否 | string | 控制编辑页显示菜单（formType为0时有效） | 1.基础设置（名称、图标）；2.表单设计；3.管理页设计；4.流程设置；5.高级设置；（不传则全部显示）|
| comptControlType  |否 | int    | 控制左侧组件库显示逻辑模式            | 0. 隐藏模式； 1. 显示模式；                                                                     |
| comptControl      |否 | string | 控制左侧组件库显示、隐藏内容 | 如："editinput,numberinput" 字段类型参考文档：https://cxapi.chaoxing.com/web/#/653656579/207985741 若comptControlType=0则仅隐藏该参数内组件，若comptControlType=1则仅显示该参数内组件 |
| toUrl            |否  | string | 回跳地址                     | 接口调用成功，并发布完应用自动回跳地址，在请求接口时需要进行一次encode-utf8编码|
| errorUrl         |否  | string | 验证失败后跳转地址                | 在请求接口时需要进行一次encode-utf8编码|
| token           |是  | string   | 令牌        | 身份校验 由https://cxapi.chaoxing.com/web/#/653656295/207987355 获取token|
|sourceType |否  |string |【sourceType】 |来源类型；`sourceType=wenjuan` 走问卷权限分支 |
|productType |否  |string |【productType】 |产品类型 |
|createType |否  |string |【createType】 |创建方式 |
|isCopy |否  |boolean |【isCopy】 |是否复制创建 |
|formAppId |否  |long |【formAppId】 |目标表单应用 id |
|limitTabNum |否  |int |【limitTabNum】 |限制可创建的标签数量 |
|successClose |否  |boolean |【successClose】 |成功后是否关闭页面 |
|documentCirculationType |否  |string |【documentCirculationType】 |文档流转类型 |

 
### 处理结果
（1）接口调用成功，并发布完应用

* 自动返回到toUrl指定页面
  
（2）接口调用失败

* 跳转到errorUrl配置的页面，如果没有指定此参数则默认跳转到办公通后台登录页面

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少用户uid信息!|未传 uid|
|缺少参数信息!|必要参数缺失|
|token校验失败|token 无效或过期|
|topBarControlJson参数格式错误!|控制菜单 JSON 非法|
|创建页面类型错误|formType 非法|
|无此应用数据!|定位不到应用|
|用户登录接口异常!|服务端异常|

> 失败时统一跳转到 `errorUrl` 指定页面；未指定则跳转办公通后台登录页。

###接口参数配置
（1）接口标识类型
> sign=deptManager_*

（2）加密秘钥
> key=xxx

（3）加密方式字符串
> source="[datetime=xxx][formId=xxx][sign=xxx][uid=xxx]……";

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
