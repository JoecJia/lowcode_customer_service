**简要描述：**

- 根据单位fid和uid获取token

**请求URL：**
- http://m.oa.chaoxing.com/api/token/get?fid=&uid=&datetime=&sign=&enc=&clientIp=

**请求方式：**
- GET,POST均可

**参数说明：**

| 参数名称     |是否必填| 参数类型   | 参数名称    | 参数说明           |
|:---------|:----|:-------|:--------|----------------|
| datetime |是  | string | 生成加密串时间 | 格式：yyyyMMddHH  |
| sign     |是  | string | 接口标识    | 由超星办公系统方提供     |
| enc      |是  | string | 接口参数加密串 | 采用md5加密方式进行生成  |
| fid      |是  | int    | 目标单位ID  | 单位fid（新表单所属单位） |
| uid      |是  | int    | 用户uid   | 用户uid          |

 **返回参数说明**

|参数名| 类型     | 说明 |
|:-----  |:-------|----|
|token | String | 令牌 |


**返回结果**
（1）成功
* 返回数据格式：
```json
   {
      "data": {
        "token": "530640aef1b0328e3b32e0196d0b61e30a49da5072307e19d4bd5e82adf4327f"
      },
      "success": true
  }
```
（2）失败

* 返回数据格式：{"msg":"验证失败","success":false}

**补充说明：**

|项|说明|
|:---|:---|
|clientIp|请求 URL 中出现，但控制器方法只接收 `uid`/`fid`/`enc`（`sign`/`datetime` 由鉴权层读取），该参数不参与鉴权与业务|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少uid或fid参数|uid / fid 缺失|
|缺少enc参数|未传 enc|
|token生成失败|服务端生成 token 失败|

**接口参数配置**
（1）接口标识类型
> sign=deptManager_*

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[datetime=xxx][fid=63555][sign=deptManager_*][uid=73361131]";
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5）结果地址
> http://m.oa.chaoxing.com/api/token/get?fid=63555&uid=73361131&datetime=2025040116&sign=deptManager_*&enc=99e1fe8614e264e42dd7f0b698f057e9



**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
