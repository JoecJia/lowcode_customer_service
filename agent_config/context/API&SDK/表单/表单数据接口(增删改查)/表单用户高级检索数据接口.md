

**简要描述：**

- 支持多字段设置查询条件，组合查询表单数据。并且支持多条件之间是或还是且的关系进行查询。
  支持多种逻辑关系，比如数字支持等于、不等于、大于、小于等关系，详情参见下面的说明。

**请求URL：**
-  http://m.oa.chaoxing.com/api/apps/forms/user/advanced/search/list?deptId=&searchStr=&uids=&cpage=&pageSize=&orderType=&formId=&appName=&startTime=&endTime=&startUpdateTime=&endUpdateTime=&datetime=&orderBy=&sign=&enc=

**请求方式：**
- GET，POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json
```java
POST
ContentType:application/x-www-form-urlencoded
Body数据:
deptId=&searchStr=&uids=&cpage=&pageSize=&orderType=&formId=&appName=&startTime=&endTime=&startUpdateTime=&endUpdateTime=&datetime=&orderBy=&sign=&enc=
```

**参数说明：**

|参数名|必选|类型|详细说明|
|:----    |:---|:----- |-------   |
|deptId     |是  |int | 单位ID    |
|formId     |否  |int | 表单ID（与appName参数至少要有一个有值）   |
|appName    |否  |string | 表单接口标识(别名)（与formId参数至少要有一个有值）    |
|aprvStatus |否  |int | 表单审核状态（0:待审核 1:通过 2:不通过） |
|status     |否  |int | 表单数据有效状态（1：有效数据 2：无效，已删除数据），默认为1 |
|onlyReturnCount    |否  |int | 传此参数且为1时,则只返回totalCount查询总数量    |
|searchStr     |否  |string | 查询筛选条件,不参与加密,json格式，传入时需做URLEncode编码，注意不要二次编码,[点击查看searchStr结构](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看searchStr结构") |
|returnFields |否  |string | 指定需要返回的表单字段 比如需要返回组件别名为name的字段和子表单下组件别名为name1的字段格式为:```[{"alias":"name"},{"alias":"detailbox","subFields":[{"alias":"name1"}]}]```|
|uids     |否  |string | 要参与检索的用户uid串，格式：uid1,uid2,uid3 加密时不用urlcode（utf-8）编码, 访问时进行一次urlcode（utf-8）编码|
|cpage     |否  |int | 当前页码  ，从1开始。（默认1）|
|pageSize     |否  |int | 分页大小   （默认10）最大值：100  |
|orderBy     |否  |string |orderBy参数为字段别名.目前支持的字段有numberinput,computeinput,dateinput,editinput,radiobutton,selectbox,autonumber,需结合orderType使用,默认为"inserttime",两个或多个排序字段字段为"inserttime,updatetime"中间以逗号分隔；其中手动排序标记为"manualOrder",当表单开启了手动排序，orderBy可传入"manualOrder"，接口会按照手动排序的顺序返回;"manualOrderTop"为置顶排序,传入此参数后，会优先返回置顶区的数据;|
|orderType     |否  |string | 排序类型,按照表单用户填写时间排序（desc降序，asc升序，默认desc).当orderBy为2个排序字段时,orderType也支持传递多个,例如"desc,asc"以逗号分隔.如果orderType没传,则两个字段的排序类型均默认为"desc,desc" |
|startTime     |否  |string | 用户提交数据的开始时间，参数格式 yyyy-MM-dd HH:mm:ss   |
|endTime     |否  |string | 用户提交数据的结束时间，参数格式 yyyy-MM-dd HH:mm:ss   |
|startUpdateTime     |否  |string | 数据的起始更新时间，参数格式 yyyy-MM-dd HH:mm:ss   |
|endUpdateTime     |否  |string | 数据的完成更新时间，参数格式 yyyy-MM-dd HH:mm:ss   |
|datetime |是  |string |生成加密串时间，格式：yyyyMMddHH  |
|sign |是  |string | 接口标识 ，由超星办公系统方提供   |
|enc     |是  |string | 接口参数加密串  ，具体加密方式参见文章最下面的ecn加密说明  |
|formUserIds |否 |string |按数据行 id 限定检索范围，多个以英文逗号分隔 |

**返回结果**
（1）成功

* 返回数据格式：
```
{"totalRow": "总条数","totalPage": "总页数","dataList": "数据结果集","success": true}
```

（2）失败

* 返回数据格式：
```
{"msg":"失败信息","success":false}
```

**补充返回说明：**

|字段|说明|
|:---|:---|
|`onlyReturnCount=1` 时的总数键|ES 后端返回 `data.total`；MySQL/PostgreSQL 后端返回 `data.totalRow`。文档旧版写作 `totalCount`，实际不存在|
|data.dataList|数据结果集|
|data.totalPage|总页数|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|PARAMS_INVALID|searchStr 格式错误|
|searchStr字段不存在|searchStr 引用了不存在的字段|
|[500]|服务端异常|

**接口参数配置**
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[appName=info][cpage=1][datetime=2020080808][deptId=73566][formId=8][orderBy=4][orderType=desc][pageSize=8][sign=xxx][uids=1,2,3]"
```

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
