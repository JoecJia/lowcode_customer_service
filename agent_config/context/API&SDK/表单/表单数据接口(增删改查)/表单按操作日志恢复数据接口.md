**简要描述：**
- 表单按操作日志恢复数据接口

**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：https://m.oa.chaoxing.com/api/apps/forms/data/recovery

HTTP Header:

Content-Type application/x-www-form-urlencoded
HTTP Body中放置请求参数，参数详情如下：

**请求参数**

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| formId | 1 | 是 | number | 表单id |
| fid | 1 | 是 | number | 单位id |
| formUserIds | 1,2 | 否 | string | formuserId字符串（1-100个）传formuserIds就只恢复传的formuserIds的数据 |
| operatorUid | 1 | 是 | number | 操作人id |
| callBackUrl | [http://test.com/back](http://test.com/back) | 否 | string | 任务完成回调地址；get请求，会追加 taskId（任务id），status（执行状态 1 成功，2 不成功），formId（表单id） 三个参数 |
| startTime | 2025-12-08 17:17:22 | 是 | string | 要恢复的时间段起始时间 yyyy-MM-dd HH:mm:ss |
| endTime | 2025-12-08 17:18:22 | 是 | string | 要恢复的时间段结束时间 yyyy-MM-dd HH:mm:ss 时间间隔不能超过 12 小时 |
| datetime | 2025120817 | 是 | string | yyyyMMddHH 当前时间戳 |
| enc | md5串 | 是 | string | enc=md5 排序后的参数，**如果传callBackUrl，则callBackUrl也需要参与enc加密** \[datetime=2025121112\]\[endTime=2025-12-08 17:17:22\]\[fid=125259\]\[formId=13934632\]\[formUserIds=\]\[operatorUid=1\]\[sign=sign\]\[startTime=2025-12-08 17:00:00\]\[key\] |


成功会返回任务id
```json
{"data":{"taskId":24},"success":true}
```
任务会异步执行，数据恢复完会回调，如果传了callBackUrl的话

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
