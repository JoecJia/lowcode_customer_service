**简要描述：**

- 获取表单里某个字段汇总滤重后的值(给过滤功能用)
- 支持的字段有:单行、多行、数字、日期、单选、下拉框、多选、下拉复选

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/data/field/distinct/values?fid=&formId=&formAlias=&fieldId=&fieldAlias=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
```
POST请求样例:
ContentType:application/x-www-form-urlencoded
Body数据:
fid=97253&formId=1&fieldId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705
```

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID |
|formId   |否  |int |表单Id|与formAlias参数至少要有一个有值|
|formAlias |否 |string|表单接口标识（表单别名）|与formId参数至少要有一个有值|
|fieldId   |否 |int | 字段Id |与fieldAlias参数至少要有一个有值|
|fieldAlias |否 |string |字段别名 |与fieldId参数至少要有一个有值|
|searchStr  |否  |string | 查询筛选条件,不参与加密,json格式，传入时需做URLEncode编码，注意不要二次编码,[点击查看searchStr结构](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看searchStr结构")||
|sortType |否  |int|排序规则 0正序，1倒序，-1 自定义排序   | |
|customSortRule |否  |string |  sortType 为-1时生效  | 格式：[{"sortScore":1,"value":"data1"},{"sortScore":2,"value":"data2"}]|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "msg": "[200]请求成功",
    "data": {
        "fieldValues":["选项1","选项2","选项3"]
    },
    "success": true
}
```
（2）失败

* 返回数据样例:
```
{
    "msg": "[100000]缺少单位id",
    "success": false
}
{
    "msg": "[3000]请求参数不合法",
    "success": false
}
{
    "msg": "[100003]该单位下表单不存在",
    "success": false
}
```

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021082717][fid=97253][fieldId=1][formId=1][sign=xxx]";

```
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5） 结果地址
> http://m.oa.chaoxing.com/api/apps/forms/data/field/distinct/values?fid=97253&formId=1&fieldId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
