**简要描述：**

- 表单的分组汇总统计接口

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/user/data/group/summary/statistics

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID    |高级设置页面可以查看  与formAlias参数至少要有一个有值|
|formAlias   |否  |string | 表单接口标识（表单别名） |高级设置页面可以设置 与formId参数至少要有一个有值 |
|groupFieldId  |否  |int | 分组字段ID   | 分组字段ID|
|statsFieldId  |是  |int | 统计字段ID   | 统计字段ID|
|statsType   |否  |string| 统计类型(计次,求和,最小值,最大值,平均值),默认为"count"计次|当statsFieldId为数字类型字段时,值可为"count","sum","min","max","avg";反之,statsType只能为count(计次)；另支持去重计数 `distinctCount`（SDK `StatsTypeEnum` 未含该值，截至 1.23.3 未暴露）|
|searchStr   |否  |string| 查询条件|查询筛选条件,不参与加密,json格式，传入时需做URLEncode编码，注意不要二次编码,[点击查看searchStr结构](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看searchStr结构") |
|subIndex    |否  |int| 默认为0|日期区间字段在统计时进行了拆分，故值可以为0,1,2|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|groupFieldAlias |否  |string |【groupFieldAlias】 |分组字段别名；groupFieldId <= 0 时用别名定位 |
|statsFieldAlias |否  |string |【statsFieldAlias】 |统计字段别名；statsFieldId <= 0 时用别名定位 |
|startTime |否  |string |【startTime】 |按数据创建时间起始过滤，格式 yyyy-MM-dd HH:mm:ss |
|endTime |否  |string |【endTime】 |按数据创建时间结束过滤，格式 yyyy-MM-dd HH:mm:ss |
|startUpdateTime |否  |string |【startUpdateTime】 |按数据更新时间起始过滤，格式 yyyy-MM-dd HH:mm:ss |
|endUpdateTime |否  |string |【endUpdateTime】 |按数据更新时间结束过滤，格式 yyyy-MM-dd HH:mm:ss |


**返回结果**
（1）成功 

**当有分组字段时，返回结果**
* 返回数据格式：
```json
{
    "msg": "[200]请求成功",
    "data": {
        "resultMap": {
            "班级1": {
                "value": 1000011.0
            },
            "班级2": {
                "value": 388.0
            },
            "班级3": {
                "value": 1011.0
            },
            "班级4": {
                "value": 1000.0
            }
        }
    },
    "success": true
}
```
**当没有分组字段时，返回结果**
* 返回数据格式：
```json
{
    "msg": "[200]请求成功",
    "data": {
        "resultMap": {
		     //统计字段格式:totalStcs+statsFieldId
            "totalStcs2": {
                "value": 1002410.0 //统计结果数据
            }
        }
    },
    "success": true
}
```
（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]请求失败错误信息","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid 或 fid <= 0|
|PARAMS_INVALID|statsType / subIndex / groupFieldId 非法|
|MISSING_STATS_FIELD_ALIAS|statsFieldId <= 0 且未传 statsFieldAlias|
|MISSING_STATS_FIELD_ID|未传 statsFieldId|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|[300]|统计失败，附错误文案|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2023030816][fid=109147][formId=182275][sign=xxx][statsFieldId=1][statsType=count]";
```
          
（4） MD5加密操作
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
