**简要描述：**

- 根据"查询条件"先查询出符合条件的数据,之后根据传入的"formData"参数，批量更新表单数据接口.

**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：http://m.oa.chaoxing.com/api/apps/forms/data/batch/update

HTTP Header:

Content-Type application/x-www-form-urlencoded

HTTP Body中放置请求参数，参数详情如下：

**请求参数**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |string | 单位ID    | 单位ID|
|formId   |否  |int | 表单Id    | 表单Id 与formAlias参数至少要有一个有值|
|formAlias  |否  |string | 表单接口标识（表单别名）   | 表单接口标识（表单别名） 与formId参数至少要有一个有值|
|uids   |否  |string | 提交人uids  |【更新条件】 可更新该参数指定uid提交的数据。 多值格式"uid1,uid2",以逗号分隔|
|formUserIds |否  |string | 数据行id数组 | 【更新条件】 需要更新的数据行id数组,传递此参数后,cPage和pageSize参数失效 。多值格式"1,2,3,4",以逗号分隔|
|searchStr|否(不参与加密)  |string |检索条件串 |【更新条件】 可更新满足条件的数据。参照表单高级检索接口searchStr[点击查看](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看")|
|startTime  |否  |string | 数据插入时间 参数格式 yyyy-MM-dd HH:mm:ss  | 【更新条件】 开始时间|
|endTime  |否  |string | 数据插入时间   参数格式 yyyy-MM-dd HH:mm:ss|【更新条件】  结束时间|
|startUpdateTime  |否  |string | 数据更新时间  参数格式 yyyy-MM-dd HH:mm:ss |【更新条件】  开始时间|
|endUpdateTime  |否  |string | 数据更新时间   参数格式 yyyy-MM-dd HH:mm:ss| 【更新条件】 结束时间|
|cpage  |否  |int | 页码   | 默认1|
|pageSize  |否  |int | 页数   | 默认10条|
|orderType  |否  |String | 排序类型   | 默认"desc"|
|formData|是(不参与加密)  |string | 修改的表单数据jsonArray数组 |字段值数组[{字段值1},{字段值2}],传入时需做URLEncode编码，注意不要二次编码,[点击查看formData结构](https://cxapi.chaoxing.com/web/#/653656579/207985736 "点击查看formData结构")注意附件字段的puid参数，要传入附件上传人的puid，否则可能无法预览；若附件中的puid没传，默认使用接口传递的uid参数，可能会影响附件的预览，请酌情使用|
|autoSendData|否 |int    |默认为1|1:可触发数据推送，0:不触发数据推送|
|autoFilterErrorFields|否 |boolean    |默认为false|开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|operatorUid |否  |long |【operatorUid】 |操作人 uid，用于记录本次更新的操作人 |
|operationRecord |否  |string |【operationRecord】 |操作记录，最长100字符 |
|comptVerify |否  |boolean |【comptVerify】 |是否执行组件校验，默认 true |
查询条件参数不能全部为空

**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|data|更新失败的数据放入failedList列表中.例如:```{"failedList:"{"formUserId":"1000","msg":"comptId=1 字段数据验证不通过"}```
|success|true/false
|msg|提示语.例如"批量更新成功2条"
|data.failedList[] |更新失败的行，元素为 `{formUserId, msg}` |

**返回结果**
（1）批量更新成功

* 全部更新成功返回数据格式：
```json
   {
       "msg": "[200]批量更新成功10条",
       "success": true
   }
```
* 部分更新成功返回数据格式：
```json
   {
       "msg": "[200]批量更新成功2条",
	   "data"{"failedList":"{"formUserId":"1000","msg":"comptId=1 字段数据验证不通过"}}
       "success": true
   }
```
（2）批量更新失败时 将失败数据放入"failedList"列表中 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[200]批量更新成功0条","data"{"failedList:"{"formUserId":"1000","msg":"comptId=1 字段数据验证不通过"}}"success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid 或 fid <= 0|
|PARAMS_INVALID|autoSendData 不是 0/1；formUserIds 超过 100 个；searchStr 非法|
|SEARCH_OUT_OF_RANGE|检索范围超出限制|
|NO_DATA|没有命中可更新的数据|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|FORM_DATA_INVALID|formData 不是合法 JSON 数组|
|FORM_DATA_NOT_EMPTY|formData 解析后为空|
|FORM_DATA_NO_EFFECTIVE_DATA|过滤后无有效字段|
|[500]|服务端异常|

**接口参数配置**(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[cpage=3][datetime=2021081117][fid=97253][formId=51000][formUserIds=90205,90204][pageSize=10][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
