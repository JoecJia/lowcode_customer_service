**简要描述：**
- 根据"查询条件"先查询出符合条件的数据,批量删除表单数据接口.

**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：http://m.oa.chaoxing.com/api/apps/forms/data/batch/delete

HTTP Header:

Content-Type application/x-www-form-urlencoded

HTTP Body中放置请求参数，参数详情如下：

**请求参数**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:----|-----------   |
|fid   |是  |string | 单位ID    | 单位ID|
|formId   |否  |int | 表单Id    | 表单Id 与formAlias参数至少要有一个有值|
|formAlias  |否  |string | 表单别名（表单接口标识）   | 表单接口标识（表单别名）与formId参数至少要有一个有值|
|formUserIds   |否  |string | 需要删除的数据行id,传此参数后,pageSize参数失效  | 多值格式"1,2,3,4",以逗号分隔。 最多支持100个行id|
|uids   |否  |string | 提交人uids  | 多值格式"uid1,uid2",以逗号分隔。如果传值，会删掉uid作为提交人的数据，删除的条数按pageSize参数的值|
|operatorUid   |否  |int | 操作人uid  | 用于记录此次删除记录的操作人|
|autoSendData|否 |int    |默认为1|1:可触发数据推送，0:不触发数据推送|
|startTime  |否  |string | 数据插入开始时间  参数格式 yyyy-MM-dd HH:mm:ss | 与endTime配套使用，删除startTime到endTime时间范围内提交的数据|
|endTime  |否  |string | 数据插入结束时间  参数格式 yyyy-MM-dd HH:mm:ss | 与startTime配套使用，删除startTime到endTime时间范围内提交的数据|
|startUpdateTime  |否  |string | 数据更新开始时间  参数格式 yyyy-MM-dd HH:mm:ss | 与endUpdateTime配套使用，删除startUpdateTime到endUpdateTime时间范围内更新的数据|
|endUpdateTime  |否  |string | 数据更新结束时间  参数格式 yyyy-MM-dd HH:mm:ss | 与startUpdateTime配套使用，删除startUpdateTime到endUpdateTime时间范围内更新的数据|
|searchStr|否(不参与加密)  |string | 查询条件   |传入时需做URLEncode编码，注意不要二次编码,[点击查看searchStr结构](https://cxapi.chaoxing.com/web/#/653656579/207985738 "点击查看searchStr结构")|
|pageSize  |否  |int | 页数，默认10，最大100  |一次性删除查询结果中的前N条 |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|orderType |否  |string |【orderType】 |排序方向，决定“删除查询结果前 N 条”取哪一端 |
|operationRecord |否  |string |【operationRecord】 |操作记录，最长100字符 |

**返回结果**
（1）成功

* 返回数据格式：
```json
   {
       "msg": "[200]批量删除成功",
       "success": true
   }
```
（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]批量删除失败","success":false}
```

**补充返回字段：**

|字段|说明|
|:---|:---|
|data.totalCount|有剩余数据或总条数时返回；SDK 1.19.5 起可读|
|msg|无数据被删除时返回 `[200]数据已被删除`，`success` 仍为 true|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid 或 fid <= 0|
|PARAMS_INVALID|autoSendData 不是 0/1；formUserIds 超过 100 个；searchStr 字段不存在|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|operationRecord参数内容限制100字符|operationRecord 超过 100 字符|
|[500]|服务端异常|

**接口参数配置**(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2020090916][formUserIds=9760][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
