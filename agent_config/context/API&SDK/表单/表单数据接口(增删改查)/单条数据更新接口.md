**简要描述：**

 根据单位ID和数据行ID修改表单数据接口

**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：http://m.oa.chaoxing.com/api/apps/forms/data/update

HTTP Header:

Content-Type application/x-www-form-urlencoded

HTTP Body中放置请求参数，参数详情如下：

**请求参数**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位id    | 单位id|
|formId   |否  |int | 表单id    | 与formAlias任传一个|
|formAlias   |否  |string | 表单接口标识   | 与formId任传一个|
|formUserId   |是  |long | 表单用户填写id    | 数据表行id|
|aprvStatus   |否  |int | 表单审核状态(表单开启审核后可传此参数)    | 0:未审核 1：通过 2:不通过|
|autoSendData|否 |int    |默认为1|1:可触发数据推送，0:不触发数据推送|
|operatorUid   |否  |int | 操作人uid  | 用于记录此次修改数据的操作人|
|autoFilterErrorFields|否 |boolean    |默认为false|开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；
|checkRequired  |否  |boolean | 控制数据的必填校验是否开启，默认为开启true|控制数据的必填校验是否开启，默认为开启true|
|formData|是(不参与加密)  |string | 修改的表单数据jsonArray数组  |字段值数组[{字段值1},{字段值2}],传入时需做URLEncode编码，注意不要二次编码,[点击查看formData结构](https://cxapi.chaoxing.com/web/#/653656579/207985736 "点击查看formData结构")注意附件字段的puid参数，要传入附件上传人的puid，否则可能无法预览；若附件中的puid没传，默认使用接口传递的uid参数，可能会影响附件的预览，请酌情使用|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|operationRecord |否  |string |【operationRecord】 |操作记录，最长100字符；写入数据操作日志 |
|comptVerify |否  |boolean |【comptVerify】 |是否执行组件校验，默认 true |
|defaultValueRules |否  |string |【defaultValueRules】 |默认值规则，影响更新时默认值的计算 |

**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|success| true/false
|msg|修改成功/失败

**返回结果**
（1）成功

* 返回数据格式：
```json
   {
       "msg": "[200]修改成功",
       "success": true
   }
```
（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]修改失败","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid 或 fid <= 0|
|MISSING_FORM_USER_ID|未传 formUserId|
|PARAMS_INVALID|aprvStatus 不是 0/1/2，或 autoSendData 不是 0/1|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|FORM_CONFIG_NOT_EXIST|表单配置不存在|
|FORM_DATA_INVALID|formData 不是合法 JSON 数组|
|FORM_DATA_NOT_EMPTY|formData 解析后为空|
|FORM_DATA_NO_EFFECTIVE_DATA|过滤后无有效字段|
|operationRecord参数内容限制100字符|operationRecord 超过 100 字符|
|[500]|服务端异常|

**接口参数配置**(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[checkRequired=false][datetime=2020090916][fid=1][formUserId=9760][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
