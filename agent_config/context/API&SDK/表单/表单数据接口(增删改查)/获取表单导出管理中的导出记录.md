

##### 请求URL


* `http://m.oa.chaoxing.com/api/apps/forms/data/export/list`


##### 请求方式


* get/post


##### 请求Body参数


| 参数名 | 示例值 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| uid |  | 否 | number | uid 用户uid |
| fid |  | 是 | number | fid 单位id |
| formAlias |  | 否 | string | 表单别名 |
| formId |  | 否 | number | 表单id |
| pageSize |  | 否 | number | 分页大小 |
| cpage |  | 否 | number | 当前页码 |
| sign |  | 是 | string | 申请的sign |
| datetime |  | 是 | string | 当前时间串yyyyMMDDHH |
| enc |  | 是 | string | 校验参数 |
|startTime | |否 |string |按导出时间起始过滤，格式 yyyy-MM-dd HH:mm:ss |
|endTime | |否 |string |按导出时间结束过滤，格式 yyyy-MM-dd HH:mm:ss |

##### 备注

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|fid不能为空|未传 fid|
|pageSize不能小于1|pageSize < 1|
|cpage不能小于1|cpage < 1|
|开始时间x参数错误|startTime 格式非法|
|结束时间x参数错误|endTime 格式非法|
|接口异常异常|服务端异常|

**接口参数配置**
（1）接口标识


> sign=xxx


（2）加密秘钥


> key=xxx


（3）加密原文字符串
除sign参数和enc 参数外，用到哪个参数就把哪个参数加进去，格式如下，按字典序排序


> source="[fid=97253][sign=xxx]";


（4） MD5加密操作


> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合


* 例如：[a=1][b=2][c=3][ei=4][ej=5]


（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合


* 例如：[a=1,2,3,4,5,6]
