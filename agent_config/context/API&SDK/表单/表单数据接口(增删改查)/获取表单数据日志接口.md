| --- | --- | --- | --- | --- |

| formAlias |  | 否 | string | 表单别名，别名id至少写一个 |
| formId |  | 否 | number | 表单id，别名id至少写一个 |
| pageSize |  | 否 | number | 分页大小 |
| cpage |  | 否 | number | 当前页码 |

| datetime |  | 是 | string | 当前时间串yyyyMMDDHH |
| enc |  | 是 | string | 校验参数 |
|version | |否 |string |SDK 版本号；达到阈值时走新版校验，要求 formId / formAlias 至少一个 |

##### 备注

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|[100000]缺少单位id|未传 fid|
|MISSING_FORM_USER_ID|未传 formUserId|
|PARAMS_INVALID|表单id和表单别名不能同时为空|
|[300]|请求失败，附错误文案|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|NO_DATA|无数据日志|
|[500]|服务端异常|

**接口参数配置**
（1）接口标识


> sign=xxx


（2）加密秘钥


> key=xxx


（3）加密原文字符串
除sign参数和enc 参数外，用到哪个参数就把哪个参数加进去，格式如下，按字典序排序


> source="[fid=97253][sign=xxx]";


（4） MD5加密操作


> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合


* 例如：[a=1][b=2][c=3][ei=4][ej=5]


（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合


* 例如：[a=1,2,3,4,5,6]
