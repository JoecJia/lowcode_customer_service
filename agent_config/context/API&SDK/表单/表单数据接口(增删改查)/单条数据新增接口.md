**简要描述：**
- 在表单里插入新的数据，插入成功后返回对应的行id。

**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：http://m.oa.chaoxing.com/api/apps/forms/data/add

HTTP Header:

Content-Type application/x-www-form-urlencoded

HTTP Body中放置请求参数，示例详情如下:
```
ContentType:application/x-www-form-urlencoded
Body数据(以下只是样例,参数的数据需要替换):
fid=1385&uid=111&formId=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705&formData=%5B%0A%20%20%20%20%7B%0A%20%20%20%20%20%20%20%20%22alias%22%3A%20%221%22%2C%0A%20%20%20%20%20%20%20%20%22compt%22%3A%20%22editinput%22%2C%0A%20%20%20%20%20%20%20%20%22values%22%3A%20%5B%0A%20%20%20%20%20%20%20%20%20%20%20%20%7B%0A%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%22val%22%3A%20%22111%22%0A%20%20%20%20%20%20%20%20%20%20%20%20%7D%0A%20%20%20%20%20%20%20%20%5D%0A%20%20%20%20%7D%2C%0A%20%20%20%20%7B%0A%20%20%20%20%20%20%20%20%22alias%22%3A%20%222%22%2C%0A%20%20%20%20%20%20%20%20%22compt%22%3A%20%22numberinput%22%2C%0A%20%20%20%20%20%20%20%20%22values%22%3A%20%5B%0A%20%20%20%20%20%20%20%20%20%20%20%20%7B%0A%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%22val%22%3A%20%22222%22%0A%20%20%20%20%20%20%20%20%20%20%20%20%7D%0A%20%20%20%20%20%20%20%20%5D%0A%20%20%20%20%7D%0A%5D 
```

HTTP Body中放置请求参数，参数详情如下：

**请求参数**

|参数名称|是否必填|参数类型|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位Id|
|uid      |是  |int | 提交人uid |
|uuid      |否  |string | uuid,调用方业务唯一id，可以防止数据重复提交 |
|formId   |否  |int | 表单ID  与formAlias参数至少要有一个有值 |
|formAlias  |否  |string | 表单接口标识(表单别名)  与formId参数至少要有一个有值 |
|autoSendData|否 |int    |默认为1可触发数据推送，0:不触发数据推送|
|autoFilterErrorFields|否 |boolean    |默认为false,开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；
|operationRecord|否|string|操作记录，最长100字符；超过限制返回“operationRecord参数内容限制100字符”；写入数据操作日志|
|comptVerify|否|boolean|是否执行组件校验，默认 true|
|updatetime|否|string|自定义数据时间，格式 yyyy-MM-dd HH:mm:ss.SSS；传值时优先作为数据的 inserttime/updatetime，格式错误时忽略并使用服务端当前时间|
|source|否|string|数据来源标识，透传给数据保存链路，默认空|
|flowId|否|string|关联流程 id，透传给数据保存链路，默认空|
|flowName|否|string|关联流程名称，透传给数据保存链路，默认空|
|checkRequired  |否  |boolean | 控制数据的必填校验是否开启，默认为开启true|
|formData|是(不参与加密)|string | 新增的表单数据jsonArray数组，字段值数组[{字段值1},{字段值2}]，详细结构如下。传入时需做URLEncode编码，注意不要二次编码,[点击查看formData结构](https://cxapi.chaoxing.com/web/#/653656579/207985736 "点击查看formData结构")，注意附件字段的puid参数，要传入附件上传人的puid，否则可能无法预览；若附件中的puid没传，默认使用接口传递的uid参数，可能会影响附件的预览，请酌情使用|
|defaultValueConfig|否|string|{ "enable": true,  // 必填，是否触发接口默认值计算（核心开关）"onlyFormData":false, // true=只处理 formData 中显式传了 "defaultValue": true 的字段；false=扫描全表配置，所有为空/缺失的默认值字段都补算 "enableDetailOverall": false // true=允许子表单父组件整体触发默认值；false=只按子表单内部字段逐行补算}
|datetime |是  |string |格式：yyyyMMddHH|
|sign     |是  |string | 接口标识 ， 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串，采用md5加密方式进行生成|


**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|data|返回新增成功的数据 ```{"formUserId":9826}``` 该数据在表单里的行id， 修改，删除将会使用该值。
|data.formUserId（失败时）|`uuid` 重复（`DATA_ID_EXISTS`）时 `success=false`，仍返回已存在数据的行 id ```{"formUserId":9826}```|
|success|新增成功/失败标识,true/false
|msg|提示语 如 "保存成功"

**返回结果**
（1）成功

* 返回数据格式：
```json
   {
       "msg": "[200]保存成功",
	   "data": {
           "formUserId": 9826    //该数据在表单里的行id， 修改，删除将会使用该值。
       },
       "success": true
   }
```
（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```json
{"msg":"[300]保存失败","success":false}
```

常见失败返回（msg 为“业务码 + 文案”）：

|业务码|触发条件|
|:---|:---|
|MISSING_FID|未传 fid 或 fid <= 0|
|MISSING_UID|uid <= 0（默认 -1）|
|PARAMS_INVALID|autoSendData 不是 0/1；defaultValueConfig 不是合法 JSON|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|FORM_DATA_INVALID|formData 不是合法 JSON 数组|
|FORM_DATA_NOT_EMPTY|formData 解析后为空数组|
|DATA_ID_EXISTS|uuid 重复；返回体带 data.formUserId|
|FORM_DATA_NO_EFFECTIVE_DATA|autoFilterErrorFields=true 且过滤后无有效字段|
|SERVER_ERROR|服务端异常|
|operationRecord参数内容限制100字符|operationRecord 长度超过 100|
|您所访问的应用正在升级中|应用正在升级|
|缺少sign参数 / 缺少enc参数 / enc参数验证失败 / 接口暂未开通 / 无此单位权限！|鉴权层校验失败|

**接口参数配置**
（1）接口标识
> sign=xxx   由超星办公系统方分配

（2）加密秘钥
> key=xxx    由超星办公系统方分配

（3）加密原文字符串
```
> source="[checkRequired=false][datetime=2020090916][fid=1385][formId=1][sign=xxx][uid=111]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） enc的生成样例
> enc=md5([checkRequired=false][datetime=2020090916][fid=1385][formId=1][sign=xxx][uid=111][分配的key值]);
enc的获取:可使用此链接进行md5加密测试，取其32位小写即可https://md5jiami.bmcx.com/

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]

（3）参与 enc 的参数范围

> 除 `formData` 外的全部请求参数都参与加密，包括 `uuid`、`autoSendData`、`autoFilterErrorFields`、`checkRequired`、`operationRecord`、`comptVerify`、`updatetime`、`source`、`flowId`、`flowName`；未传入的参数不参与拼接。拼接规则：参数名按字典序排列，每项为 `参数名=参数值`，多值用英文逗号连接，最后追加分配的 key 后取 MD5 32 位小写。
