**简要描述：**

表单批量插入数据接口

**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：http://m.oa.chaoxing.com/api/apps/forms/data/batch/add

HTTP Header:

Content-Type application/x-www-form-urlencoded

HTTP Body中放置请求参数，参数详情如下：

**请求参数**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    | 单位ID|
|uid   |是  |int | 提交人uid  | 用户passportId|
|formId   |否  |int | 表单Id    | 表单Id 与formAlias参数至少要有一个有值|
|autoSendData|否 |int    |默认为1|1:可触发数据推送，0:不触发数据推送|
|autoFilterErrorFields|否 |boolean    |默认为false|开启后，可自动过滤formData中的错误字段，比如字段不再当前表单中，字段别名和id错误均会自动过滤掉，只添加正确且存在于当前表单中的字段；
|formAlias  |否  |string | 表单接口标识（表单别名）   | 表单接口标识（表单别名）与formId参数至少要有一个有值|
|formData|是(不参与加密)  |string | 表单多行数据（二维数组)    |[点击查看formData结构](https://cxapi.chaoxing.com/web/#/653656579/207985737 "点击查看formData结构")注意附件字段的puid参数，要传入附件上传人的puid，否则可能无法预览；若附件中的puid没传，默认使用接口传递的uid参数，可能会影响附件的预览，请酌情使用|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|operationRecord |否  |string |【operationRecord】 |操作记录，最长100字符；超过限制返回“operationRecord参数内容限制100字符” |
|comptVerify |否  |boolean |【comptVerify】 |是否执行组件校验，默认 true |

**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|data| 返回的数据说明 新增成功的数据存入formUserIdList中.例如```"formUserIdList": [91025,91026,91027,91028,91029,91030,91031,91032,91033,91034]``` 修改，删除将会使用该值。新增失败的数据会放入failedList中.例如:```"failedList:"{"dataIndex":0,"msg":"第0行:comptId=1 字段数据验证不通过"}```
|success|新增成功/失败标识,true/false
|msg|提示语 如 "批量插入成功10条"
|data.succeedList |实际返回的新增成功列表，元素含 `formUserId`（行id）、`dataIndex`、`detailUrl`；文档示例中的 `formUserIdList` 不存在 |
|succeedList[].dataIndex |新增行下标，SDK 1.0 起支持 |
|succeedList[].detailUrl |数据详情页地址，SDK 1.23.3 起可拿到值 |
|data.failedList[] |失败行列表，元素为 `{dataIndex, msg}` |

**返回结果**
（1）批量插入成功

* 全部插入成功返回数据格式：
```json
   {
       "msg": "[200]批量插入成功10条",
	   "data": {
        "formUserIdList": [
            91025,91026,91027,91028,91029,91030,91031,91032,91033,91034
        ]
    },
    "success": true
   }
```
* 部分插入成功返回数据格式：
```json
   {
       "msg": "[200]批量插入成功2条",
	   "data"{"failedList":"{"dataIndex":0,"msg":"第0行:comptId=1 字段数据验证不通过"}}
       "success": true
   }
```
（2）批量插入失败时 将失败数据放入"failedList"列表中 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[200]批量插入成功0条","data"{"failedList:"{"dataIndex":0,"msg":"第0行:comptId=1 字段数据验证不通过"}}"success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid 或 fid <= 0|
|MISSING_UID|未传 uid 或 uid <= 0|
|PARAMS_INVALID|autoSendData 不是 0/1|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|operationRecord参数内容限制100字符|operationRecord 超过 100 字符|
|[300]操作失败|全部行失败，附 data.failedList|
|[500]|服务端异常|

**接口参数配置**(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[datetime=2021081117][fid=97253][formId=51000][sign=xxx]";

（4） MD5加密操作，生成enc参数
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
