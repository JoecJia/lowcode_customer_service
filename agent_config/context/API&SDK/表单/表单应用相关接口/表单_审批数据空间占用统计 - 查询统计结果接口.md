# 表单/审批数据空间占用统计 - 查询统计结果接口


**简要描述：**


- 按任务 ID 查询统计结果，同一 taskId 支持多次重复查询。
- 采用 `sign + enc + datetime` 鉴权，`sign` 需为超星办公系统分配的 `appsFormsDataStatistics_*` 类型接口标识。


**请求URL：**


- http://m.oa.chaoxing.com/api/apps/forms/data/space/statistics/search


**请求方式：**


- GET、POST 均可


**参数说明：**


| 参数名称 | 是否必填 | 参数类型 | 参数标识 | 参数说明 |
|:---|:---|:---|:---|:---|
| fid | 是 | int | 单位 ID | 单位 fid，须与任务所属单位一致 |
| taskId | 是 | string | 任务 ID | 触发统计接口返回的任务 ID |
| datetime | 是 | string | 生成加密串时间 | 格式：yyyyMMddHH |
| sign | 是 | string | 接口标识 | 由超星办公系统提供 |
| enc | 是 | string | 接口参数加密串 | 采用 md5 加密方式生成 |

    "video": { "bytes": 52428800, "kb": 51200.00, "mb": 50.00, "gb": 0.0488, "count": 4 },
    "audio": { "bytes": 0, "kb": 0.00, "mb": 0.00, "gb": 0.0000, "count": 0 },

（2）失败


```json
{ "success": false, "msg": "任务不存在" }
```


常见失败提示：`fid缺失`、`taskId缺失`、`enc参数验证失败` 等。


**data 字段说明：**


| 字段 | 类型 | 说明 |
|:---|:---|:---|
| taskId | string | 任务 ID |
| taskStatusCode | int | 任务状态码：0 排队中 / 1 计算中 / 2 成功 / 3 失败 / 4 已暂停 |
| taskStatus | string | 任务状态中文名：排队中/计算中/成功/失败/已暂停 |
| startTime | string | 任务开始时间（yyyy-MM-dd HH:mm:ss，排队中为 null） |
| endTime | string | 任务结束时间（终态才有值，进行中为 null） |
| durationMs | long | 耗时（毫秒，起止时间均有值时才有） |
| failReason | string | 失败原因 |
| totalCount | long | 总数据条数 |
| total | object | 总占用：bytes/kb/mb/gb |
| image / video / audio / doc / otherAtt | object | 各类附件占用：bytes/kb/mb/gb + count（文件个数） |
| fieldValue | object | 其他字段值占用：bytes/kb/mb/gb |


**接口参数配置：**


（1）接口标识类型


> sign=appsFormsDataStatistics_*


（2）加密秘钥


> key=xxx


（3）加密原文字符串


参数按名称的字母序排列（含 fid、datetime、sign 等，除 enc 外的全部请求参数均参与），示例：


```text
source="[datetime=2025091714][fid=63555][sign=appsFormsDataStatistics_xxx][taskId=space_stat_63555_1726550400000_a1b2c3]";
```


（4）MD5 加密操作


```text
enc=md5(source+[key]);
```


（5）结果地址


```text
http://m.oa.chaoxing.com/api/apps/forms/data/space/statistics/search?fid=63555&taskId=space_stat_63555_1726550400000_a1b2c3&datetime=2025091714&sign=appsFormsDataStatistics_xxx&enc=xxx
```


**注意事项：**


1. 同一 `taskId` 支持多次重复查询，结果为聚合后的最终统计口径。
2. `fid` 必须与任务所属单位一致，任务不存在或单位不匹配统一返回“任务不存在”。
3. 生成 `enc` 时，参数名必须按字母序排列，并包含除 `enc` 外的全部请求参数；多值参数使用英文逗号组合。
4. `sign` 必须是该第三方已授权的接口标识，且仅可操作授权单位下的应用，否则无权调用。
