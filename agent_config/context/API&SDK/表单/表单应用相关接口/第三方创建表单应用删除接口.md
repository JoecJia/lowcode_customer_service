**简要描述：**

- **<font color="#dd0000">**注意：微服务创建的表单应用不可通过此接口删除！！！**</font>**

- 第三方创建表单应用删除接口

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/app/delete

**请求方式：**
- GET,POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位id    |微服务设置里可以查看|
|formId   |否  |int | 表单id    |和appName只传一个即可|
|appName   |否  |string | 表单接口标识（别名) |和formId只传一个即可|
|operatorUid|是  |int | 操作人uid |操作人uid|
|formType |是  |int | 表单类型 | 1：审批 2：表单，默认为2|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 应用授权sign    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回结果**
（1）成功

* 返回数据格式：
```json
    {"msg": "删除成功","success": true}
```

（2）失败

* 返回数据格式：
```json
   {"msg":"删除失败","success":false}
```

**接口参数配置**
（1）接口标识
> sign="appsFormsData_*" 由超星办公系统方分配

（2）加密秘钥
> key=xxx 由超星办公系统方分配

（3）加密原文字符串
```
> source="[datetime=2020092718][fid=109147][formId=2712][sign=appsFormsData_*]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/apps/forms/app/delete?datetime=2020092718&fid=109147&sign=sign=appsFormsData_*&enc=17bd5b2cd2e0c412f35fc304345e3f1d&formId=2712

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
