# 表单/审批数据空间占用统计 - 触发统计接口

**简要描述：**

- 提交一批表单/审批应用的空间占用统计任务，任务异步执行，结果通过「查询统计结果」接口或 `callbackUrl` 回调获取。
- 采用 `sign + enc + datetime` 鉴权，`sign` 需为超星办公系统分配的 `appsFormsDataStatistics_*` 类型接口标识。

**请求URL：**

- http://m.oa.chaoxing.com/api/apps/forms/data/space/statistics/trigger

**请求方式：**

- GET、POST 均可

**参数说明：**

| 参数名称 | 是否必填 | 参数类型 | 参数标识 | 参数说明 |
|:---|:---|:---|:---|:---|
| fid | 是 | int | 单位 ID | 单位 fid，须为 sign 已授权单位 |
| formType | 是 | int | 应用类型 | 0 表示自定义表单，1 表示审批；仅支持这两类，信息查询/图表不支持 |
| formIds | 否 | string | 表单 ID 集合 | 逗号分隔，与 formAlias 至少传一个；formIds 优先 |
| formAlias | 否 | string | 表单别名 | 支持逗号分隔多个，与 formIds 至少传一个 |
| operatorUid | 是 | long | 操作人 ID | 操作人 UID |
| callbackUrl | 否 | string | 回调地址 | 任务结束后 POST JSON 回调该地址，可空 |
| datetime | 是 | string | 生成加密串时间 | 格式：yyyyMMddHH |
| sign | 是 | string | 接口标识 | 由超星办公系统提供 |
| enc | 是 | string | 接口参数加密串 | 采用 md5 加密方式生成 |

（4）失败

```json
{ "success": false, "msg": "formIds与formAlias不能同时为空" }
```

常见失败提示：`fid缺失`、`formType不合法，仅支持 0(表单)/1(审批)`、`formIds格式不合法`、`表单别名不存在: xxx`、`表单不存在或参数缺失`、`表单数量超出限制，单次最多 50 个`、`表单不存在: 111,222`、`数据总量超出限制，当前总数据条数: xxx，最大允许: 500000`、`任务提交异常，请稍后重试`、`enc参数验证失败` 等。

**结果回调（callbackUrl 非空时）：**

任务执行结束后（成功/失败/已暂停），服务端以 POST 方式向 `callbackUrl` 推送 JSON（Content-Type：application/json），失败重试 3 次（指数退避）：

```json
{
  "taskId": "space_stat_63555_1726550400000_a1b2c3",
  "fid": 63555,
  "formType": 0,
  "taskStatusCode": 2,
  "taskStatus": "成功",
  "failReason": null,
  "statistics": {}
}
```

**接口参数配置：**

（1）接口标识类型

> sign=appsFormsDataStatistics_*

（2）加密秘钥

> key=xxx

（3）加密原文字符串

参数按名称的字母序排列（含 fid、datetime、sign 等，除 enc 外的全部请求参数均参与），示例：

```text
source="[callbackUrl=http://xxx][datetime=2025091714][fid=63555][formAlias=myForm][formIds=][formType=0][operatorUid=73361131][sign=appsFormsDataStatistics_xxx]";
```

（4）MD5 加密操作

```text
enc=md5(source+[key]);
```

（5）结果地址

```text
http://m.oa.chaoxing.com/api/apps/forms/data/space/statistics/trigger?fid=63555&formType=0&formAlias=myForm&operatorUid=73361131&callbackUrl=http://xxx&datetime=2025091714&sign=appsFormsDataStatistics_xxx&enc=xxx
```

**注意事项：**

1. `formType` 仅支持 `0`（自定义表单）与 `1`（审批），其余取值（含不传）直接拒绝。
2. `formIds` 与 `formAlias` 不能同时为空；两者都传时以 `formIds` 为准。`formIds` 中任一非法值会使整体判定为格式错误。
3. 单次请求表单数量上限为 50 个，超出直接拒绝。
4. 单次请求数据总量上限默认 500000 条，超出直接拒绝；运维可通过 Redis key `office:forms:space:stat:max_total_count` 动态调整。
5. 任务级去重：相同参数（fid + formType + 排序去重后的 formIds）的任务在排队中/计算中时，不新建任务，返回进行中任务的 taskId。
6. 结果复用：相同参数且 12 小时内有成功任务时，直接返回上一次 taskId 及统计结果（`reuse=true`）；部分 formId 命中复用时仅扫描剩余 formId。
7. 生成 `enc` 时，参数名必须按字母序排列，并包含除 `enc` 外的全部请求参数；多值参数使用英文逗号组合。
8. `sign` 必须是该第三方已授权的接口标识，且仅可操作授权单位下的应用，否则无权调用。
