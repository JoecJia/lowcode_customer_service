**简要描述：**

- 表单的应用名称设置修改接口，如下图，可对应用名称进行设置修改
![表单应用名称](http://document.chaoxing.com/server/index.php?s=/api/attachment/visitFile&sign=aa445d8f254ea22c3990d8509a79e3a6 "表单应用名称")

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/app/name/set

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID  | 与formAlias传一个即可|
|formAlias  |否  |string | 表单别名  | 与formId传一个即可|
|uid   |是  |int  | 当前操作人uid | 当前操作人uid|
|name |是|string|应用名称|限制1-100个字|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口验证参数,生成规则在下面的'接口参数配置'处查看    |生成enc值的参数名称列表必须通过字母a-z的顺序依次组合 |

**返回结果**
（1）成功

* 返回数据格式：
```json
  {
      "msg": "[200]设置成功",
      "success": true
  }
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]设置失败","success":false}
```
**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2023082410][fid=109147][formId=182275][name=helloWorld][sign=xxx][uid=47101001]";
```
（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
