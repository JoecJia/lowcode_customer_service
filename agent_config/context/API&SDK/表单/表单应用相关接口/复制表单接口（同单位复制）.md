**简要描述：**

- 根据单位fid和表单Id表单复制接口

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/app/copy?deptId=&formId=&datetime=&sign=&enc=

**请求方式：**
- GET,POST均可

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|
|deptId   |是  |int | 单位ID    |单位fid|
|formId   |是  |int | 原表单ID    |原表单ID|
|appName |否  |string |【appName】 |表单别名；formId <= 0 时用它定位原表单 |

 **返回参数说明**

|参数名|类型|说明|
|:-----  |:-----|-----                           |
|formId |int   |新的表单id  |
|applyUrl |String   |填写页地址  |
|manageUrl |String   | 后台数据管理页地址  |


**返回结果**
（1）成功

* 返回数据格式：
```json
    {
        "data": {
            "formId": 3145,
            "applyUrl": "http://t.chaoxing.com/front/apps/forms/fore/apply?id=3145&formAppId=&enc=f07832279ee897c00e2a9c48f2632e0c",
            "manageUrl": "http://m.chaoxing.com/api/manager/micro/user/login/gopage?fid=63555&uid=73361131&appSign=4_183153_183153&inner=1&dataCenter=0&appEnc=0414a58ba6a2b792bbf11130b1fb0be9&enc=504a0940d484522869cbfccd5fb448e9"
        },
        "success": true
    }
```
（2）失败

* 返回数据格式：{"msg":"验证失败","success":false}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|表单id和表单别名不能同时为空|formId <= 0 且 appName 为空|
|单位id不能为空|未传 deptId|
|授权sign不能为空|未传 sign|
|授权sign不正确|sign 未在第三方配置中登记|
|要复制的自定义表单不存在|appName / formId 定位不到表单|
|表单配置异常|表单配置缺失|
|复制表单失败|复制链路失败|
|复制失败|复制链路失败|
|自定义表单复制接口异常|服务端异常|

**接口参数配置**
（1）接口标识类型
> sign= appsFormsData_*

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[datetime=2019040818][deptId=xxx][formId=xxx][sign=xxx]";
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5）结果地址
> http://m.oa.chaoxing.com/api/apps/forms/copy?deptId=97253&formId=3096&datetime=2021011110&sign=appsFormsData_yjsjwglxt&enc=a110fef32e8c18402a18d414b4cfc90c

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
