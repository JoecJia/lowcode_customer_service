**简要描述：**

- 根据单位fid和表单Id集合表单复制接口

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/app/batchcopy?originalFid=&fid=&uid=&formIds=&aprvIds=&treeIds=&chartIds=&datetime=&sign=&enc=

**请求方式：**
- GET,POST均可

**参数说明：**

|参数名称| 是否必填 |参数类型|参数名称|参数说明|
|:----    |:-----|:----- |:-----   |-----   |
|file     | 否    |MultipartFile |升级包zip文件   | 格式：MultipartFile（升级包zip方式不支持表单数据复制）|
|datetime | 是    |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     | 是    |string | 接口标识    | 由超星办公系统方提供|
|enc      | 是    |string | 接口参数加密串    |采用md5加密方式进行生成|
|formIds  | 否    |string | 复制表单ID集合(file方式不传入)   | 表单ID集合，如："1,2"|
|aprvIds  | 否    |string | 复制审批ID集合(file方式不传入)   | 审批ID集合，如："1,2"|
|treeIds  | 否    |string | 复制分类树ID集合    | 分类树ID集合，如："1,2"|
|chartIds  | 否    |string | 复制图表ID集合    | 图表ID集合，如："1,2"|
|originalFid   | 是    |int | 原表单所属单位ID    |单位fid|
|fid      | 是    |int | 当前单位ID    |单位fid|
|uid      | 是    |int | 当前单位管理员ID    |用户uid|
|isCopyData      | 否    |int | 是否复制表单数据    |1.需要复制，默认不复制|
|copyDataFormIds | 否    |string | 指定复制表单数据的表单ID集合，仅当isCopyData=1且此参数不为空且值存在于formIds（当前复制表单批次中）才进行表单数据复制 | 如："1,2"|

 **返回参数说明**

|参数名|类型|说明|
|:-----  |:-----|-----                   |
|statusKey |   | 查询复制状态key |
|linkMaps   |   | 新老表单对应关系|
|linkAprvMaps |   | 新老审批对应关系 |
|chartConfigMaps |   | 新老图表对应关系 |
|typeTreeConfigMaps |   | 新老分类树对应关系 |
|data.statusKey |- |异步复制任务标识；当前无按 statusKey 查询进度的接口 |

* 返回数据格式：{"msg":"验证失败","success":false}

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|缺少uid或fid参数|uid / fid 缺失|
|复制目标ID集合不能为空|formIds / aprvIds / treeIds / chartIds 全空|
|当前单位存在该应用，请稍后操作|并发复制冲突|
|当前单位正在复制应用，请稍后操作|并发复制冲突|
|批量复制失败|复制链路失败|
|批量复制接口异常|服务端异常|

**接口参数配置**
（1）接口标识类型
> sign=appsFormsData_*

（2）加密秘钥
> key=xxx

（3）加密原文字符串
> source="[aprvIds=xxx][chartIds=xxx][datetime=2019040818][fid=xxx][formIds=xxx][originalFid=xxx][sign=xxx][treeIds=xxx][uid=xxx]...";
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5）结果地址
> http://m.oa.chaoxing.com/api/apps/forms/app/batchcopy?fid=63555&uid=73361131&datetime=2021031616&originalFid=1385&sign=appsFormsData_yjsjwglxt
&formIds=1%2C2%2C3&aprvIds=1%2C2%2C3&chartIds=1%2C2%2C3&treeIds=1%2C2%2C3&enc=5ce99c7376f2197bf09df637b5cc2bbd

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
