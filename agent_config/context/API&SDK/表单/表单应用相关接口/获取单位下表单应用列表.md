**简要描述：**

- 获取单位下表单应用列表

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/app/list?deptId=&formIds=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|deptId   |是  |int | 单位ID    |单位ID|
|formIds  |否 |string|表单ID  |不传获取该单位下所有表单；传此参数获取对应表单的信息,支持传多个表单id,多个以逗号分隔；一次最多限制100个|
|formAlias  |否 |string|表单别名  |支持传多个表单别名,多个以逗号分隔|
|uid  |否 |Long| 应用创建人uid  |仅支持传一个uid|
|name  |否 |string|表单名称  |表单名称|
|source  |否 |int|表单的创建来源 |表单的创建来源|
|excludeFields  |否 |string|返回值排除的字段 |approveVerifyConfig，enteringVerifyConfig，submitVerifyConfig，permissionConfig，formConfig，formHighGradeConfig，submitPrompt 中的0个或多个，英文逗号分隔|
|cpage  |否 |int|页码 |默认第1页|
|pageSize  |否 |int|一页多少条 |默认50条，最多限制一次50条；若传了formIds参数，最多限制传100个，此时pageSize=formIds的长度大小|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**补充返回说明：**

|字段|说明|
|:---|:---|
|data.totalPage|总页数|
|data.dataList[]|除示例中的基础字段外，实现随实体返回 `formConfig`、`permissionConfig`、`formHighGradeConfig`、`submitVerifyConfig`、`enteringVerifyConfig`、`auditConfig`、`searchCondition` 等 30+ 配置字段；不需要时用 `excludeFields` 排除|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|formIds数量不能超过100|formIds 超过 100 个|
|获取表单应用列表异常|查询或组装异常|
|缺少enc参数|未传 enc|
|enc参数验证失败|enc 校验失败|
|缺少sign参数|未传 sign|
|接口暂未开通|该单位未开通接口|
|无此单位权限！|sign 与单位不匹配|

**接口参数配置**
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串，具体加密字段以实际传的参数为准，不传就不用
```
> source="[datetime=2019101517][deptId=1385][formIds=1][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5）结果地址
> http://m.oa.chaoxing.com/api/apps/forms/app/list?datetime=2019101517&deptId=1385&formIds=1&sign=xxx&enc=65285f9a00a0520b3e2c46159002df31

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
