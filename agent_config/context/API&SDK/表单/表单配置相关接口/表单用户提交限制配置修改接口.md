## 接口地址
* https://m.oa.chaoxing.com/api/apps/forms/foreground/app/config/submit/limit/edit

## 接口标识类型
> sign=appsFormsData_*

## 请求参数

| 参数名称 | 是否必填 | 参数类型 | 默认值 | 参数说明 |
|:---|:---|:---|:---|:---|
| fid | 是 | int | - | 单位fid |
| formId | 否 | int | - | 表单ID，与formAlias任传一个 |
| formAlias | 否 | string | - | 表单别名，与formId任传一个 |
| uid | 是 | long | - | 操作人UID |
| userInputShow | 是 | int | - | 用户提交限制开关 0/1 否/是 |
| limitType | 条件必填 | int | - | 计数周期类型 1/2/3/4/5/6 只能/每天/每周/每月/每年/自定义，userInputShow=1时必传 |
| userInputNum | 条件必填 | int | - | 上限次数，userInputShow=1时必传且大于0 |
| limitStartDate | 否 | string | - | 自定义周期开始日期，格式yyyy-MM-dd，仅limitType=6时生效；不传保留原配置；原配置也无日期时周期降级为"只能" |
| limitEndDate | 否 | string | - | 自定义周期结束日期，格式yyyy-MM-dd，仅limitType=6时生效；不传保留原配置 |
| sign | 是 | string | - | 接口标识，由超星办公系统方提供 |
| datetime | 是 | string | - | 生成加密串时间，格式：yyyyMMddHH |
| enc | 是 | string | - | 接口参数加密串，采用md5加密方式进行生成 |

## 参数规则
（1）userInputShow=0（关闭）时，limitType、userInputNum、limitStartDate、limitEndDate均不生效，落库时周期归一化为"只能"、上限次数清空；自定义周期日期保留原库值不清空，与后台管理页保存口径一致。
（2）limitType=6（自定义）且开始、结束日期都传时，开始时间必须早于结束时间，否则返回参数错误；日期落库时归一化为当天00:00:00与23:59:59；日期不传时保留原配置，仅当原配置也无日期（合并后双空）时周期降级为"只能"。
（3）配置发生变更（关闭开关、改变计数周期、改变自定义周期时间）后，服务端会清除该表单已有的个人提交计数器，新周期重新计数。

## 处理结果

### 成功
配置有变更、修改成功：
```json
{
  "success": true,
  "msg": "[200]修改成功"
}
```
配置未变更（各字段与原配置一致）时幂等返回成功，不写库、不记录操作日志：
```json
{
  "success": true,
  "msg": "[200]配置未变更,无需修改"
}
```

### 失败
参数校验不通过（示例：自定义周期开始时间不早于结束时间）：
```json
{"msg":"[3000]提交限制开始时间需小于提交限制结束时间","success":false}
```
落库未命中时：
```json
{"msg":"[300]修改失败","success":false}
```

### 返回码说明

| 返回码 | 含义 |
|:---|:---|
| [200] | 成功（含"修改成功"与"配置未变更,无需修改"两种文案） |
| [300] | 操作失败（落库未命中） |
| [3000] | 请求参数不合法（如开关值非0/1、周期类型越界、上限次数≤0、开始时间不早于结束时间、日期格式非yyyy-MM-dd等） |

## 测试关注点建议

1. **开关语义**：userInputShow 显式传 0/1（0 关闭、1 开启）。
2. **条件必填校验**：开启（userInputShow=1）时 limitType + userInputNum 必传；缺失或越界应返回 [3000]。
3. **自定义周期（limitType=6）**：
   - 开始、结束都传 → 开始必须早于结束，否则 [3000]；落库归一化为 00:00:00 / 23:59:59。
   - 只传一侧 → 另一侧保留原配置。
   - 都不传 → 保留原配置；若原配置也无日期 → 周期降级为"只能"。
4. **关闭（userInputShow=0）**：周期归一化为"只能"、上限次数清空；自定义日期保留原库值不清空。
5. **幂等性**：重复提交相同配置 → 返回"配置未变更,无需修改"，不写库、不落操作日志。
6. **计数器清除**：关闭开关 / 改周期 / 改自定义周期时间后，该表单已有个人提交计数器被清除，新周期重新计数。
7. **formId / formAlias**：二者任传一个定位表单。
8. **操作日志**：变更成功后应生成管理员操作日志（明细形式）。

## 加密说明

（1）加密秘钥
> key=xxx（由超星办公系统方提供）

（2）加密方式字符串
> source="[datetime=2019040818][fid=xxx][formId=xxx][sign=xxx]……";

（3）MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合
* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合
* 例如：[a=1,2,3,4,5,6]
