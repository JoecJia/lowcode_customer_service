**简要描述：**
- 表单的地址替换接口，可将配置的旧url地址替换为新的url地址
场景1：需要将http://www.baidu.com 替换为 http://www.chaoxing.com
此时可以传的样例如下：
1.oldAddr=baidu,newAddr=chaoxing
2.oldAddr=http://www.baidu.com ,newAddr=http://www.chaoxing.com
3.oldAddr=www.baidu.com , newAddr = www.chaoxing.com
场景2：需要将http://www.baidu.com:8080 替换为http://www.chaoxing.com:8081
此时可以传的样例如下：
1.oldAddr=http://www.baidu.com:8080 newAddr= http://www.chaoxing.com:8081
注意：底层使用的url.replace方法进行查找替换


**请求方式**

POST: Content-Type为application/x-www-form-urlencoded，通过urlencode格式化请求体。

**请求示例**

HTTP方法：POST

请求URL：http://m.oa.chaoxing.com/api/apps/forms/user/data/addr/replace

HTTP Header:

Content-Type application/x-www-form-urlencoded

HTTP Body中放置请求参数，示例详情如下:
```
ContentType:application/x-www-form-urlencoded
Body数据(以下只是样例,参数的数据需要替换):
fid=109147&uid=111&formId=1&oldAddr=&newAddr=&type=1&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705&
```

HTTP Body中放置请求参数，参数详情如下：

**请求参数**

|参数名称|是否必填|参数类型|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位Id|
|uid      |是  |int | 替换人的uid |
|formId   |否  |int | 表单ID|
|oldAddr |是   |string  |要替换的原地址|
|newAddr |是   |string  |替换后的新地址|
|type   | 是 |int| 1:字段数据从第三方获取（下拉框、下拉复选框、多级下拉 选项第三方获取 ;联系人字段，单行输入字段联想输入的第三方获取）2:按钮字段(button)配置的URL 3:后台顶部按钮打开URL 4:后台右侧按钮打开URL 5:提交校验（第三方校验) 7:进入表单校验 8:前端事件 9:数据推送|
|datetime |是  |string |格式：yyyyMMddHH|
|sign     |是  |string | 接口标识 ， 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串，采用md5加密方式进行生成|


**返回参数说明：**

|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|success|新增成功/失败标识,true/false
|msg|提示语 如 "替换成功"

**返回结果**
（1）成功

* 返回数据格式：
```json
   {
       "msg": "[200]替换成功",
       "success": true
   }
```
（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")
```
* 返回数据格式：{"msg":"[300]保存失败","success":false}
```

**接口参数配置**
（1）接口标识
> sign=xxx   由超星办公系统方分配

（2）加密秘钥
> key=xxx    由超星办公系统方分配

（3）加密原文字符串
```
> source="[datetime=2020090916][fid=109147][formId=1][newAddr=chaoxing][oldAddr=baidu][sign=xxx][type=1][uid=111]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） enc的生成样例
> enc=md5([datetime=2020090916][fid=10947][formId=1][newAddr=chaoxing][oldAddr=baidu][sign=xxx][type=1][uid=111][分配的key值]);
enc的获取:可使用此链接进行md5加密测试，取其32位小写即可https://md5jiami.bmcx.com/

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
