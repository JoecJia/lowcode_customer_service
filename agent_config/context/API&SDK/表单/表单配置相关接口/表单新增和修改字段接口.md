**简要描述：**


- 支持给现存表单新增和修改字段接口


**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/add/field


**请求方式：**
- POST


**参数说明：**


|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID    |高级设置页面可以查看  与formAlias参数至少要有一个有值|
|formAlias   |否  |string | 表单接口标识（表单别名）    |高级设置页面可以设置 与formId参数至少要有一个有值 |
|operatorUid   |是  |long | 操作人uid  | 操作人uid|
|fieldListStr   |是  |string | 新增字段列表  | 新增字段列表，详情见下方|
|autoSendData|否 |int    |默认为1|1:可触发数据推送，0:不触发数据推送|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口验证参数,生成规则在下面的'接口参数配置'处查看    |生成enc值的参数名称列表必须通过字母a-z的顺序依次组合 |


fieldListStr结构


- 新增字段示例
```json
[
  {
    "compt": "editinput", // 字段类型（必填）
    "alias": "字段别名", // 字段别名（非必填，不填默认为字段id）要求：1.只能包含字母、数字、下划线  2.不能重复
    "title": "字段标题", // 字段标题（非必填，不填为默认值）
    "titleDesc": "标题描述"// 字段描述（非必填，不填为默认值）
  },
  {
    "compt": "numberinput",
    "minValue": "0", // 数字输入字段最小值（非必填，不填为默认值）
    "maxValue": "100"// 数字输入字段最大值（非必填，不填为默认值）
  }
]
```
- 说明：以上为字段基础属性；图片、视频、附件、子表单等字段还支持权限参数（可见、可编辑、下载、记录操作等），详见下方“字段权限配置参数说明”



- 修改字段示例
```json
[
  {
    "update": true, // 是否修改（非必填， true 表示修改字段，不传或 false 表示新增字段）
    "compt": "editinput", // 字段类型（必填）
    "alias": "字段别名", // 字段别名（非必填，不填默认为字段id）要求：1.只能包含字母、数字、下划线  2.不能重复
    "title": "字段标题", // 字段标题（非必填，空字符串表示清空）
    "titleDesc": "标题描述"// 字段描述（非必填，空字符串表示清空）
  },
  {
    "update": true, // 是否修改（非必填， true 表示修改字段，不传或 false 表示新增字段）
    "compt": "numberinput",
    "minValue": "0", // 数字输入字段最小值（非必填，空字符串表示清空）
    "maxValue": "100"// 数字输入字段最大值（非必填，空字符串表示清空）
  }
]
```
- 新增子表单示例（新增子表单时compts必填，否则返回：子表单里不能为空）
```json
[
  {
    "compt": "detailcombox", // 字段类型（必填），子表单
    "alias": "子表单别名", // 子表单别名（非必填，不填默认为字段id）要求：1.只能包含字母、数字、下划线  2.不能重复
    "title": "子表单标题", // 子表单标题（非必填，不填为默认值）
    "compts": [ // 子字段配置（新增子表单时必填），结构与主表单字段一致
      {
        "compt": "editinput", // 子字段类型（必填）
        "alias": "子字段别名", // 子字段别名（非必填，不填默认为字段id）要求同主表单
        "title": "子字段标题" // 子字段标题（非必填，不填为默认值）
      }
    ]
  }
]
```



- 修改子表单示例（给现存子表单添加子字段、修改子表单或子字段属性）
```json
[
  {
    "update": true, // 修改子表单
    "compt": "detailcombox", // 字段类型（必填），子表单
    "id": 14, // 子表单字段id（id或alias二选一定位子表单）
    "title": "新的子表单标题", // 修改子表单属性时，compts结构可以不传；子表单权限参数（visible、editable、addDetail等）也在此对象内传递
    "compts": [ // 非必填：update=true的项表示修改已有子字段，其余项表示给子表单新增子字段
      {
        "compt": "numberinput", // 给子表单新增子字段，结构同新增字段
        "title": "新增的子字段"
      },
      {
        "update": true, // 修改子表单里已有子字段
        "compt": "editinput", // 字段类型（必填），必须与子字段实际类型一致
        "alias": "子字段别名", // id或alias二选一定位子字段
        "title": "新的子字段标题" // 支持的属性与主表单字段一致（title、alias、options、titleDesc、minValue、maxValue及权限参数）
      }
    ]
  }
]
```
说明：子表单的子字段支持的类型与主表单一致（所属人belonger、子表单detailcombox本身除外）
说明：每个表单最多支持添加30个子表单（detailcombox）字段，添加后总数超出30个时返回：仅支持添加30个子表单字段
- 只统计新增子表单，修改（update=true）不计数；子表单内的子字段不占额度
- 已解除子表单字段数量限制的表单不做数量校验（如需解除请联系技术或产品支持配置）


- 字段权限配置示例（新增字段和修改字段均可携带）
```json
[
  {
    "compt": "fileupload", // 附件字段
    "alias": "附件别名",
    "title": "附件",
    "visible": true, // 可见（非必填，新增默认true，修改不传保持原值）
    "editable": true, // 可编辑（非必填，新增默认true，修改不传保持原值）
    "downloadFile": true, // 可下载已有附件
    "copyFile": true, // 可在线复制附件中内容
    "addFile": true, // 可新增附件
    "editFile": false, // 可在线编辑已有附件
    "deleteFile": false // 可删除已有附件
  },
  {
    "compt": "imagebox", // 图片字段：仅支持visible、editable、downloadFile
    "title": "图片",
    "visible": true,
    "editable": true,
    "downloadFile": true // 可下载已有图片
  },
  {
    "compt": "videobox", // 视频字段：仅支持visible、editable、downloadFile
    "title": "视频",
    "visible": true,
    "editable": true,
    "downloadFile": true // 可下载已有视频
  },
  {
    "update": true, // 修改已有子表单的权限
    "compt": "detailcombox", // 字段类型（必填），子表单
    "alias": "子表单别名",
    "visible": true, // 子表单可见
    "editable": true, // 子表单可编辑
    "addDetail": true, // 可新增记录
    "batchImport": true, // 允许批量添加子表单（仅PC端有效）
    "editDetail": true, // 可编辑已有记录
    "deleteDetail": false // 可删除已有记录
  }
]
```


**字段权限配置参数说明**（fieldListStr 每个字段对象内，均为非必填）


|参数名称|参数类型|支持字段|参数说明|不传时行为|
|:----    |:----|:----- |:-----   |-----   |
|visible|boolean|全部字段（含子表单）|字段是否可见；为false时不能同时开启任何子权限|新增默认true，修改保持原值|
|editable|boolean|全部字段（含子表单）|字段是否可编辑；为false时不能同时开启编辑类子权限|新增默认true，修改保持原值|
|downloadFile|boolean|附件、图片、视频|可下载已有附件/图片/视频|新增默认true，修改保持原值|
|copyFile|boolean|附件|可在线复制附件中内容|新增默认true，修改保持原值|
|addFile|boolean|附件|可新增附件|新增默认true，修改保持原值|
|editFile|boolean|附件|可在线编辑已有附件|新增默认true，修改保持原值|
|deleteFile|boolean|附件|可删除已有附件|新增默认true，修改保持原值|
|addDetail|boolean|子表单|可新增记录|新增默认true，修改保持原值|
|batchImport|boolean|子表单|允许批量添加子表单（仅PC端有效，需同时开启addDetail）|新增默认false，修改保持原值|
|editDetail|boolean|子表单|可编辑已有记录|新增默认true，修改保持原值|
|deleteDetail|boolean|子表单|可删除已有记录|新增默认true，修改保持原值|


字段权限配置说明：
- 权限参数值必须为JSON布尔（true/false），传1、0、"true"或null均返回参数错误
- 普通字段的权限参数与compt、alias、title同级；子表单的权限参数写在子表单对象内，不放在compts中；子表单内的子字段权限写在compts对应子字段内
- 权限参数与字段类型不匹配时返回：[300]请求失败{字段名}字段不支持该权限配置
- 配置约束：
  - 不可见（visible=false）时开启任一子权限，返回：配置不合法：字段不可见，不能开启xxx
  - 不可编辑（editable=false）时开启编辑类子权限，返回：配置不合法：字段不可编辑，不能开启xxx
  - 附件字段可编辑（editable=true）时，addFile、editFile、deleteFile不能全部为false
  - 子表单可见且可编辑时，addDetail、batchImport、editDetail、deleteDetail至少开启一项
  - 不可新增记录（addDetail=false）时不能开启batchImport
- 父权限关闭时，本次未显式传值的子权限会同步关闭（如visible=false时，未传的editable及各子权限一并置为false）

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

{"msg":"[300]请求失败错误信息","success":false}

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx


（2）加密秘钥
> key=xxx


（3）加密原文字符串
```
> source="[autoSendData=][datetime=][fid=][fieldListStr=][formAlias=][formId=][operatorUid=][sign=]";
```


（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);



**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合


* 例如：[a=1][b=2][c=3][ei=4][ej=5]


（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合


* 例如：[a=1,2,3,4,5,6]
