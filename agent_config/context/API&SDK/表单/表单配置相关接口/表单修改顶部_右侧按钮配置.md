#### 简要描述

- 修改数据管理页顶部\右侧按钮
- 新增数据管理页顶部\右侧按钮（暂时仅支持：自定义按钮-打开url）
- 备注：
	- [系统按钮id字典](https://cxapi.chaoxing.com/web/#/p/cd5e9ed25b2b97c6ffe98c124ebb53c2)


#### 请求URL
- ` http://m.oa.chaoxing.com/api/apps/forms/operate/config/save `
#### 请求方式
- POST 

#### 参数

| 参数名称     | 是否必填 | 参数类型   | 参数名称    | 参数说明               |
|:---------|:-----|:-------|:--------|---------------------|
| formId   | 是    | int    | 表单ID    | formId和formAlias不能同时为空 |
| formAlias| 是    | string | 表单别名  | formId和formAlias不能同时为空 |
| fid      | 是    | int    | 单位fid   ||
| uid      | 是    | int    | 操作人UID ||
| topOperates      | 否    | string    | [顶部按钮配置JSON](#顶部按钮配置参数结构)  | 顶部和右侧按钮配置JSON不能同时为空 |
| rightOperates    | 否    | string    | [右侧按钮配置JSON](#右侧按钮配置参数结构)  | 顶部和右侧按钮配置JSON不能同时为空 |
| isReturnOperates  | 否    | boolean   | 成功是否返回按钮配置列表    | 默认false，为true返回的结果同：[查询接口返回值](https://cxapi.chaoxing.com/web/#/p/432d279c53e26862e330568779ba7f8f) |
| sign     | 是    | string | 接口标识    | 由超星办公系统方提供          |
| datetime | 是    | string | 生成加密串时间 | 格式：yyyyMMddHH       |
| enc      | 是    | string | 接口参数加密串 | 采用md5加密方式进行生成       |

#### 请求结果

（1）接口调用成功

 **返回示例**

```
{
  "success": true,
  "msg": "[200]请求成功",
  "data": {                 //如果 isReturnOperates=true 才会返回具体的结构
  	"topOperates": [],      //修改后的顶部按钮配置列表
  	"rightOperates": []     //修改后的右侧按钮配置列表
  }
}
```

（2）接口调用失败

 **返回示例**

```
{
  ,
  "success":false,
  "msg":"[错误code]错误信息",
  "data": {
  	"errorTopOperates":[                             //有问题的按钮配置列表
  		{
  			"errorObj": "",                          //有问题的顶部按钮配置
  			"errorMsg": "index取值范围：不小于0"        //问题描述
  		}
  	],
  	"errorRightOperates": [                           //有问题的按钮配置列表
  		{
  			"errorObj": "",                           //有问题的右侧按钮配置
  			"errorMsg": "index取值范围：不小于0"         //问题描述
  		}
  	]
  }
}
```

#### 顶部按钮配置参数结构

topOperates 的结构为 **JSON 数组**，需要按照规则构造，传递需要修改\新增的 `按钮配置` 信息。
1.修改单个按钮配置 `[{按钮配置1}]`。
2.修改多个按钮配置 `[{按钮配置1},{按钮配置2},{按钮配置2}]` ，按钮配置详情参考下文。

##### 顶部按钮参数完整结构
```JSON
[
    //系统按钮
    {
        "groupId": 0,                //所属分组id
        "index": 0,                  //按钮排序：在按钮列表内的下标位置
        "id": -n,                    //系统按钮id（唯一标识）
        "name": "添加",              //系统按钮名称
        "status": true,              //系统按钮是否启用
    },
    //自定义-顶部按钮配置
    {
        "groupId": 0,                //所属分组id
        "index": 0,                  //按钮排序：在按钮列表内的下标位置
        "id": 0,                     //按钮id（唯一标识，自定义按钮如果不传按照新增处理）
        "name": "",                  //按钮名称
        "status": "",                //按钮是否启用
        "userConfirm": {             //点击按钮是否弹出确认弹框
            "show": false,           //是否开启确认弹框
            "text": ""               //弹框提示文本
        }
    },
    //自定义按钮-打开url配置
    {
        "groupId": 0,                //所属分组id
        "index": 0,                  //按钮排序：在按钮列表内的下标位置
        "type": 2,					 //自定义打开url按钮类型
        "id": 0,                     //按钮id（唯一标识，自定义按钮如果不传按照新增处理）
        "name": "",                  //按钮名称
        "status": "",                //按钮是否启用
        "url": "",                   //顶部按钮url地址
        "userConfirm": {             //点击按钮是否弹出确认弹框
            "show": false,           //是否开启确认弹框
            "text": ""               //弹框提示文本
        }, 
        "paramVerify": {             //追加加密串配置
            "open": false,           //是否开启
            "secret": ""             //加密的key
        },
        "buttonStatus": 0,           //未选择数据时按钮状态( 常显:0, 置灰：1, 隐藏:2)
        "openType": 0,               //打开方式：0打开新页面，1打开弹框，2调用url
        // openType=1 打开弹窗页面（才生效）
        "title": "", 				 //弹窗标题
        "window": {                  
            "width": {               //弹框宽度
                "unit": 0,           //单位：0 像素，1 百分比
                "size": 600          //具体数值(unit=1时，size <= 100)
            },
            "height": {              //弹框高度
                "unit": 0,           //单位：0 像素，1 百分比
                "size": 400          //具体数值(unit=1时，size <= 100)
            }
        },
        // action=2 调用URL地址（才生效）
        "actionType": 0,      //调用url之后的动作：0 无操作、1 刷新所有数据、2 刷新当前页数据
    }
]
```

##### 修改顶部按钮分组

```JSON
[
	{
		"id": 1,             //分组id（唯一标识）
		"index": 0,          //按钮排序：在按钮列表内的下标位置
		"name": "",          //分组名称
		"status": false,     //分组是否启用（分组内的按钮都不可用，默认转为false）
	}
]
```

| 属性名称 | 类型    | 是否必填 | 备注                                                         |
| :------- | :------ | :------- | :----------------------------------------------------------- |
| id       | int     | 是       | 分组id                                                       |
| index    | int     | 否       | 按钮的排序下标。 <br />1.如果不修改按钮的顺序，不要传。<br /> 2.如果传了 groupId 分组id，index 表示按钮在分组内的按钮顺序。  如果传了 groupId 分组id，不传index按钮默认放在新列表的末尾。<br /> 3.取值范围：0~n(按钮列表的size-1)。  <br /> 如果 index>n，默认会放到列表末尾。 |
| name     | string  | 否       | 按钮名称。<br />1.不修改按钮名称可以不传。                   |
| status   | boolean | 否       | 按钮启用状态。<br />1.不修改可以不传。                       |


| status             | boolean | 否       | 按钮启用状态。 <br />1.不修改可以不传。                      |
| userConfirm        | JSON    | 否       | 点击按钮确认弹框配置。 <br />1.不修改可以不传。              |

####参数校验配置

（1）接口标识类型
> sign=appsFormsData__*

（2）加密秘钥
> key=xxx

（3）加密方式字符串
> source="[datetime=2019040818][fid=xxx][formAlias=xxx][formId=xxx][sign=xxx]……";

（4） MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
