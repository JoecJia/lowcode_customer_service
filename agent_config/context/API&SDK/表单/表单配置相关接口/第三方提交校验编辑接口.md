##第三方提交校验配置编辑接口说明

###接口地址
* http://m.oa.chaoxing.com/api/apps/forms/submit/verify/edit/config?formId=&uid=&datetime=&formType=&fid=&sign=&enc=

| 参数名称       | 是否必填 | 参数类型    | 参数名称    | 参数说明                |
|:-----------|:-----|:--------|:--------|---------------------|
| formId     | 是    | int     | 表单ID    
| fid        | 是    | int     | 单位fid   
| uid        | 是    | int     | 操作人UID  
| formType   | 否    | int     | 应用类型标识  | 0.自定义表单(默认)  1.审批表单 |
| id         | 否    | int     | -1      | 校验配置ID，-1表示新增       |
| promptText | 是    | string  | -       | 校验名称                |
| url        | 是    | string  | -       | 校验接口URL             |
| on         | 是    | boolean | -       | 是否启用                |
| sign       | 是    | string  | 接口标识    | 由超星办公系统方提供          |
| datetime   | 是    | string  | 生成加密串时间 | 格式：yyyyMMddHH       |
| enc        | 是    | string  | 接口参数加密串 | 采用md5加密方式进行生成       |
|formAlias |否  |string |【formAlias】 |表单别名，formId 为空时用它定位表单 |
|verifyType |否  |int |【verifyType】 |校验类型，默认 0 |


### 处理结果
（1）接口调用成功
 **返回示例**
```
{
  "success": true,
  "data": {
    "verifyConfig": "[{\"id\":1,\"promptText\":\"校验名称\",\"url\":\"http://example.com\",\"on\":true,\"verifyType\":0}]"
  },
  "msg": "success"
}
```
  
（2）接口调用失败

 **返回示例**
```
{"msg":"错误信息","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|编辑表单提交校验配置异常！|编辑异常|
|参数校验错误|参数缺失或非法|
|鉴权失败|sign / enc 校验失败|

###接口参数配置
（1）接口标识类型
> sign=appsFormsData__*

（2）加密秘钥
> key=xxx

（3）加密方式字符串
> source="[datetime=2019040818][fid=xxx][formId=xxx][formType=xxx][sign=xxx]……";

（4） MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密
> source中所有参数均需参与加密

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
