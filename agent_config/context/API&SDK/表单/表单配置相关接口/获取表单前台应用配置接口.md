**简要描述：**

- 根据单位id,(表单id或表单别名)获取表单前台应用设置接口

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/foreground/app/config?fid=&formId=&formAlias=&datetime=&sign=&enc=

**请求方式：**
- GET,POST
注:因enc参数的校验规则,POST请求支持Content-Type为application/x-www-form-urlencoded,不支持Content-Type为applcation/json

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID    |高级设置页面可以查看  与formAlias参数至少要有一个有值|
|formAlias   |否  |string | 表单接口标识（表单别名）    |高级设置页面可以设置 与formId参数至少要有一个有值 |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc |是  |string |【enc】 |接口参数加密串，除 enc 外全部参数参与 MD5 |

**有效时段字段优先级**

先检查 `periodShow`。值为 `1` 时，按以下顺序判断表单是否处于有效时段。

1. **优先读取 `timeRangeConfig`**。字段有非空白值时，将其作为 JSON 字符串解析，按 `configs` 中启用的时段判断。字段值为 `"{}"` 时，表示未设置有效时段限制，无需读取旧字段。
2. **缺少新版配置时读取 `effectiveDate` 和 `deadline`**。仅当 `timeRangeConfig` 缺失、为 `null`、空字符串或仅含空白时，才读取旧版生效时间和截止时间。两者均为 Unix 毫秒时间戳，缺少哪一端就不限制该端。若 `perDayPeriodShow` 为 `1`，再按旧版 `perDayStartTime` 和 `perDayEndTime` 判断每日时段。

（2）失败 [点击查看code业务码说明](https://document.chaoxing.com/web/#/21?page_id=421 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]请求失败错误信息","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|FORM_NOT_EXIST|formId / formAlias 定位不到表单|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2020090916][fid=1385][formAlias=info][formId=1][sign=xxx]";
```
          
（4） MD5加密操作
> enc=md5(source+[key]);
          
（5） 结果地址
> http://m.oa.chaoxing.com/api/apps/forms/foreground/app/config?formAlias=info&formId=1&datetime=2020090916&fid=1385&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]
  
（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
