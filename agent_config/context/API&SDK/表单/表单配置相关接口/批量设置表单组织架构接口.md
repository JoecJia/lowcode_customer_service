**简要描述：**
 批量设置表单的组织架构接口。组织架构的示意图如下图所示：

![](http://document.chaoxing.com/server/index.php?s=/api/attachment/visitFile&sign=1849ad334ac0dacbc0da9f804a38eb16)

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/serviceid/set

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formIds |是  |string | 表单ID  | 多个表单id，以逗号分隔 如"1,2,3"|
|uid   |是  |int  | 当前操作人uid | 当前操作人uid|
|serviceId|是 |int|组织架构id|组织架构id(注意：serviceId接口不做验证,需调用方自身做下验证)|
|serviceName|是 |string|组织架构名称|组织架构名称(注意：serviceName接口不做验证,需调用方自身做下验证)|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口验证参数,生成规则在下面的'接口参数配置'处查看    |生成enc值的参数名称列表必须通过字母a-z的顺序依次组合 |
|formAlias |否  |string |【formAlias】 |表单别名；formIds 为空时按别名解析表单 |

**返回结果**
（1）成功

* 返回数据格式：
```json
  {
      "msg": "[200]设置成功",
      "success": true
  }
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]表单不存在","success":false}
```

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|MISSING_FID|未传 fid|
|MISSING_FORM_ID|formIds 与 formAlias 同时为空|
|MISSING_UID|未传 uid|
|MISSING_SERVICE_ID|未传 serviceId|
|MISSING_SERVICE_NAME|未传 serviceName|
|FORM_CONFIG_NOT_EXIST|表单配置不存在|
|[表单id]参数不存在|formIds 中有不存在的表单|
|[500]|服务端异常|

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2023082410][fid=109147][formIds=182275,182275][serviceId=-1][serviceName=通讯录][sign=xxx][uid=47101001]";
```
（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
