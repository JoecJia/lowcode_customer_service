**简要描述：**
**该接口为老接口，部分老表单还可以用，请使用新接口** https://cxapi.chaoxing.com/web/#/653656295/207986664
- 表单前台应用设置-表单提交时间修改接口。如下图所示，此接口，可以对'表单有效时间' 和 '每日启用时段' 时间配置做修改
![](http://document.chaoxing.com/server/index.php?s=/api/attachment/visitFile&sign=260098b5d06ebb7fb45298573d9c18f1)

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/foreground/app/config/submit/time/edit

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |微服务设置里可以查看|
|formId   |否  |int | 表单ID  | 与formAlias传一个即可|
|formAlias  |否  |string | 表单别名  | 与formId传一个即可|
|uid   |是  |int  | 当前修改人uid | 当前修改人uid|
|effecttiveTime |是|string|表单提交的启用时间,当'表单有效时段'开启后可修改|格式为:yyyy-MM-ddTHH:mm
|deadLine |是|string|表单提交的停用时间,当'表单有效时段'开启后可修改|格式为:yyyy-MM-ddTHH:mm
|startTime |否|string|每日启用时段的开始时间,当'每日启用时段'开启后可修改|格式为:HH:mm
|endTime |否|string|每日启用时段的结束时间,当'每日启用时段'开启后可修改|格式为:HH:mm
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口验证参数,生成规则在下面的'接口参数配置'处查看    |生成enc值的参数名称列表必须通过字母a-z的顺序依次组合 |

**返回结果**
（1）成功

* 返回数据格式：
```json
  {
      "msg": "[200]修改成功",
      "success": true
  }
```

（2）失败 [点击查看code业务码说明](https://cxapi.chaoxing.com/web/#/653656579/207985742 "code业务码说明")

* 返回数据格式：
```
{"msg":"[300]请求失败错误信息","success":false}
```
**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2023082410][deadLine=2023-08-24T10:51][effecttiveTime=2023-08-24T11:51][fid=109147][formId=182275][sign=xxx][uid=47101001]";
```
（4） MD5加密操作,生成enc参数
> enc=md5(source+[key]);


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
