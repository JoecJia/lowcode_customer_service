
##数据推送配置删除接口说明

###接口地址
* http://m.oa.chaoxing.com/api/apps/forms/app/datapush/config/del?formId=&uid=&datetime=&formType=&deptId=&sign=&id=&enc=

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|uid      |是  |int | 用户uid
|formId   |是  |int | 表单ID
|deptId   |是  |int | 单位fid
|id       |是  |int | 数据推送id   |删除此id对应数据推送|
|formType |否  |int | 应用类型标识    | 0.自定义表单  1.审批表单|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

 
### 处理结果
（1）接口调用成功，

 **返回示例**

```
{"data":"删除成功","success":true}
```
  
（2）接口调用失败

 **返回示例**

```
{"msg":"删除失败","success":false}
```
```
{"msg":"接口暂未开通","success":false}
```
```
{"msg":"表单不存在","success":false}
```

###接口参数配置
（1）加密秘钥
> key=xxxxxxxx

（2）加密方式字符串
> date="yyyy-MM-dd";
> source="[datetime=2019040818][formId=xxx][sign=xxx][uid=xxx]……";

（3） MD5加密操作
> enc=md5(source+[key]);

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
