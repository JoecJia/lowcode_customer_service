
##获取表单下数据推送列表

###接口地址
* http://m.oa.chaoxing.com/api/apps/forms/app/datapush/config/list?formId=&formType=&datetime=&cpage=&deptId=&sign=&pageSize=&enc=



### 请求方式：

​	GET/POST均可



| 参数名称 | 是否必填 | 参数类型 | 参数名称                     | 参数说明                       |
| -------- | -------- | -------- | ---------------------------- | ------------------------------ |
| formId   | 是       | int      | 表单ID                       |                                |
| deptId   | 是       | int      | 单位id                       |                                |
| formType | 否       | int      | 应用类型标识                 | 0.自定义表单(默认)  1.审批表单 |
| cpage    | 否       | int      | 当前页码，从1开始。（默认1） |                                |
| pageSize | 否       | int      | 分页大小，默认每页10条       |                                |
| sign     | 是       | string   | 接口标识                     | 由超星办公系统方提供           |
| datetime | 是       | string   | 生成加密串时间               | 格式：yyyyMMddHH               |
| enc      | 是       | string   | 接口参数加密串               | 采用md5加密方式进行生成        |

（1）接口调用成功

（2）接口调用失败

 **返回示例**

```
{"msg":"验证失败","success":false}
```
```
{"msg":"接口暂未开通","success":false}
```
```
{"msg":"时间参数格式错误","success":false}
```

**补充返回字段（list[] 元素）：**

|字段|说明|
|:---|:---|
|pushName|推送名称|
|status|推送配置状态|
|source|推送来源|
|inserttime|创建时间|
|updatetime|更新时间|

**常见失败返回（msg = 业务码 + 文案）：**

|业务码 / msg|触发条件|
|:---|:---|
|formId参数异常|未传 formId 或非法|
|deptId参数异常|未传 deptId 或非法|
|formType参数异常|formType 不是 0/1|
|验证失败|sign / enc 校验失败|
|接口暂未开通|该单位未开通接口|
|时间参数格式错误|datetime 不是 yyyyMMddHH|

###接口参数配置

```
（1）加密秘钥
> key=xxxxxxxx

（2）加密方式字符串
> date="yyyyMMddHH";
> source="[cpage=1][datetime=2019040818][deptId=xxx][formId=xxx][formType=xxx][pageSize=10][sign=xxx]";

（3） MD5加密操作
> enc=md5(source+[key]);
> source中所有参数均需参与加密

**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
```
