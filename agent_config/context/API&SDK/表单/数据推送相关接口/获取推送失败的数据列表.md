
**简要描述：**

- 获取数据推送失败的数据列表接口 

**请求URL：**
- http://m.oa.chaoxing.com/api/apps/forms/app/datapush/logs/failed?fid=&formId=&pushId=&startTime=&endTime=&datetime=&sign=&enc=

**请求方式：**
- GET,POST

**参数说明：**

|参数名称|是否必填|参数类型|参数名称|参数说明|
|:----    |:----|:----- |:-----   |-----   |
|fid   |是  |int | 单位ID    |单位ID |
|formId   |否  |int | 表单ID    |与formAlias参数至少要有一个有值 |
|formAlias |否 |string|表单别名 |与formId参数至少要有一个有值
|formType   |否  |int |表单类型 默认0|0:自定义表单 1:审批表单 |
|pushId   |是  |int | 推送ID    |推送ID |
|startTime   |否  |string | 起始时间|查询某时间范围内数据-起始时间(yyyy-MM-dd)|
|endTime     |否  |string | 结束时间|查询某时间范围内数据-结束时间(yyyy-MM-dd)  |
|cpage   |否  |int | 页码    |默认查询第一页 |
|pageSize   |否  |int | 页数    |默认一页10条 |
|datetime |是  |string |生成加密串时间   | 格式：yyyyMMddHH|
|sign     |是  |string | 接口标识    | 由超星办公系统方提供|
|enc      |是  |string | 接口参数加密串    |采用md5加密方式进行生成|

**返回参数说明：**

|参数名称|参数说明|
|:----  |:----
|totalPage   |总页数
|totalCount   |总数量
|formUserId   |推送的数据行id(用户填写id)
|pushEvent   |推送事件 （data_create：数据新增 ｜ data_update：数据修改 ｜ data_remove：数据删除 ）
|inserttime  |推送开始时间

**返回结果**
（1）成功

* 返回数据格式：
```json
{
    "data": {
        "totalPage": 1,//总页数
        "totalCount": 2,//总数量
        "list": [
            {
                "formUserId": 123,
                "inserttime": 1629792652000,
                "pushEvent": "data_create"
            },
            {
                "formUserId": 345,
                "inserttime": 1629792093000,
                "pushEvent": "data_update"
            }
        ]
    },
    "success": true
}
```

（2）失败

* 返回数据样例:
```
{"msg":"缺少单位Id","success":false}
{"msg":"表单不存在","success":false}
{"msg":"缺少推送Id","success":false}
```

**接口参数配置(sign,key由超星办公系统方分配)
（1）接口标识
> sign=xxx

（2）加密秘钥
> key=xxx

（3）加密原文字符串
```
> source="[datetime=2021082717][fid=97253][formId=1][pushId=1][sign=xxx]";
```

（4） MD5加密操作
> enc=md5(source+[key]);

（5） 结果地址
> http://m.oa.chaoxing.com/api/apps/forms/app/datapush/logs/failed?fid=97253&formId=1&pushId=1&startTime=&endTime=&datetime=2020090916&sign=xxx&enc=2e0bfef1d948cc4f55f745d81fbb7705


**注意事项**
（1）生成enc值的参数名称列表必须通过字母a-z的顺序依次组合

* 例如：[a=1][b=2][c=3][ei=4][ej=5]

（2）生成enc值时如果某个参数的值存在多个，在加密过程中要将这些值通过英文逗号进行组合

* 例如：[a=1,2,3,4,5,6]
