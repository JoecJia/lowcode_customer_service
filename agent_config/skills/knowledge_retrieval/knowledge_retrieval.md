# Skill: 知识检索 (Knowledge Retrieval)

## 描述
这是智能客服系统的核心检索能力。当用户提出关于产品功能、业务逻辑、账号操作或常见问题时，总调度智能体应调用此技能来获取精准的知识片段。

## 输入参数
- `query` (string): 用户咨询的核心关键词或问题摘要。

## 执行逻辑
本技能底层基于**混合式检索**（Hybrid Search），结合 BM25 关键词匹配与向量语义检索，通过 RRF（Reciprocal Rank Fusion）融合两路结果，以提升召回精度。

1. **BM25 关键词检索**：对 query 进行 jieba 中文分词，在所有文档 chunk 上执行 BM25 打分，召回 Top-K。
2. **向量语义检索**：使用 BAAI/bge-small-zh-v1.5 模型将 query 编码为 512 维向量，在 FAISS 索引中做余弦相似度检索，召回 Top-K。
3. **RRF 融合排序**：将两路结果的排名进行 RRF（k=60）交叉融合，取最终 Top-K。
4. **结果拼装**：从命中 chunk 中提取文本内容、标题链、来源文件及图片引用。
5. **返回结果**：返回“命中文本 + 命中图片（可选）”，不带无关信息。

## 输出格式
按以下结构返回，方便总调度智能体与业务咨询类技能拼装最终答复：

### 命中文本
（与问题直接相关的段落内容，保留必要的小节标题）

### 命中图片（可选）
- `alt`: 图片说明文字（可为空）
- `path`: 图片路径（例如：`../assets/form_usage_guide/image156.png`）
- `source`: 命中来源文件（例如：`context/product_docs/form_usage_guide.md`）

## 使用建议
- 若命中片段中包含图片，且图片能显著提升用户理解（例如配置步骤截图、对比示意、效果图），总调度智能体在最终回复中必须使用 `![图片说明](图片路径)` 的 markdown 格式展示图片（例如 `![操作界面截图](/assets/xxx/image.png)`），以确保前端能正常渲染显示。
- 若用户侧无法直接查看图片，可优先输出图片的说明文字与路径，告知用户到对应文档位置查看。

## 优势
- **双重召回**：BM25 保证精确关键词命中（如术语、函数名），向量检索覆盖语义相近的表达（如“数据联动” ↔ “关联查询”）。
- **节省上下文**：仅返回与问题相关的 chunk 片段，避免将整个知识库塞入对话。
- **提高准确性**：RRF 融合消除单一检索的偏差，显著降低模型“幻觉”风险。

## 目录结构
- `knowledge_retrieval.md`：本技能描述文件。
- `hybrid_search.py`：混合检索引擎核心代码（BM25 + 向量 + RRF）。

## 使用示例
- 用户问：“怎么导出数据？”
- Skill 动作：匹配索引中的“数据导出”，定位到 `context/faq/general_faq.md`，提取导出相关的 Q&A 段落。
