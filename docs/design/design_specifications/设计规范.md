> 参考 [cxlowcode.com](https://www.cxlowcode.com) 设计风格制定

## 一、设计理念

| 关键词 | 说明 |
|--------|------|
| **专业信赖** | 以蓝色为主色调，传递稳定、专业、可信赖的品牌感知 |
| **简洁高效** | 减少视觉噪音，聚焦核心任务流，降低认知负担 |
| **统一一致** | 全局统一的设计语言，确保跨页面体验一致 |
| **轻量现代** | 扁平化设计 + 微阴影 + 克制圆角，符合现代 SaaS 审美 |

## 二、色彩系统

### 2.1 品牌色 / 主色 — Blue

```
主色        #2B67FF  ██████████████████████  (品牌蓝，按钮、链接、选中态)
悬停态      #3D82F2  ██████████████████████  (按钮 hover、交互反馈)
点击态      #0057FF  ██████████████████████  (按钮 active、深色强调)
浅底色      #EBF2FF  ██████████████████████  (选中背景、标签背景)
```

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-primary` | `#2B67FF` | 主按钮、链接、选中高亮、进度条、开关激活 |
| `--color-primary-hover` | `#3D82F2` | 主按钮 hover 态 |
| `--color-primary-active` | `#0057FF` | 主按钮 active 态 |
| `--color-primary-light` | `#EBF2FF` | 选中行/标签浅色背景 |

危险/错误    #F53F3F  ██████████████████████  (删除、错误、失败)

| Token | 色值 | 用途 |

## 三、字体系统

### 3.1 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
```

| 平台 | 默认字体 |
|------|---------|
| macOS / iOS | PingFang SC（苹方） |
| Windows | Microsoft YaHei（微软雅黑） |
| 英文/数字 | -apple-system / Helvetica Neue |

### 3.2 字号与行高

| 层级 | 字号 | 行高 | 用途 |
|------|------|------|------|
| H1 大标题 | `24px` | `32px` | 页面主标题 |
| H2 标题 | `20px` | `28px` | 卡片标题、弹窗标题 |
| H3 小标题 | `16px` | `24px` | 区块标题、对话标题 |
| Body 正文 | `14px` | `22px` | 正文、表单标签、菜单项 |
| Caption 辅助 | `12px` | `20px` | 辅助说明、时间戳、标签 |
| Small 小字 | `11px` | `18px` | 角标、极小文字 |

### 3.3 字重

| Token | 值 | 用途 |
|-------|-----|------|
| `--font-weight-regular` | `400` | 正文、辅助文字 |
| `--font-weight-medium` | `500` | 标签、按钮文字、菜单 |
| `--font-weight-bold` | `600` | 标题、强调文字 |

## 四、间距系统

基于 **4px** 基础间距单位。

| Token | 值 | 用途 |
|-------|-----|------|
| `--spacing-xs` | `4px` | 极小间距（图标与文字） |
| `--spacing-sm` | `8px` | 小间距（表单项之间） |
| `--spacing-md` | `12px` | 中等间距 |
| `--spacing-lg` | `16px` | 常用间距（卡片 padding、区块间距） |
| `--spacing-xl` | `24px` | 大间距（页面内边距、模块间距） |
| `--spacing-2xl` | `32px` | 超大间距（页面上下留白） |
| `--spacing-3xl` | `48px` | 极大间距 |

## 十、动效规范

| 场景 | 时长 | 缓动 |
|------|------|------|
| hover 过渡 | `0.2s` | `ease` |
| 弹窗打开/关闭 | `0.3s` | `ease-out` |
| 侧边栏展开/折叠 | `0.3s` | `ease-in-out` |
| 消息出现 | `0.3s` | `ease-out` + 轻微上移 |
| 加载骨架屏 | `1.5s` | `ease-in-out`（循环） |

---

## 十一、设计对照检查清单

- [ ] 所有可点击元素有 hover 态反馈
- [ ] 表单校验错误使用 `#F53F3F` 红色提示
- [ ] 文字层级不超过 3 级颜色深度
- [ ] 间距使用 4px 倍数
- [ ] 圆角统一 4px/8px，不混用
- [ ] 弹窗/抽屉有遮罩层 (rgba(0,0,0,0.45))
- [ ] 加载态有骨架屏或 spin 动画，避免白屏
- [ ] 空状态有插图和引导文案
