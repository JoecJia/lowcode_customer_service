## 二、数据库设计

### 2.1 新建表：`users`（用户表）

```sql
CREATE TABLE IF NOT EXISTS users (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    username    TEXT    NOT NULL UNIQUE,          -- 用户名，唯一
    password    TEXT    NOT NULL,                 -- bcrypt 哈希后的密码
    role        TEXT    NOT NULL DEFAULT 'user',  -- 角色：'user' | 'admin'
    avatar      TEXT    DEFAULT '',               -- 头像 URL（预留）
    created_at  REAL    NOT NULL,                 -- 创建时间戳 (Unix timestamp)
    updated_at  REAL    NOT NULL                  -- 更新时间戳
);

CREATE UNIQUE INDEX IF NOT EXISTS idx_users_username ON users(username);
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `id` | INTEGER | ✅ | 自增主键 |
| `username` | TEXT | ✅ | 用户名，4-20 字符，唯一约束 |
| `password` | TEXT | ✅ | bcrypt 加密后的密码哈希值 |
| `role` | TEXT | ✅ | `'user'`（普通用户）或 `'admin'`（管理员） |
| `avatar` | TEXT | — | 头像 URL，预留字段，默认空 |
| `created_at` | REAL | ✅ | Unix 时间戳 |
| `updated_at` | REAL | ✅ | Unix 时间戳 |

**校验规则**：

**成功响应 (201 Created)**：

**失败响应**：

**JWT Token 载荷 (Payload)**：
```json

  "username": "zhangsan",
  "role": "user",            // 'user' | 'admin'

  "iat": 1716681600          // 签发时间
}
```

**后端实现伪代码** (`auth_service.py`)：
```python
import bcrypt
import jwt
from datetime import datetime, timedelta

JWT_SECRET = os.environ.get("JWT_SECRET", "change-me-in-production")
JWT_ALGORITHM = "HS256"
JWT_EXPIRATION_DAYS = 7

def hash_password(password: str) -> str:
    return bcrypt.hashpw(password.encode('utf-8'), bcrypt.gensalt()).decode('utf-8')

def verify_password(password: str, hashed: str) -> bool:
    return bcrypt.checkpw(password.encode('utf-8'), hashed.encode('utf-8'))

def create_token(user_id: int, username: str, role: str) -> str:
    payload = {
        "sub": user_id,
        "username": username,
        "role": role,
        "exp": datetime.utcnow() + timedelta(days=JWT_EXPIRATION_DAYS),
        "iat": datetime.utcnow(),
    }
    return jwt.encode(payload, JWT_SECRET, algorithm=JWT_ALGORITHM)

def decode_token(token: str) -> dict:
    return jwt.decode(token, JWT_SECRET, algorithms=[JWT_ALGORITHM])
```

#### 3.1.4 认证中间件 `get_current_user`（新建）

**文件**：`backend/dependencies/auth.py`

```python
from fastapi import Depends, HTTPException, Header
from typing import Optional
from services.auth_service import decode_token

async def get_current_user(authorization: Optional[str] = Header(None)) -> dict:
    """从 Authorization Header 提取并验证当前用户"""
    if not authorization:
        raise HTTPException(status_code=401, detail="未提供认证令牌")
    
    scheme, _, token = authorization.partition(" ")
    if scheme.lower() != "bearer":
        raise HTTPException(status_code=401, detail="认证格式错误")
    
    try:
        payload = decode_token(token)
    except Exception:
        raise HTTPException(status_code=401, detail="无效的认证令牌")
    
    return payload  # { sub, username, role, exp, iat }


def require_admin(current_user: dict = Depends(get_current_user)) -> dict:
    """管理员权限校验"""
    if current_user.get("role") != "admin":
        raise HTTPException(status_code=403, detail="需要管理员权限")
    return current_user
```

### 3.3 AI 对话模块（已有）

**文件**：`backend/routers/chat.py`（已存在，基本无需改造）

#### 3.3.1 POST `/api/chat` — AI 流式对话

- **认证**：需要 Bearer Token
- **响应类型**：`text/event-stream` (SSE)

**请求体**：
```json
{
  "session_id": "a1b2c3d4...",   // 会话 ID
  "message": "用户输入的消息",     // 消息正文
  "new_session": false           // 是否仅创建新会话（不发送消息）
}
```

**SSE 事件流类型**：

| event 类型 | data 结构 | 说明 |
|-----------|----------|------|
| `reasoning` | `{"content": "思考过程中的文本片段"}` | 模型思考过程，流式增量推送 |
| `content` | `{"content": "回复正文文本片段"}` | AI 回复内容，流式增量推送 |
| `task` | `{"type": "knowledge_retrieval", "status": "executed", "result": "检索结果"}` | Skill 任务执行结果 |
| `warning` | `{"content": "警告信息"}` | 异常情况通知 |
| `error` | `{"content": "错误信息"}` | 发生错误时推送 |
| `done` | `{}` | 对话完成 |

**SSE 流示例**：
```
event: reasoning
```

#### 4.2.4 密码强度计算逻辑

```typescript
function calcPasswordStrength(password: string): { level: number; label: string } {
  if (password.length < 6) return { level: 0, label: '' }
  let score = 0
  if (password.length >= 8) score++
  if (/[a-zA-Z]/.test(password) && /[0-9]/.test(password)) score++
  if (/[^a-zA-Z0-9]/.test(password)) score++
  const labels = ['', '弱', '中', '强']
  return { level: score, label: labels[score] }
}
```

**强度条渲染**：
- level 0：3 条全灰色
- level 1：第 1 条 `#F53F3F`（弱）
- level 2：前 2 条 `#FBA233`（中）
- level 3：3 条全 `#4DD655`（强）

### 5.4 API 请求拦截（Token 注入）

```typescript
// frontend/src/api/auth.ts (新建)

const BASE = '/api'

function getAuthHeaders(): Record<string, string> {
  const token = localStorage.getItem('auth_token')
  const headers: Record<string, string> = { 'Content-Type': 'application/json' }
  if (token) {
    headers['Authorization'] = `Bearer ${token}`
  }
  return headers
}

export async function authFetch(url: string, options: RequestInit = {}): Promise<Response> {
  const headers = getAuthHeaders()
  const resp = await fetch(url, {
    ...options,
    headers: { ...headers, ...(options.headers || {}) },
  })
  
  // 全局 401 拦截：Token 过期/无效 → 跳转登录
  if (resp.status === 401) {
    localStorage.removeItem('auth_token')
    localStorage.removeItem('user_info')
    window.location.href = '/login'
  }
  
  return resp
}
```

## 七、状态管理与全局配置

### 7.1 前端全局状态

本项目不引入 Pinia，使用 Vue 3 `provide/inject` + composable 模式管理全局状态。

```typescript
// frontend/src/composables/useAuth.ts (建议新建)
import { ref, computed } from 'vue'
import { useRouter } from 'vue-router'

interface UserInfo {
  id: number
  username: string
  role: 'user' | 'admin'
  avatar: string
}

const currentUser = ref<UserInfo | null>(
  JSON.parse(localStorage.getItem('user_info') || 'null')
)

const isLoggedIn = computed(() => !!localStorage.getItem('auth_token'))
const isAdmin = computed(() => currentUser.value?.role === 'admin')

export function useAuth() {
  const router = useRouter()

  function setAuth(token: string, user: UserInfo) {
    localStorage.setItem('auth_token', token)
    localStorage.setItem('user_info', JSON.stringify(user))
    currentUser.value = user
  }

  function logout() {
    localStorage.removeItem('auth_token')
    localStorage.removeItem('user_info')
    currentUser.value = null
    router.push('/login')
  }

  function getToken(): string | null {
    return localStorage.getItem('auth_token')
  }

  return { currentUser, isLoggedIn, isAdmin, setAuth, logout, getToken }
}
```

## 十、对开发文档的补充

除上述核心内容外，以下方面也建议在开发前充分考量：

### 10.1 错误处理与边界情况

| 场景 | 前端处理 | 后端处理 |
|------|---------|---------|
| Token 过期 | authFetch 全局拦截 401 → 清除 Token → 跳转 `/login` | 返回 401 + `{"detail": "Token 已过期"}` |
| 网络中断 | 显示 "网络连接失败，请检查网络" toast，自动重连 SSE | SSE 断连后自动清理临时状态 |
| 用户名已存在（注册） | 字段级 error 提示 "用户名已被注册" | 捕获 UNIQUE constraint 错误，返回 409 |
| 密码错误（登录） | 表单级 error 提示 "用户名或密码错误" | bcrypt 验证失败，返回 401 |
| 会话不属于当前用户 | 不显示在列表中（前端无感知） | 返回 403 Forbidden |
| SSE 流中断 | streamChat 的 onError 回调中显示错误信息，恢复按钮状态 | 正常中断或异常中断时发送 `event: error` |
| 空对话列表 | 显示空状态插图和 "暂无对话，点击新建开始对话" | 返回 `{ "sessions": [], "total": 0 }` |
| 并发发送消息 | 前端正处于 streaming 状态时，禁用发送按钮和输入框 | 不做特殊处理（每次对话独立） |
| XSS 防护 | 用户消息使用 `v-text` 或 HTML 转义，AI 回复使用 marked 渲染（已安全） | 不做特殊处理 |
| SQLite 并发锁 | — | 使用 `Lock` 确保写操作串行化 |
| 管理员权限不足 | 导航守卫拦截 + ElMessage.error | 中间件 `require_admin` 返回 403 |

### 10.2 安全性关注点

| 关注点 | 措施 |
|--------|------|
| 密码存储 | bcrypt 加盐哈希，不可逆 |
| Token 存储 | 前端 localStorage，生产环境建议使用 httpOnly Cookie |
| Token 有效期 | JWT 7 天过期，可配置 |
| XSS | 用户消息 HTML 转义，AI 回复 marked 渲染（无 raw HTML） |
| CSRF | SPA + Token 认证，天然免疫 |
| SQL 注入 | 使用参数化 SQL（`?` 占位符），原生 sqlite3 自动转义 |
| 敏感信息 | `.env` 不入 Git（已 .gitignore），API Key 不下发给前端 |
| CORS | 生产环境限制 `allow_origins`，非 `*` |

### 10.3 性能考量

| 场景 | 措施 |
|------|------|
| 对话列表过长 | 前端分页加载（滚动到底部加载更多），后端 `limit` + `offset` |
| SSE 连接数过多 | 每个用户最多 1 个活跃 SSE 连接，前端 AbortController 管理 |
| SQLite 读多写少 | WAL 模式 + 索引优化 |
| Markdown 渲染 | 利用 Vue 响应式缓存，不重复渲染已完成的静态消息 |
| 消息列表虚拟化 | 后期可选：1000+ 条消息时引入虚拟列表 |
