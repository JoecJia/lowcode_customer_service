## 三、后端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| Web 框架 | **FastAPI** | Python 异步 Web 框架，自动生成 OpenAPI 文档 |
| ASGI 服务器 | **Uvicorn** | 高性能异步服务器，开发模式 hot reload |
| 数据库 | **SQLite** | `backend/data/app.db`，4 张表：users / sessions / messages / feedback |
| 鉴权 | **JWT (HS256)** | 7 天过期 Token，通过 `dependencies/auth.py` 中间件注入 |
| 密码加密 | **bcrypt** | `hash_password()` / `verify_password()` |
| HTML 处理 | **BeautifulSoup4 + html2text** | 知识库文档 HTML 解析与纯文本转换 |
| 词嵌入 | **sentence-transformers** | 知识检索用的文本向量化 |
| Embedding 模型 | **BAAI/bge-small-zh-v1.5** | 512 维中文优化向量模型 |
| 向量索引 | **FAISS (IndexFlatIP)** | 内积索引，等价于余弦相似度检索 |
| 搜索引擎 | **BM25 + FAISS** | 关键词 + 向量混合检索 (RRF k=60 融合) |
| 中文分词 | **jieba** | 中文分词，辅助检索 |
| AI 大模型 | **Doubao-Seed-2.0-pro-260215** | 火山引擎 Ark `/api/v3/chat/completions` SSE 流式输出 |
| 会话管理 | Session Store | 内存 dict + SQLite 双写，TTL 30 分钟 |
| 技能系统 | Skill Registry | 支持 knowledge_retrieval / clarifying_questions / fallback 等 |

### API 接口

#### 健康检查

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/health` | 健康检查 |

#### 对话 & 会话 (chat.py — prefix: `/api`)

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/chat` | AI 对话 (SSE 流式响应，含 thinking / task / content 事件) |
| `GET` | `/api/sessions` | 会话列表（支持分页 `?offset=&limit=`） |
| `POST` | `/api/sessions` | 创建新会话 |
| `GET` | `/api/sessions/{id}/messages` | 获取会话消息（自动过滤 task_result 内部消息） |
| `PATCH` | `/api/sessions/{id}` | 修改会话标题 |
| `DELETE` | `/api/sessions/{id}` | 删除会话 |

#### 用户认证 (auth.py — prefix: `/api`)

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/register` | 用户注册 |
| `POST` | `/api/login` | 用户登录（返回 JWT Token） |
| `GET` | `/api/me` | 获取当前登录用户信息（需 Bearer Token） |

#### 用户反馈 (feedback.py — prefix: `/api`)

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/feedback` | 提交对话反馈 |
| `GET` | `/api/feedback/check` | 查询某消息是否有未处理的反馈 |
| `GET` | `/api/admin/feedbacks` | 管理员查看反馈列表 |
| `GET` | `/api/admin/feedbacks/{id}` | 查看反馈详情 |
| `POST` | `/api/admin/feedbacks/{id}/resolve` | 标记反馈为已处理 |

#### 管理员后台 (admin.py — prefix: `/api/admin`)

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/admin/agent-config/tree` | 获取 Agent 配置文件树 |
| `GET` | `/api/admin/agent-config/file` | 读取指定配置文件内容 |
| `GET` | `/api/admin/accounts` | 查看所有账号 |
| `POST` | `/api/admin/accounts` | 创建账号 |
| `PATCH` | `/api/admin/accounts/{id}/password` | 重置密码 |
| `PATCH` | `/api/admin/accounts/{id}/permissions` | 修改权限 |

## 四、开发环境

| 项目 | 命令 | 说明 |
|------|------|------|
| 一键启动 (Windows) | `.\windows_start.bat` 或 `.\windows_start.ps1` | 自动启动前后端（后端 :8000, 前端 :5173） |
| 前端开发 | `cd frontend && npm run dev` | 启动 Vite 开发服务器，自动代理 `/api`,`/health`,`/assets` 到 `:8000` |
| 后端开发 | `python backend/main.py` | 启动 :8000，hot reload |
| 前端构建 | `cd frontend && npm run build` | 输出到 `frontend/dist/` |
| 交互式调试 | `python debug/volcengine_doubao_stream.py` | 终端与 AI 直接对话 |
| 一体化部署 | 后端 `StaticFiles` 托管 `frontend/dist` | 生产模式 |

### 前后端通信

```
开发模式：
  浏览器 :5173 ──/api/*, /health──▶ Vite Proxy ──▶ FastAPI :8000
  浏览器 :5173 ──/assets/*─────────▶ Vite Proxy ──▶ FastAPI StaticFiles :8000

生产模式：
  浏览器 :8000 ──/api/*, /health──▶ FastAPI API
  浏览器 :8000 ──/*───────────────▶ StaticFiles (frontend/dist)
  浏览器 :8000 ──/assets/*─────────▶ StaticFiles (agent_config/context/assets)
```

## 五、数据流

```
用户输入 ──▶ POST /api/chat ──▶ agent_service.run_agent_stream()
                                      │
                                      ▼
                              llm_service 调用豆包模型 SSE 流式响应
                                      │
                              ┌───────┴───────┐
                              ▼               ▼
                        内容解析          Task 解析
                    (parse_tasks)     (dispatch_skill)
                              │               │
                              ▼               ▼
                     SSE event:         SSE event:
                   content/thinking       task
                              │               │
                              └───────┬───────┘
                                      ▼
                              前端 ChatView.vue
                            (EventSource 解析)
                                      │
                              ┌───────┴───────┐
                              ▼               ▼
                         对话气泡        思考过程折叠区
                       (Markdown 渲染)  (reasoning + task)
```
