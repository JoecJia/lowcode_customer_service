## 三、后端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| Web 框架 | **FastAPI** | Python 异步 Web 框架，自动生成 OpenAPI 文档 |
| ASGI 服务器 | **Uvicorn** | 高性能异步服务器 |
| 数据库 | **SQLite** | `data/app.db`，轻量级但会话持久化 |
| 词嵌入 | **sentence-transformers** | 知识检索用的文本向量化 |
| Embedding 模型 | **BAAI/bge-small-zh-v1.5** | 512 维中文优化向量模型，L2 归一化，Query 自动添加 BGE 前缀 |
| 向量索引 | **FAISS (IndexFlatIP)** | 内积索引，配合 L2 归一化等价于余弦相似度检索，支持增量增删 |
| 搜索引擎 | **BM25 + FAISS** | 关键词 + 向量混合检索 (RRF k=60 融合) |
| 中文分词 | **jieba** | 中文分词，辅助检索 |
| AI 大模型 | **豆包 (火山引擎)** | `/api/v3/chat/completions` SSE 流式输出 |
| 会话管理 | 自研 Session Store | 内存 dict + SQLite 双写，TTL 30 分钟 |
| 技能系统 | 自研 Skill Registry | 支持 knowledge_retrieval / clarifying_questions 等 |

## 四、开发环境

| 项目 | 命令 | 说明 |
|------|------|------|
| 前端开发 | `cd frontend && npm run dev` | 启动 :5173，自动代理 /api 到 :8000 |
| 后端开发 | `python backend/main.py` 或 `uvicorn backend.main:app --reload` | 启动 :8000 |
| 前端构建 | `cd frontend && npm run build` | 输出到 `frontend/dist/` |
| 一体化部署 | 后端直接 `StaticFiles` 托管 `frontend/dist` | 生产模式 |

### 前后端通信

```
开发模式：
  浏览器 :5173 ──/api/*──▶ Vite Proxy ──▶ FastAPI :8000

生产模式：
  浏览器 :8000 ──/api/*──▶ FastAPI API
  浏览器 :8000 ──/*──────▶ StaticFiles (frontend/dist)
```

## 五、HTML 原型 → Vue 组件转换对照

| 原型元素 | Element Plus 组件 | 备注 |
|----------|-------------------|------|
| 自定义 `<input>` | `<el-input>` | 自带 clearable / show-password / slots |
| 自定义 `<button>` | `<el-button type="primary">` | 自带 loading / disabled / size |
| 手写 form 校验 | `<el-form>` + `rules` prop | 声明式校验，无需手写逻辑 |
| 手写 toast | `ElMessage.success()` / `.error()` | 全局调用，自动消失 |
| 手写 error 提示 | `el-form-item` 的 `error` slot | 跟随字段定位 |
| 密码强度手写 | 保留自写逻辑 或 用 `el-progress` | 无直接对应组件 |
| 页面居中布局 | Element Plus `el-container` + flex | 响应式容器 |
| CSS 变量 | 提取到 `frontend/src/style.css` `:root` | 全局复用 |
